Lógica de Programação

1 min de leitura

fonte

Antes de aprender qualquer linguagem, vem a lógica de programação: a habilidade de quebrar um problema em passos claros e ordenados - como uma receita de bolo.

Um programa nada mais é do que uma sequência de instruções que o computador executa na ordem em que você escreveu. Aqui você começa a pensar em: o que precisa acontecer primeiro? E depois? O que se repete?

Dica: não se preocupe com "qual linguagem aprender" ainda. Primeiro treine o raciocínio de dividir um problema em passos.

# Pense como quem escreve uma receita.
# Quais são os passos para "ir ao mercado comprar pão"?

print("1. Pegar a chave")
print("2. Sair de casa")
print("3. Travar a porta")
print("4. Ir até a padaria")
print("5. Comprar pão")
print("Pronto!")

Configurando o Ambiente

1 min de leitura

fonte

Antes de escrever qualquer linha de código, você precisa de onde escrever. Um programa é um arquivo de texto salvo com uma extensão específica (.js, .ts, .py...) - o computador não entende código "soltando" no chat.

Você vai precisar de três coisas:

  1. Uma linguagem instalada - para essa trilha, JavaScript (Node.js) é uma boa pedida porque não precisa configurar quase nada, ou Python 3 se você preferir. Baixe o instalador oficial e siga o "next, next, finish".
  2. Um editor de código - o VS Code é gratuito, leve, cheio de extensões úteis e roda em Windows, Mac e Linux.
  3. Um terminal - aquela tela preta onde você digita comandos. No Mac e Linux já vem embutido; no Windows, o terminal do VS Code ou o PowerShell resolvem.

Depois de instalar tudo, teste no terminal:

node --version

Variáveis e Tipos

1 min de leitura

fonte

Uma variável é como uma caixinha com um nome, onde você guarda um valor para usar depois. Por exemplo: guardar a idade de alguém, ou o nome de um produto.

Os valores têm tipos diferentes:

  • Texto (string): "Olá, mundo"
  • Número: 42, 3.14
  • Booleano (verdadeiro/falso): true, false

Entender variáveis e tipos é a base para guardar e manipular informação - algo que todo programa faz o tempo inteiro.

Operadores e Expressões

1 min de leitura

fonte

Operadores são os símbolos que fazem operações com valores. Você já conhece vários da matemática.

Aritméticos - com números:

  • + soma, - subtração, * multiplicação, / divisão
  • % resto da divisão (útil para saber se um número é par: n % 2 === 0)
  • ** potência (em JavaScript e Python)

Comparação - comparam dois valores e devolvem true ou false:

  • === igual a (sempre prefira três sinais; == faz conversões estranhas)
  • !== diferente de
  • <, >, <=, >= menor/maior que

Lógicos - combinam condições:

  • && (e) - as duas precisam ser verdadeiras
  • || (ou) - pelo menos uma é verdadeira
  • ! (não) - inverte o valor

Operadores combinados viram expressões - toda expressão tem um valor. 2 + 3 vale 5; idade >= 18 vale true ou false. É o que permite montar lógica sem precisar escrever várias linhas.

Condicionais

1 min de leitura

fonte

Condicionais deixam o programa tomar decisões. É o famoso "se... então...":

Se a idade for maior ou igual a 18, então pode dirigir; senão, não pode.

Em código, isso aparece como if (se) e else (senão). É o que permite um programa reagir de formas diferentes dependendo da situação - em vez de sempre fazer a mesma coisa.

Domine condicionais e você já consegue escrever programas que se comportam de maneiras diferentes conforme os dados que recebem.

Laços e Iteração

1 min de leitura

fonte

Às vezes o programa precisa repetir uma ação várias vezes - somar 100 números, percorrer uma lista, tentar até algo dar certo. Para isso servem os laços (loops).

O for é o mais comum quando você sabe quantas vezes quer repetir:

for (let i = 0; i < 5; i++) {
  console.log(i); // imprime 0, 1, 2, 3, 4
}

O while é para quando você não sabe quantas vezes - repete enquanto a condição for verdadeira:

let resposta = "";
while (resposta !== "sair") {
  resposta = perguntarAoUsuario();
}

Para percorrer arrays existe o for...of (mais legível):

const nomes = ["Ana", "Bruno", "Carla"];
for (const nome of nomes) {
  console.log(`Olá, ${nome}!`);
}

Cuidado com o loop infinito: se a condição nunca virar falsa, o programa trava. Ctrl+C no terminal resolve. Se acontecer muito, é sinal de que a condição precisa de uma mudança.

Experimente

// Soma os números de 1 a 10
let total = 0;
for (let i = 1; i <= 10; i++) {
  total += i;
}
console.log("Soma de 1 a 10 =", total);
// Checkpoint · +10 XP pendente

Use um for para imprimir os números de 1 a 3, um por linha.

Funções

1 min de leitura

fonte

Uma função é um bloco de código com um nome, que faz uma tarefa específica e pode ser reutilizado quantas vezes você quiser - sem reescrever tudo.

Pense numa função como uma máquina: você coloca uma entrada (os parâmetros), ela processa e devolve um resultado. Por exemplo, uma função somar(a, b) recebe dois números e devolve a soma.

Funções são o que mantêm o código organizado e sem repetição. Conforme os programas crescem, elas se tornam essenciais para não virar bagunça.

Strings e Manipulação de Texto

1 min de leitura

fonte

String é o tipo que guarda texto - sempre entre aspas ("olá" ou 'olá'). Você pode juntar, cortar, procurar, trocar - tudo com métodos da própria string.

const nome = "Primo";
nome.toUpperCase();      // "PRIMO"
nome.toLowerCase();      // "primo"
nome.length;             // 5
nome[0];                 // "P" (primeiro caractere)
"Olá, " + nome + "!";    // "Olá, Primo!" (concatenação)
`Olá, ${nome}!`;         // "Olá, Primo!" (template literal - mais legível)

Strings são imutáveis em quase toda linguagem: nome.toUpperCase() não muda nome, devolve uma string nova. Para guardar, é preciso const novo = nome.toUpperCase();.

Quando o texto tem aspas dentro, use uma barra invertida para escapar: "Ele disse: \"olá\"". Ou use aspas diferentes: 'Ele disse: "olá"'.

Experimente

const frase = "  aprender programação é divertido  ";
console.log("original:", JSON.stringify(frase));
console.log("tamanho:", frase.length);
console.log("sem espaços:", JSON.stringify(frase.trim()));
console.log("maiúsculo:", frase.toUpperCase());
console.log("começa com 'aprender'?", frase.trim().startsWith("aprender"));

Listas (Arrays)

1 min de leitura

fonte

Um array (ou lista) guarda vários valores em ordem, dentro de uma única variável. É uma das estruturas mais usadas em qualquer programa.

const notas = [8, 9, 7, 10];
notas[0];      // 8 (o primeiro!)
notas.length;  // 4
notas.push(6); // adiciona 6 no final
notas.pop();   // remove o último
notas.includes(9); // true - busca um valor

Para percorrer todos os itens, o jeito clássico é o for. Mas existem métodos que deixam isso mais legível e poderoso:

const dobrados = notas.map(n => n * 2);
const maioresQue7 = notas.filter(n => n > 7);
const soma = notas.reduce((total, n) => total + n, 0);
  • map - transforma cada item em outro (mesma quantidade de itens).
  • filter - mantém só os itens que passam no teste.
  • reduce - combina todos os itens em um único valor.

Map, filter e reduce são a base da programação funcional - não precisa virar especialista agora, mas é bom saber que existem. Eles evitam muitos for complicados.

Experimente

const notas = [8, 9, 7, 10, 6];
console.log("notas:", notas);
console.log("maior:", Math.max(...notas));
console.log("média:", notas.reduce((t, n) => t + n, 0) / notas.length);
console.log("aprovados (>=7):", notas.filter(n => n >= 7));

Objetos e Dicionários

1 min de leitura

fonte

Um objeto (ou dicionário, em outras linguagens) guarda pares de chave: valor - uma forma natural de representar "uma coisa com vários dados".

const pessoa = {
  nome: "Ana",
  idade: 28,
  cidade: "São Paulo",
};
pessoa.nome;      // "Ana"
pessoa["idade"];  // 28
pessoa.email = "ana@exemplo.com"; // adiciona uma chave nova
delete pessoa.cidade;             // remove uma chave

Objetos podem ser aninhados (um objeto dentro do outro) - útil para representar dados do mundo real:

const pedido = {
  id: 123,
  cliente: { nome: "Ana", email: "ana@exemplo.com" },
  itens: [{ produto: "Caderno", preco: 12.5 }],
};

Objetos são a base do JSON (JavaScript Object Notation), que é o formato que a internet inteira usa para trocar dados. JSON.stringify(objeto) converte para texto; JSON.parse(texto) converte de volta. Sempre que você ouvir "API REST" ou "resposta de servidor", provavelmente é JSON indo e voltando.

Experimente

const usuario = {
  nome: "Ana",
  idade: 28,
  habilidades: ["JavaScript", "Python", "Git"],
};

console.log("Nome:", usuario.nome);
console.log("Habilidades:", usuario.habilidades.join(", "));
console.log("JSON:", JSON.stringify(usuario));

Depuração e Leitura de Erros

1 min de leitura

fonte

Todo programa tem bugs - errar faz parte. O que separa quem avança de quem trava é saber ler o erro e investigar em vez de fugir.

A primeira reação certa: ler a mensagem inteira, do topo para baixo. Geralmente ela diz:

  • O que deu errado (ex: "Cannot read properties of undefined")
  • Onde (arquivo e linha: app.js:42)
  • A stack trace - a sequência de chamadas que levou até ali

Ferramentas básicas que cobrem 90% dos casos:

  • console.log(valor) - imprime no terminal. O depurador universal.
  • console.error(...) e console.warn(...) - variantes para erros e avisos.
  • console.table(array) - imprime arrays/objetos em formato de tabela.
  • Debugger do editor - colocar um breakpoint (bolinha vermelha) e rodar passo a passo. Vale aprender quando o console.log parar de bastar.

Quando empacar, copie a mensagem de erro e pesquise no Google. Alguém no mundo já teve esse mesmo bug e provavelmente postou a solução. Ler erros em inglês é normal - vale a pena se acostumar desde cedo.

Dica: leia o erro em voz alta. "Cannot read properties of undefined, reading 'nome'" - significa que você tentou acessar .nome em algo que está undefined. Provavelmente a variável não recebeu o valor que você esperava.

Git: add, commit, push

1 min de leitura

fonte

Git é a ferramenta que registra o histórico do seu código. Cada vez que você "salva uma versão" (commit), o git guarda um ponto de retorno. É por isso que todo projeto - dessa trilha, do seu trabalho, de tudo - usa git.

Os quatro comandos que você usa 90% do tempo:

git init                   # cria um repositório novo na pasta atual
git add .                  # marca todos os arquivos alterados para o próximo commit
git commit -m "mensagem"   # salva um ponto no histórico
git push                   # envia para o GitHub (ou outro servidor)

Seu Primeiro Projeto

1 min de leitura

fonte

Você chegou ao fim da trilha. Agora é hora de fazer, não só ler. Escolha um dos projetos abaixo e construa do zero. Sozinho, no seu ritmo, sem pular etapas.

Sugestões de primeiro projeto

  • Calculadora - recebe dois números e uma operação, devolve o resultado. Prática de input/output, condicionais e funções.
  • Jogo de adivinhação - o computador "pensa" num número de 1 a 100 e você tenta adivinhar; ele diz "maior" ou "menor". Prática de loops, condições e números aleatórios.
  • Lista de tarefas (to-do) - você adiciona, marca como feita e remove itens. Prática de arrays, objetos e manipulação de strings.
  • Gerador de senhas - você diz o tamanho e quais tipos de caractere incluir; o programa monta uma senha aleatória. Prática de loops e Math.random.

Critério de "pronto"

  1. Funciona sem travar e sem erros.
  2. O código está no GitHub (aprendeu git, lembra?).
  3. Tem um README.md curto explicando: o que é, como rodar, o que você aprendeu fazendo.

Compartilhe

Quando terminar, compartilhe. Poste no LinkedIn, mande para amigos, comente no nosso GitHub em uma issue com a tag meu-projeto. O melhor jeito de fixar o que aprendeu é explicar para alguém - e quem sabe isso inspira outra pessoa a começar.

Próximo passo natural: escolha uma das trilhas seguintes (Frontend ou Backend) e continue construindo. Você já tem a base.
