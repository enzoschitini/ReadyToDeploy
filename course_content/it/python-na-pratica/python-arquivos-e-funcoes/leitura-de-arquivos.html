Nella vita reale, i dati raramente vengono digitati a mano nel codice: arrivano in file esportati da sistemi, foglio di calcolo o database. Saper aprire e leggere un file è il primo passo di qualsiasi analisi di dati.

Motivazione

Lavori nel team dati di una banca e hai ricevuto il file banco.csv, con informazioni su alcuni clienti. Il primo compito è semplice: scoprire l'età media dei clienti.

Un file CSV (Comma-Separated Values, o "valori separati da virgola") è un file di testo in cui ogni riga rappresenta un record e le colonne sono separate da virgole. La prima riga, chiamata intestazione, riporta il nome delle colonne. Nel nostro file, sono in inglese:

ColonnaSignificato
ageEtà
jobProfessione
maritalStato civile
educationIstruzione
defaultÈ inadempiente?
balanceSaldo sul conto
housingHa un mutuo per la casa?
loanHa un prestito personale?

Come possiamo portare il contenuto di questo file dentro Python e calcolare l'età media?

Aprendo file con with e open()

Per lavorare con un file, prima dobbiamo aprirlo. In Python, facciamo questo con la funzione nativa open(), quasi sempre accompagnata dalla parola chiave with:

with open('percorso/del/file', mode='modalità', encoding='utf-8') as alias:
    # blocco di codice che usa il file (indentato)
ParteCosa significa
'percorso/del/file'Nome (o percorso) del file. Senza cartella, Python cerca nella cartella corrente.
modeModalità di apertura. 'r' (read) è lettura ed è il predefinito. Vedremo gli altri di seguito.
encodingCodifica del testo. Usa 'utf-8' perché accenti e cediglia funzionino correttamente.
as aliasNome della variabile che rappresenta il file aperto dentro il blocco.

Il with garantisce che il file venga chiuso automaticamente alla fine del blocco, anche se si verifica un errore nel mezzo. Un file lasciato aperto per dimenticanza può rimanere bloccato, consumare memoria o addirittura perdere dati non ancora registrati.

Attenzione: se il file non esiste, open() in modalità lettura genera un errore FileNotFoundError. Possiamo gestire questa situazione con il try/except che abbiamo visto nel modulo precedente:

# Tentativo di aprire un file che non esiste
try:
    with open('file_che_non_esiste.csv', mode='r', encoding='utf-8') as file:
        print(file.read())
except FileNotFoundError:
    print('File non trovato. Controlla il nome e la cartella.')
# File non trovato. Controlla il nome e la cartella.

Leggere tutto con read()

Il metodo .read() legge tutto il contenuto del file in una sola volta e lo restituisce come un'unica string:

with open('banco.csv', mode='r', encoding='utf-8') as file:
    contenuto = file.read()

# Fuori dal blocco, il file è già stato chiuso, ma il testo letto resta nella variabile
print(contenuto)
print(type(contenuto))
# age,job,marital,education,default,balance,housing,loan
# 30,unemployed,married,primary,no,1787,no,no
# 33,services,married,secondary,no,4789,yes,yes
# ... (altre righe)
# <class 'str'>

Suggerimento: in modalità 'r' il file può essere solo letto. Qualsiasi tentativo di scriverci genera un errore, il che protegge il file originale da modifiche accidentali.

Leggere riga per riga

Il .read() è pratico, ma carica l'intero file in memoria. Per file grandi (centinaia di megabyte o più), l'ideale è leggere una riga alla volta. Python offre tre modi:

ModoCosa restituisceQuando usarlo
file.readline()La riga successiva del file, come stringPer leggere una riga specifica, come l'intestazione
for riga in file:Una riga a ogni ripetizione del cicloPer scorrere l'intero file senza caricarlo tutto in memoria
file.readlines()Una lista con tutte le righeFile piccoli, quando servono le righe in una lista

Esempio: il .readline() legge una riga e "avanza" nel file, quindi la chiamata successiva restituisce già la riga successiva.

with open('banco.csv', mode='r', encoding='utf-8') as file:
    intestazione = file.readline()        # 1ª riga: l'intestazione
    primo_cliente = file.readline()       # 2ª riga: il primo cliente

print(intestazione)
print(primo_cliente)
# age,job,marital,education,default,balance,housing,loan
#
# 30,unemployed,married,primary,no,1787,no,no
#

Nota che è apparsa una riga vuota dopo ogni testo. Ciò accade perché ogni riga letta termina con il carattere invisibile \n (interruzione di riga), e il print() aggiunge un'altra interruzione. La funzione repr() mostra la string "grezza", con questi caratteri visibili:

# repr() rivela i caratteri invisibili, come il \n alla fine della riga
print(repr(intestazione))

# .strip() rimuove spazi e interruzioni di riga dall'inizio e dalla fine
print(repr(intestazione.strip()))
# 'age,job,marital,education,default,balance,housing,loan\n'
# 'age,job,marital,education,default,balance,housing,loan'

Esempio: scorrendo l'intero file con for, che è il modo più semplice ed efficiente di leggere riga per riga.

with open('banco.csv', mode='r', encoding='utf-8') as file:
    for riga in file:
        # .strip() evita la riga vuota in più tra i record
        print(riga.strip())
# age,job,marital,education,default,balance,housing,loan
# 30,unemployed,married,primary,no,1787,no,no
# ... (altre righe, una alla volta)

Esempio: il .readlines() restituisce tutte le righe in una lista, ciascuna ancora con il \n alla fine.

with open('banco.csv', mode='r', encoding='utf-8') as file:
    righe = file.readlines()

print(len(righe))  # intestazione + 10 clienti
print(righe[:3])   # le prime tre righe
# 11
# ['age,job,marital,education,default,balance,housing,loan\n', '30,unemployed,married,primary,no,1787,no,no\n', '33,services,married,secondary,no,4789,yes,yes\n']

Attenzione: quando il file arriva alla fine, il .readline() restituisce una string vuota (''), non None. Puoi trovare codici che usano un ciclo while con .readline() per leggere il file, interrompendosi quando la string arriva vuota. Il for riga in file fa esattamente la stessa cosa, con meno codice e meno possibilità di errore.

Rivisitando la motivazione

Ora possiamo calcolare l'età media dei clienti. Il piano è:

  1. Leggere e scartare l'intestazione con .readline();
  2. Scorrere le righe rimanenti con for;
  3. In ogni riga, rimuovere il \n con .strip() e separare le colonne con .split(',');
  4. Prendere la prima colonna (l'età), convertirla in int e salvarla in una lista.
eta_clienti = []

with open('banco.csv', mode='r', encoding='utf-8') as file:
    file.readline()  # scarta l'intestazione

    for riga in file:
        colonne = riga.strip().split(',')  # '30,unemployed,...' -> ['30', 'unemployed', ...]
        eta = int(colonne[0])              # l'età è la 1ª colonna e arriva come testo
        eta_clienti.append(eta)

print(eta_clienti)
# [30, 33, 35, 30, 59, 35, 36, 39, 41, 43]

Con le età in una lista, la media è la somma divisa per la quantità:

eta_media = sum(eta_clienti) / len(eta_clienti)
print(f'Età media dei clienti: {eta_media:.1f} anni')
# Età media dei clienti: 38.1 anni

Attenzione: tutto ciò che viene letto da un file di testo arriva come str, anche se sembra un numero. Senza int(), la lista avrebbe '30', '33' e così via, e il sum() genererebbe un errore.

Suggerimento: separare le colonne con .split(',') funziona bene per file semplici, ma fallisce quando un valore contiene una virgola (per esempio, "São Paulo, SP"). Per questi casi esistono il modulo csv di Python e la libreria Pandas, che vedremo in moduli futuri.
