Con le funzioni, nasce una domanda importante: una variabile creata dentro di una funzione esiste anche fuori di essa? E il contrario? Lo scope (ambito) definisce dove una variabile può essere accessibile e per quanto tempo esiste. Capire questo evita errori difficili da individuare.

Definizione

Lo scope di una variabile è la regione del codice in cui essa è visibile. In Python, i due scope più importanti sono:

ScopeDove la variabile viene creataDove può essere usataPer quanto tempo esiste
LocaleDentro di una funzione (inclusi i parametri)Solo dentro quella funzioneMentre la funzione viene eseguita
GlobaleFuori da qualsiasi funzione (nel "corpo" del notebook)Ovunque, anche dentro le funzioni (per la lettura)Finché il programma (o la sessione) termina

Scope locale

Le variabili create dentro una funzione sono locali: nascono quando la funzione viene chiamata e vengono scartate quando essa termina.

Esempio: sommando i valori di una lista.

def sommare_lista(numeri: list) -> int:
    totale = 0  # variabile locale: esiste solo dentro la funzione
    for numero in numeri:
        totale = totale + numero
    return totale

somma = sommare_lista([2, 4, 6, 8])
print(somma)
# 20

Fuori dalla funzione, la variabile totale non esiste. Provare a usarla genera un errore:

# print(totale)    # NameError: name 'totale' is not defined

# Il risultato arriva qui fuori tramite il return, salvato nella variabile somma
print(somma)
# 20

Suggerimento: Python ha già la funzione nativa sum(), che fa esattamente ciò che fa sommare_lista(). Abbiamo creato la nostra solo per capire lo scope, ma nella pratica quotidiana preferisci le funzioni native.

Scope globale

Le variabili create fuori dalle funzioni sono globali e possono essere lette dentro qualsiasi funzione:

tassa_amministrazione = 0.02  # variabile globale

def calcolare_valore_netto(valore_lordo: float) -> float:
    # La funzione riesce a LEGGERE la variabile globale
    return valore_lordo * (1 - tassa_amministrazione)

print(calcolare_valore_netto(1000))
# 980.0

Ma attenzione: se la funzione assegna un valore a una variabile con lo stesso nome, Python crea una nuova variabile locale, e la globale resta intatta:

def simulare_tassa_maggiore(valore_lordo: float) -> float:
    tassa_amministrazione = 0.10  # crea una variabile LOCALE con lo stesso nome
    return valore_lordo * (1 - tassa_amministrazione)

print(simulare_tassa_maggiore(1000))  # usa la tassa locale (10%)
print(tassa_amministrazione)          # la globale rimane 0.02
# 900.0
# 0.02

Per modificare una variabile globale dentro una funzione, occorre dichiararla con la parola chiave global:

contatore_simulazioni = 0

def registrare_simulazione():
    # contatore_simulazioni += 1  # senza "global": UnboundLocalError
    global contatore_simulazioni
    contatore_simulazioni += 1

registrare_simulazione()
registrare_simulazione()
print(contatore_simulazioni)
# 2

Attenzione: usare global rende il codice difficile da capire e da testare, perché la funzione dipende da qualcosa "nascosto" al di fuori di essa. Preferisci il percorso più chiaro: ricevere i dati tramite parametri e restituire il risultato con return.

# Stesso risultato, senza global: la funzione riceve il valore e restituisce quello nuovo
def incrementare(contatore: int) -> int:
    return contatore + 1

contatore = 0
contatore = incrementare(contatore)
contatore = incrementare(contatore)
print(contatore)
# 2

Strutture condizionali e di ripetizione

A differenza di altri linguaggi, in Python if e for non creano un proprio scope. Una variabile creata al loro interno continua a esistere dopo che il blocco termina.

saldo = 1787

if saldo > 0:
    situazione = 'positivo'  # creata dentro l'if...
else:
    situazione = 'negativo'

print(situazione)  # ...ma accessibile fuori da esso
# positivo

for indice in range(3):
    ultimo_elaborato = indice

# Dopo il ciclo, le due variabili continuano a esistere con l'ultimo valore
print(indice)
print(ultimo_elaborato)
# 2
# 2

Attenzione: una variabile creata in un blocco che non è stato eseguito semplicemente non esiste. Se nell'esempio sopra solo l'if definisse situacao (senza l'else) e il saldo fosse negativo, print(situacao) genererebbe un NameError. Perciò, assicurati che la variabile riceva un valore in tutti i percorsi possibili, oppure creala con un valore iniziale prima dell'if.

saldo = -88

# Valore iniziale definito prima dell'if: la variabile esiste sempre
situazione = 'non negativo'
if saldo < 0:
    situazione = 'negativo'

print(situazione)
# negativo
