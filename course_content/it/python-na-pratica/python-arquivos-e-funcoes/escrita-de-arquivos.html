Importante quanto leggere dati è salvare risultati: un report, una lista filtrata, un file per un altro sistema. In questa lezione creeremo file, li sovrascriveremo e aggiungeremo contenuto a essi.

Modalità di apertura

Il parametro mode di open() definisce cosa possiamo fare con il file:

ModalitàNomeSe il file esiste...Se il file non esiste...
'r'Lettura (read)Apre in letturaGenera FileNotFoundError
'w'Scrittura (write)Cancella tutto il contenuto e scrive da zeroCrea il file
'a'Aggiunta (append)Scrive alla fine, mantenendo il contenutoCrea il file
'x'Creazione esclusivaGenera FileExistsErrorCrea il file

Attenzione: la modalità 'w' cancella il file senza chiedere confermazione. Se l'obiettivo è aggiungere contenuto, usa 'a'. Se vuoi essere certo di non sovrascrivere nulla, usa 'x'.

Scrivere con write()

Il metodo .write() scrive una string nel file. Non aggiunge automaticamente l'interruzione di riga, quindi dobbiamo includere \n alla fine di ogni riga.

Esempio: salvando le età estratte nella lezione precedente in un nuovo file, idades.csv.

with open('idades.csv', mode='w', encoding='utf-8') as file:
    file.write('età\n')  # intestazione

    for eta in eta_clienti:
        # write() accetta solo str: convertiamo il numero e aggiungiamo l'interruzione di riga
        file.write(f'{eta}\n')

print('File idades.csv salvato!')
# File idades.csv salvato!

Leggiamo il file per verificare cosa è stato registrato:

with open('idades.csv', mode='r', encoding='utf-8') as file:
    print(file.read())

Attenzione: passare un numero direttamente a .write(), come file.write(30), genera un TypeError. Converti con str() oppure usa una f-string, come abbiamo fatto sopra.

Aggiungere contenuto con la modalità 'a'

Esempio: due nuovi clienti sono stati registrati e dobbiamo includere le loro età alla fine del file, senza perdere quelle già presenti.

nuove_eta = [25, 48]

# Modalità 'a': il contenuto esistente viene mantenuto e il nuovo va alla fine
with open('idades.csv', mode='a', encoding='utf-8') as file:
    for eta in nuove_eta:
        file.write(f'{eta}\n')

with open('idades.csv', mode='r', encoding='utf-8') as file:
    print(file.read())
# età

# 33
# 35
# 30
# 59
# 35
# 36
# 39
# 41
# 43
# 25
# 48

Suggerimento: se esegui la cella sopra più di una volta, le età 25 e 48 verranno aggiunte di nuovo a ogni esecuzione. Per tornare allo stato iniziale, esegui di nuovo la cella che usa la modalità 'w', che ricrea il file da zero.

Leggere da un file e scrivere in un altro

È molto comune leggere un file, elaborare le righe e registrare il risultato in un altro. Un unico with può aprire entrambi i file, separati da virgola.

Esempio: copiando banco.csv in un file con un'altra estensione, banco.txt.

with open('banco.csv', mode='r', encoding='utf-8') as lettura, \
     open('banco.txt', mode='w', encoding='utf-8') as scrittura:
    for riga in lettura:
        scrittura.write(riga)  # la riga termina già con \n

print('Copia completata!')
# Copia completata!

Suggerimento: l'estensione (.csv, .txt) è solo parte del nome del file e serve a indicare ai programmi come aprirlo. Il contenuto dei due file è esattamente lo stesso testo.

Esempio: il gestore del credito ha chiesto un file solo con i clienti che hanno un prestito personale (colonna loan, l'8ª colonna, con valore yes).

with open('banco.csv', mode='r', encoding='utf-8') as lettura, \
     open('clientes_com_emprestimo.csv', mode='w', encoding='utf-8') as scrittura:
    # L'intestazione è copiata così com'è
    scrittura.write(lettura.readline())

    for riga in lettura:
        colonne = riga.strip().split(',')
        ha_prestito = colonne[7] == 'yes'  # indice 7 = 8ª colonna (loan)
        if ha_prestito:
            scrittura.write(riga)

with open('clientes_com_emprestimo.csv', mode='r', encoding='utf-8') as file:
