Con la crescita dei programmi, le stesse porzioni di codice iniziano a ripetersi. Le funzioni permettono di dare un nome a un blocco di codice ed eseguirlo ogni volta che ci serve, con valori diversi ogni volta. Questo rende il codice più corto, più organizzato e più facile da correggere.

Motivazione

Lavori in una società di intermediazione finanziaria e devi simulare il rendimento di investimenti con interesse composto in diversi scenari. Nel regime a interesse composto, ogni anno il rendimento viene calcolato sul valore accumulato fino a quel momento: valore alla fine dell'anno = valore all'inizio dell'anno × (1 + tasso di interesse annuale).

Ecco come sarebbe il codice per simulare solo due scenari:

# Scenario 1
valore_iniziale = 1000.00
tasso_interesse_annuale = 0.05
anni = 10

valore_finale = valore_iniziale
for anno in range(anni):
    valore_finale = valore_finale * (1 + tasso_interesse_annuale)

print(f'R$ {valore_iniziale:.2f} al {tasso_interesse_annuale:.0%} annuo, in {anni} anni: R$ {valore_finale:.2f}')

# Scenario 2: esattamente lo stesso codice, cambiano solo i valori
valore_iniziale = 1020.00
tasso_interesse_annuale = 0.03
anni = 10

valore_finale = valore_iniziale
for anno in range(anni):
    valore_finale = valore_finale * (1 + tasso_interesse_annuale)

print(f'R$ {valore_iniziale:.2f} al {tasso_interesse_annuale:.0%} annuo, in {anni} anni: R$ {valore_finale:.2f}')
# R$ 1000.00 al 5% annuo, in 10 anni: R$ 1628.89
# R$ 1020.00 al 3% annuo, in 10 anni: R$ 1370.79

Suggerimento: nella f-string, il formato :.0% moltiplica il numero per 100 e aggiunge il simbolo di percentuale: 0.05 diventa 5%.

E se fossero 50 scenari? Copiare e incollare lo stesso blocco 50 volte renderebbe il codice enorme, e un errore nel calcolo dovrebbe essere corretto in 50 posti.

Come possiamo riutilizzare questo codice ed evitare tanta ripetizione?

Definizione

Una funzione è un blocco di codice con un nome, che viene eseguito solo quando è chiamato. Abbiamo già usato diverse funzioni pronte di Python, come print(), len() e open(). Ora creeremo le nostre.

Definendo una funzione:

def nome_della_funzione(parametro_1, parametro_2):
    # blocco di codice (indentato)
    return valore_di_ritorno

Chiamando una funzione:

risultato = nome_della_funzione(argomento_1, argomento_2)
ParteCosa significa
defParola chiave che inizia la definizione di una funzione
nome_della_funzioneNome della funzione, in snake_case e preferibilmente con un verbo (calcolare_, leggere_, mostrare_)
(parametro_1, ...)Parametri: variabili che ricevono i valori inviati nella chiamata
returnRestituisce un risultato a chi ha chiamato la funzione

Esempio: una funzione che mostra un messaggio a schermo.

# Definire la funzione NON esegue il codice: lo salva solo con un nome
def mostrare_messaggio(messaggio):
    print(messaggio)

# Ora sì, la funzione viene eseguita (e può essere chiamata tutte le volte che vogliamo)
mostrare_messaggio('Ciao a tutti! Benvenuti al modulo 04.')
mostrare_messaggio('Le funzioni evitano la ripetizione del codice.')
# Ciao a tutti! Benvenuti al modulo 04.
# Le funzioni evitano la ripetizione del codice.

Attenzione: così come le variabili, la funzione deve essere definita prima di essere chiamata. Se chiami mostrare_messaggio() senza aver eseguito la cella con il def, Python genererà un NameError.

Suggerimento: è buona pratica descrivere cosa fa la funzione in una docstring, un testo tra triple virgolette subito sotto il def. Appare quando qualcuno usa help() sulla funzione.

def mostrare_messaggio(messaggio):
    '''Mostra a schermo il messaggio ricevuto.'''
    print(messaggio)

help(mostrare_messaggio)
# Help on function mostrare_messaggio in module __main__:
#
# mostrare_messaggio(messaggio)
#     Mostra a schermo il messaggio ricevuto.

Parametri e argomenti

I parametri sono le variabili dichiarate tra parentesi nel def. Gli argomenti sono i valori che inviamo a quei parametri al momento della chiamata. Una funzione può avere nessuno, uno o più parametri.

Esempio: funzione senza parametri.

def ottenere_pi():
    return 3.14159265359

valore_pi = ottenere_pi()
print(valore_pi)
# 3.14159265359

Attenzione: non salvare mai il risultato in una variabile con lo stesso nome della funzione, come ottenere_pi = ottenere_pi(). La variabile sostituisce la funzione, e una seconda chiamata ottenere_pi() genera un TypeError, perché ora il nome punta a un float, non a una funzione.

Esempio: funzione con più parametri. Gli argomenti possono essere passati in due modi: posizionali (nello stesso ordine dei parametri) o nominati (indicando parametro=valore, quando l'ordine non conta e la chiamata risulta più leggibile).

def calcolare_totale_acquisto(prezzo_unitario, quantita):
    return prezzo_unitario * quantita

# Argomenti posizionali: l'ordine conta
print(calcolare_totale_acquisto(12.50, 4))

# Argomenti nominati: l'ordine non conta
print(calcolare_totale_acquisto(quantita=4, prezzo_unitario=12.50))
# 50.0
# 50.0

Esempio: parametri con valore predefinito. Se l'argomento non viene indicato nella chiamata, il parametro assume il valore definito nel def.

def calcolare_prezzo_finale(prezzo, sconto=0.0):
    return prezzo * (1 - sconto)

print(calcolare_prezzo_finale(100))                # usa lo sconto predefinito (0%)
print(calcolare_prezzo_finale(100, sconto=0.15))   # sconto del 15%
# 100.0
# 85.0

Attenzione: i parametri con valore predefinito devono venire dopo i parametri obbligatori. Una definizione come def calcolare_prezzo_finale(sconto=0.0, prezzo): genera un SyntaxError.

Possiamo anche indicare il tipo previsto di ciascun parametro e del ritorno, usando le type hints (suggerimenti di tipo): parametro: tipo e -> tipo_del_ritorno.

def calcolare_prezzo_finale(prezzo: float, sconto: float = 0.0) -> float:
    return prezzo * (1 - sconto)

print(calcolare_prezzo_finale(250.0, sconto=0.10))
# 225.0

Suggerimento: le type hints servono come documentazione e aiutano gli editor di codice a individuare errori, ma Python non le verifica durante l'esecuzione. Una chiamata con un tipo diverso da quello indicato continua a funzionare (o a fallire) normalmente.

Ritorno

Il return restituisce un valore a chi ha chiamato la funzione. Questo valore può essere salvato in una variabile, stampato o usato in altri calcoli.

def convertire_in_maiuscolo(testo: str) -> str:
    testo_maiuscolo = testo.upper()
    return testo_maiuscolo

nome = 'André Perez'
nome_maiuscolo = convertire_in_maiuscolo(nome)

print(nome)
print(nome_maiuscolo)
# André Perez
# ANDRÉ PEREZ

Mostrare non è lo stesso che restituire. Una funzione senza return restituisce automaticamente il valore None. Perciò, il risultato di una funzione che usa solo print() non può essere sfruttato in seguito:

def mostrare_doppio(numero):
    print(numero * 2)   # mostra solo a schermo

def calcolare_doppio(numero):
    return numero * 2   # restituisce il valore

risultato_mostrare = mostrare_doppio(5)
risultato_calcolare = calcolare_doppio(5)

print(f'mostrare_doppio ha restituito:  {risultato_mostrare}')
print(f'calcolare_doppio ha restituito: {risultato_calcolare}')
# 10
# mostrare_doppio ha restituito:  None
# calcolare_doppio ha restituito: 10

Il return termina anche la funzione immediatamente: nulla di ciò che si trova dopo di esso nello stesso percorso viene eseguito. Questo permette di restituire valori diversi in base a una condizione.

Esempio: classificando il saldo di un cliente della banca.

def classificare_saldo(saldo: float) -> str:
    if saldo < 0:
        return 'negativo'   # la funzione termina qui se il saldo è negativo
    if saldo == 0:
        return 'zero'
    return 'positivo'

print(classificare_saldo(-88))
print(classificare_saldo(0))
print(classificare_saldo(1787))
# negativo
# zero
# positivo

Una funzione può restituire più di un valore, separandoli con la virgola. In realtà, Python unisce i valori in una tupla, che possiamo "spacchettare" in più variabili nella chiamata.

Esempio: separando l'utente e il provider di un'email.

def estrarre_utente_e_provider(email: str) -> tuple[str, str]:
    parti = email.split('@')
    utente = parti[0]
    provider = parti[1]
    return utente, provider

utente, provider = estrarre_utente_e_provider('andre.perez@gmail.com')

print(utente)
print(provider)
# andre.perez
# gmail.com

Gestire errori dentro le funzioni

Le funzioni che gestiscono file possono fallire per vari motivi: cartella inesistente, mancanza di permessi, dati in un formato inatteso. Con try/except, la funzione può gestire l'errore e informare chi l'ha chiamata se l'operazione è andata a buon fine.

Esempio: una funzione riutilizzabile per registrare un file CSV a una colonna, che restituisce True in caso di successo e False in caso di errore.

def scrivere_file_csv(nome_file: str, intestazione: str, valori: list) -> bool:
    '''Salva un CSV con una colonna. Restituisce True se è andato a buon fine e False in caso di errore.'''
    try:
        with open(nome_file, mode='w', encoding='utf-8') as file:
            file.write(f'{intestazione}\n')
            for valore in valori:
                file.write(f'{valore}\n')
    except Exception as errore:
        print(f'Non è stato possibile salvare il file: {errore}')
        return False

    return True

# Chiamata corretta: valori è una lista
salvato = scrivere_file_csv('idades_funcao.csv', 'idade', [30, 33, 35, 30, 59])
print(f'Salvato con successo? {salvato}')
# Salvato con successo? True

# Chiamata con errore: 10 non è una lista, quindi il for dentro la funzione fallisce
salvato = scrivere_file_csv('idades_funcao_erro.csv', 'idade', 10)
print(f'Salvato con successo? {salvato}')
# Non è stato possibile salvare il file: 'int' object is not iterable
# Salvato con successo? False

Suggerimento: nota come il programma non si è bloccato nel secondo caso. L'errore è stato gestito dentro la funzione, e il valore False permette al resto del codice di decidere cosa fare.

Rivisitando la motivazione

Ora possiamo inserire il calcolo dell'interesse composto in una funzione. Nota che essa si limita a calcolare e restituire il valore. Mostrare il risultato spetta a chi la chiama, il che rende la funzione più facile da riutilizzare.

def calcolare_interesse_composto(valore_iniziale: float, tasso_interesse_annuale: float, anni: int) -> float:
    '''Restituisce il valore finale di un investimento con interesse composto annuale.'''
    valore_finale = valore_iniziale
    for _ in range(anni):  # "_" indica che la variabile del ciclo non è usata
        valore_finale = valore_finale * (1 + tasso_interesse_annuale)
    return valore_finale

Gli stessi due scenari di prima, ora con una riga ciascuno:

valore_finale_1 = calcolare_interesse_composto(valore_iniziale=1000.00, tasso_interesse_annuale=0.05, anni=10)
valore_finale_2 = calcolare_interesse_composto(valore_iniziale=1020.00, tasso_interesse_annuale=0.03, anni=10)

print(f'Scenario 1: R$ {valore_finale_1:.2f}')
print(f'Scenario 2: R$ {valore_finale_2:.2f}')
# Scenario 1: R$ 1628.89
# Scenario 2: R$ 1370.79

E simulare più scenari diventa banale. Esempio: confrontando diversi tassi per lo stesso valore iniziale.

tassi_simulati = [0.03, 0.05, 0.08, 0.10]

for tasso in tassi_simulati:
    valore_finale = calcolare_interesse_composto(valore_iniziale=1000.00, tasso_interesse_annuale=tasso, anni=10)
    print(f'Tasso del {tasso:.0%} annuo: R$ {valore_finale:.2f}')
# Tasso del 3% annuo: R$ 1343.92
# Tasso del 5% annuo: R$ 1628.89
# Tasso del 8% annuo: R$ 2158.92
# Tasso del 10% annuo: R$ 2593.74

Suggerimento: l'interesse composto ha anche una formula diretta, valore finale = valore iniziale × (1 + tasso) ^ anni, che in Python diventa valore_iniziale * (1 + tasso_interesse_annuale) ** anni. Poiché il calcolo è isolato in una funzione, potremmo sostituire il ciclo con la formula senza cambiare nessuna chiamata. Questo è un altro grande vantaggio delle funzioni.

# Verifica: la formula diretta dà lo stesso risultato del ciclo
print(round(1000.00 * (1 + 0.05) ** 10, 2))
print(round(calcolare_interesse_composto(1000.00, 0.05, 10), 2))
# 1628.89
# 1628.89

Attenzione: il round() di Python usa l'arrotondamento bancario: quando il numero è esattamente nel mezzo (.5), arrotonda al numero pari più vicino. Perciò round(2.5) restituisce 2, e non 3.

print(round(10 / 4))  # 2.5 -> 2 (il pari più vicino)
print(round(3.5))     # 3.5 -> 4 (il pari più vicino)
print(round(2.6))     # 2.6 -> 3 (non è nel mezzo: arrotonda normalmente)
# 2
# 4
# 3
