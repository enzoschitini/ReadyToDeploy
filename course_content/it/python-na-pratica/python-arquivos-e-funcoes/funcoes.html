Con la crescita dei programmi, le stesse porzioni di codice iniziano a ripetersi. Le funzioni permettono di dare un nome a un blocco di codice ed eseguirlo ogni volta che ci serve, con valori diversi ogni volta. Questo rende il codice più corto, più organizzato e più facile da correggere.

Motivazione

Lavori in una società di intermediazione finanziaria e devi simulare il rendimento di investimenti con interesse composto in diversi scenari. Nel regime a interesse composto, ogni anno il rendimento viene calcolato sul valore accumulato fino a quel momento: valore alla fine dell'anno = valore all'inizio dell'anno × (1 + tasso di interesse annuale).

Ecco come sarebbe il codice per simulare solo due scenari:

# Cenário 1
valor_inicial = 1000.00
taxa_juros_anual = 0.05
anos = 10

valor_final = valor_inicial
for ano in range(anos):
    valor_final = valor_final * (1 + taxa_juros_anual)

print(f'R$ {valor_inicial:.2f} a {taxa_juros_anual:.0%} ao ano, em {anos} anos: R$ {valor_final:.2f}')

# Cenário 2: exatamente o mesmo código, só mudam os valores
valor_inicial = 1020.00
taxa_juros_anual = 0.03
anos = 10

valor_final = valor_inicial
for ano in range(anos):
    valor_final = valor_final * (1 + taxa_juros_anual)

print(f'R$ {valor_inicial:.2f} a {taxa_juros_anual:.0%} ao ano, em {anos} anos: R$ {valor_final:.2f}')
# R$ 1000.00 a 5% ao ano, em 10 anos: R$ 1628.89
# R$ 1020.00 a 3% ao ano, em 10 anos: R$ 1370.79

Suggerimento: nella f-string, il formato :.0% moltiplica il numero per 100 e aggiunge il simbolo di percentuale: 0.05 diventa 5%.

E se fossero 50 scenari? Copiare e incollare lo stesso blocco 50 volte renderebbe il codice enorme, e un errore nel calcolo dovrebbe essere corretto in 50 posti.

Come possiamo riutilizzare questo codice ed evitare tanta ripetizione?

Definizione

Una funzione è un blocco di codice con un nome, che viene eseguito solo quando è chiamato. Abbiamo già usato diverse funzioni pronte di Python, come print(), len() e open(). Ora creeremo le nostre.

Definendo una funzione:

def nome_da_funcao(parametro_1, parametro_2):
    # bloco de código (indentado)
    return valor_de_retorno

Chiamando una funzione:

resultado = nome_da_funcao(argumento_1, argumento_2)
ParteCosa significa
defParola chiave che inizia la definizione di una funzione
nome_da_funcaoNome della funzione, in snake_case e preferibilmente con un verbo (calcular_, ler_, exibir_)
(parametro_1, ...)Parametri: variabili che ricevono i valori inviati nella chiamata
returnRestituisce un risultato a chi ha chiamato la funzione

Esempio: una funzione che mostra un messaggio a schermo.

# Definir a função NÃO executa o código: apenas o guarda com um nome
def exibir_mensagem(mensagem):
    print(mensagem)

# Agora sim, a função é executada (e pode ser chamada quantas vezes quisermos)
exibir_mensagem('Olá, pessoal! Bem-vindos ao módulo 04.')
exibir_mensagem('Funções evitam repetição de código.')
# Olá, pessoal! Bem-vindos ao módulo 04.
# Funções evitam repetição de código.

Attenzione: così come le variabili, la funzione deve essere definita prima di essere chiamata. Se chiami exibir_mensagem() senza aver eseguito la cella con il def, Python genererà un NameError.

Suggerimento: è buona pratica descrivere cosa fa la funzione in una docstring, un testo tra triple virgolette subito sotto il def. Appare quando qualcuno usa help() sulla funzione.

def exibir_mensagem(mensagem):
    '''Exibe a mensagem recebida na tela.'''
    print(mensagem)

help(exibir_mensagem)
# Help on function exibir_mensagem in module __main__:
#
# exibir_mensagem(mensagem)
#     Exibe a mensagem recebida na tela.

Parametri e argomenti

I parametri sono le variabili dichiarate tra parentesi nel def. Gli argomenti sono i valori che inviamo a quei parametri al momento della chiamata. Una funzione può avere nessuno, uno o più parametri.

Esempio: funzione senza parametri.

def obter_pi():
    return 3.14159265359

valor_pi = obter_pi()
print(valor_pi)
# 3.14159265359

Attenzione: non salvare mai il risultato in una variabile con lo stesso nome della funzione, come obter_pi = obter_pi(). La variabile sostituisce la funzione, e una seconda chiamata obter_pi() genera un TypeError, perché ora il nome punta a un float, non a una funzione.

Esempio: funzione con più parametri. Gli argomenti possono essere passati in due modi: posizionali (nello stesso ordine dei parametri) o nominati (indicando parametro=valore, quando l'ordine non conta e la chiamata risulta più leggibile).

def calcular_total_compra(preco_unitario, quantidade):
    return preco_unitario * quantidade

# Argumentos posicionais: a ordem importa
print(calcular_total_compra(12.50, 4))

# Argumentos nomeados: a ordem não importa
print(calcular_total_compra(quantidade=4, preco_unitario=12.50))
# 50.0
# 50.0

Esempio: parametri con valore predefinito. Se l'argomento non viene indicato nella chiamata, il parametro assume il valore definito nel def.

def calcular_preco_final(preco, desconto=0.0):
    return preco * (1 - desconto)

print(calcular_preco_final(100))                # usa o desconto padrão (0%)
print(calcular_preco_final(100, desconto=0.15))  # desconto de 15%
# 100.0
# 85.0

Attenzione: i parametri con valore predefinito devono venire dopo i parametri obbligatori. Una definizione come def calcular_preco_final(desconto=0.0, preco): genera un SyntaxError.

Possiamo anche indicare il tipo previsto di ciascun parametro e del ritorno, usando le type hints (suggerimenti di tipo): parametro: tipo e -> tipo_do_retorno.

def calcular_preco_final(preco: float, desconto: float = 0.0) -> float:
    return preco * (1 - desconto)

print(calcular_preco_final(250.0, desconto=0.10))
# 225.0

Suggerimento: le type hints servono come documentazione e aiutano gli editor di codice a individuare errori, ma Python non le verifica durante l'esecuzione. Una chiamata con un tipo diverso da quello indicato continua a funzionare (o a fallire) normalmente.

Ritorno

Il return restituisce un valore a chi ha chiamato la funzione. Questo valore può essere salvato in una variabile, stampato o usato in altri calcoli.

def converter_para_maiusculas(texto: str) -> str:
    texto_maiusculo = texto.upper()
    return texto_maiusculo

nome = 'André Perez'
nome_maiusculo = converter_para_maiusculas(nome)

print(nome)
print(nome_maiusculo)
# André Perez
# ANDRÉ PEREZ

Mostrare non è lo stesso che restituire. Una funzione senza return restituisce automaticamente il valore None. Perciò, il risultato di una funzione che usa solo print() non può essere sfruttato in seguito:

def exibir_dobro(numero):
    print(numero * 2)   # apenas mostra na tela

def calcular_dobro(numero):
    return numero * 2   # devolve o valor

resultado_exibir = exibir_dobro(5)
resultado_calcular = calcular_dobro(5)

print(f'exibir_dobro devolveu:  {resultado_exibir}')
print(f'calcular_dobro devolveu: {resultado_calcular}')
# 10
# exibir_dobro devolveu:  None
# calcular_dobro devolveu: 10

Il return termina anche la funzione immediatamente: nulla di ciò che si trova dopo di esso nello stesso percorso viene eseguito. Questo permette di restituire valori diversi in base a una condizione.

Esempio: classificando il saldo di un cliente della banca.

def classificar_saldo(saldo: float) -> str:
    if saldo < 0:
        return 'negativo'   # a função termina aqui se o saldo for negativo
    if saldo == 0:
        return 'zerado'
    return 'positivo'

print(classificar_saldo(-88))
print(classificar_saldo(0))
print(classificar_saldo(1787))
# negativo
# zerado
# positivo

Una funzione può restituire più di un valore, separandoli con la virgola. In realtà, Python unisce i valori in una tupla, che possiamo "spacchettare" in più variabili nella chiamata.

Esempio: separando l'utente e il provider di un'email.

def extrair_usuario_e_provedor(email: str) -> tuple[str, str]:
    partes = email.split('@')
    usuario = partes[0]
    provedor = partes[1]
    return usuario, provedor

usuario, provedor = extrair_usuario_e_provedor('andre.perez@gmail.com')

print(usuario)
print(provedor)
# andre.perez
# gmail.com

Gestire errori dentro le funzioni

Le funzioni che gestiscono file possono fallire per vari motivi: cartella inesistente, mancanza di permessi, dati in un formato inatteso. Con try/except, la funzione può gestire l'errore e informare chi l'ha chiamata se l'operazione è andata a buon fine.

Esempio: una funzione riutilizzabile per registrare un file CSV a una colonna, che restituisce True in caso di successo e False in caso di errore.

def escrever_arquivo_csv(nome_arquivo: str, cabecalho: str, valores: list) -> bool:
    '''Grava um CSV de uma coluna. Retorna True se deu certo e False se houve erro.'''
    try:
        with open(nome_arquivo, mode='w', encoding='utf-8') as arquivo:
            arquivo.write(f'{cabecalho}\n')
            for valor in valores:
                arquivo.write(f'{valor}\n')
    except Exception as erro:
        print(f'Não foi possível gravar o arquivo: {erro}')
        return False

    return True

# Chamada correta: valores é uma lista
gravou = escrever_arquivo_csv('idades_funcao.csv', 'idade', [30, 33, 35, 30, 59])
print(f'Gravou com sucesso? {gravou}')
# Gravou com sucesso? True

# Chamada com erro: 10 não é uma lista, então o for dentro da função falha
gravou = escrever_arquivo_csv('idades_funcao_erro.csv', 'idade', 10)
print(f'Gravou com sucesso? {gravou}')
# Não foi possível gravar o arquivo: 'int' object is not iterable
# Gravou com sucesso? False

Suggerimento: nota come il programma non si è bloccato nel secondo caso. L'errore è stato gestito dentro la funzione, e il valore False permette al resto del codice di decidere cosa fare.

Rivisitando la motivazione

Ora possiamo inserire il calcolo dell'interesse composto in una funzione. Nota che essa si limita a calcolare e restituire il valore. Mostrare il risultato spetta a chi la chiama, il che rende la funzione più facile da riutilizzare.

def calcular_juros_compostos(valor_inicial: float, taxa_juros_anual: float, anos: int) -> float:
    '''Retorna o valor final de um investimento com juros compostos anuais.'''
    valor_final = valor_inicial
    for _ in range(anos):  # "_" indica que a variável do laço não é usada
        valor_final = valor_final * (1 + taxa_juros_anual)
    return valor_final

Gli stessi due scenari di prima, ora con una riga ciascuno:

valor_final_1 = calcular_juros_compostos(valor_inicial=1000.00, taxa_juros_anual=0.05, anos=10)
valor_final_2 = calcular_juros_compostos(valor_inicial=1020.00, taxa_juros_anual=0.03, anos=10)

print(f'Cenário 1: R$ {valor_final_1:.2f}')
print(f'Cenário 2: R$ {valor_final_2:.2f}')
# Cenário 1: R$ 1628.89
# Cenário 2: R$ 1370.79

E simulare più scenari diventa banale. Esempio: confrontando diversi tassi per lo stesso valore iniziale.

taxas_simuladas = [0.03, 0.05, 0.08, 0.10]

for taxa in taxas_simuladas:
    valor_final = calcular_juros_compostos(valor_inicial=1000.00, taxa_juros_anual=taxa, anos=10)
    print(f'Taxa de {taxa:.0%} ao ano: R$ {valor_final:.2f}')
# Taxa de 3% ao ano: R$ 1343.92
# Taxa de 5% ao ano: R$ 1628.89
# Taxa de 8% ao ano: R$ 2158.92
# Taxa de 10% ao ano: R$ 2593.74

Suggerimento: l'interesse composto ha anche una formula diretta, valore finale = valore iniziale × (1 + tasso) ^ anni, che in Python diventa valor_inicial * (1 + taxa_juros_anual) ** anos. Poiché il calcolo è isolato in una funzione, potremmo sostituire il ciclo con la formula senza cambiare nessuna chiamata. Questo è un altro grande vantaggio delle funzioni.

# Conferindo: a fórmula direta dá o mesmo resultado que o laço
print(round(1000.00 * (1 + 0.05) ** 10, 2))
print(round(calcular_juros_compostos(1000.00, 0.05, 10), 2))
# 1628.89
# 1628.89

Attenzione: il round() di Python usa l'arrotondamento bancario: quando il numero è esattamente nel mezzo (.5), arrotonda al numero pari più vicino. Perciò round(2.5) restituisce 2, e non 3.

print(round(10 / 4))  # 2.5 -> 2 (o par mais próximo)
print(round(3.5))     # 3.5 -> 4 (o par mais próximo)
print(round(2.6))     # 2.6 -> 3 (não está no meio: arredonda normalmente)
# 2
# 4
# 3
