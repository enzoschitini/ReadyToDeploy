Man mano che un progetto cresce, è comune finire con vari moduli correlati. Un pacchetto è una cartella che raggruppa questi moduli, permettendo di organizzarli e importarli da un unico percorso.

Motivazione

Ora devi anche elaborare file di testo semplici, come il contenuto di una notizia. Creiamo un'altra classe per questo, simile a FileCSV.

# Legge un file di testo e permette di estrarre una riga specifica
class FileTXT:

    def __init__(self, percorso_file: str):
        self.percorso_file = percorso_file
        self.righe = self._leggi_righe()

    def _leggi_righe(self):
        with open(self.percorso_file, mode='r', encoding='utf-8') as file:
            return file.readlines()

    def estrai_riga(self, numero_riga: int):
        return self.righe[numero_riga - 1].strip()

contenuto_notizia = '''Ready To Deploy lancia un modulo sull'organizzazione del codice in Python
Il corso insegna a strutturare progetti più grandi usando moduli e pacchetti, seguendo le buone pratiche più usate nel mercato.
'''

with open('noticia.txt', mode='w', encoding='utf-8') as file:
    file.write(contenuto_notizia)

file_notizia = FileTXT(percorso_file='noticia.txt')

titolo = file_notizia.estrai_riga(numero_riga=1)
print(titolo)
# Ready To Deploy lancia un modulo sull'organizzazione del codice in Python

Definizione

Un pacchetto è una cartella comune, con un dettaglio: tradizionalmente contiene un file __init__.py (può essere vuoto) che segnala a Python che quella cartella deve essere trattata come un pacchetto importabile.

Suggerimento: a partire da Python 3.3, l'interprete riconosce anche cartelle senza __init__.py come pacchetti "impliciti" (namespace packages). Comunque, includere il file resta la pratica più comune e più compatibile tra versioni.

Creiamo un pacchetto chiamato file e spostiamo i moduli file_csv.py e file_txt.py al suo interno.

import os

os.makedirs('file', exist_ok=True)

# File vuoto che segnala la cartella come pacchetto
with open('file/__init__.py', mode='w', encoding='utf-8') as file:
    file.write('')

print('Pacchetto "file" creato.')
# Pacchetto "file" creato.

Il pacchetto risulta così, con i due moduli riutilizzati dalla lezione precedente:

file/
├── __init__.py
├── file_csv.py   # la classe FileCSV
└── file_txt.py   # la classe FileTXT

Rivisitando la motivazione

Ora importiamo i due moduli dall'interno del pacchetto, usando . per indicare il percorso cartella/modulo:

from file.file_csv import FileCSV
from file.file_txt import FileTXT

file_banco_pacote = FileCSV(percorso_file='banco.csv')

istruzione = file_banco_pacote.estrai_colonna(indice_colonna=3)
print(istruzione)
# ['primary', 'secondary', 'tertiary', 'tertiary', 'secondary', 'tertiary', 'tertiary', 'secondary', 'tertiary', 'primary']

file_notizia_pacote = FileTXT(percorso_file='noticia.txt')

titolo = file_notizia_pacote.estrai_riga(numero_riga=1)
print(titolo)
# Ready To Deploy lancia un modulo sull'organizzazione del codice in Python

Il risultato è lo stesso di prima, ma ora i due moduli sono organizzati dentro un'unica cartella — esattamente come le librerie reali (Pandas, NumPy...), che sono pacchetti con decine di moduli interni.
