Man mano che un progetto cresce, è comune finire con vari moduli correlati. Un pacchetto è una cartella che raggruppa questi moduli, permettendo di organizzarli e importarli da un unico percorso.

Motivazione

Ora devi anche elaborare file di testo semplici, come il contenuto di una notizia. Creiamo un'altra classe per questo, simile a ArquivoCSV.

# Lê um arquivo de texto e permite extrair uma linha específica
class ArquivoTXT:

    def __init__(self, caminho_arquivo: str):
        self.caminho_arquivo = caminho_arquivo
        self.linhas = self._ler_linhas()

    def _ler_linhas(self):
        with open(self.caminho_arquivo, mode='r', encoding='utf-8') as arquivo:
            return arquivo.readlines()

    def extrair_linha(self, numero_linha: int):
        return self.linhas[numero_linha - 1].strip()

conteudo_noticia = '''Ready To Deploy lança módulo sobre organização de código em Python
O curso ensina a estruturar projetos maiores usando módulos e pacotes, seguindo as boas práticas mais usadas no mercado.
'''

with open('noticia.txt', mode='w', encoding='utf-8') as arquivo:
    arquivo.write(conteudo_noticia)

arquivo_noticia = ArquivoTXT(caminho_arquivo='noticia.txt')

titulo = arquivo_noticia.extrair_linha(numero_linha=1)
print(titulo)
# Ready To Deploy lança módulo sobre organização de código em Python

Definizione

Un pacchetto è una cartella comune, con un dettaglio: tradizionalmente contiene un file __init__.py (può essere vuoto) che segnala a Python che quella cartella deve essere trattata come un pacchetto importabile.

Suggerimento: a partire da Python 3.3, l'interprete riconosce anche cartelle senza __init__.py come pacchetti "impliciti" (namespace packages). Comunque, includere il file resta la pratica più comune e più compatibile tra versioni.

Creiamo un pacchetto chiamato arquivo e spostiamo i moduli arquivo_csv.py e arquivo_txt.py al suo interno.

import os

os.makedirs('arquivo', exist_ok=True)

# Arquivo vazio que marca a pasta como um pacote
with open('arquivo/__init__.py', mode='w', encoding='utf-8') as arquivo:
    arquivo.write('')

print('Pacote "arquivo" criado.')
# Pacote "arquivo" criado.

Il pacchetto risulta così, con i due moduli riutilizzati dalla lezione precedente:

arquivo/
├── __init__.py
├── arquivo_csv.py   # a classe ArquivoCSV
└── arquivo_txt.py   # a classe ArquivoTXT

Rivisitando la motivazione

Ora importiamo i due moduli dall'interno del pacchetto, usando . per indicare il percorso cartella/modulo:

from arquivo.arquivo_csv import ArquivoCSV
from arquivo.arquivo_txt import ArquivoTXT

arquivo_banco_pacote = ArquivoCSV(caminho_arquivo='banco.csv')

escolaridade = arquivo_banco_pacote.extrair_coluna(indice_coluna=3)
print(escolaridade)
# ['primary', 'secondary', 'tertiary', 'tertiary', 'secondary', 'tertiary', 'tertiary', 'secondary', 'tertiary', 'primary']

arquivo_noticia_pacote = ArquivoTXT(caminho_arquivo='noticia.txt')

titulo = arquivo_noticia_pacote.extrair_linha(numero_linha=1)
print(titulo)
# Ready To Deploy lança módulo sobre organização de código em Python

Il risultato è lo stesso di prima, ma ora i due moduli sono organizzati dentro un'unica cartella — esattamente come le librerie reali (Pandas, NumPy...), che sono pacchetti con decine di moduli interni.
