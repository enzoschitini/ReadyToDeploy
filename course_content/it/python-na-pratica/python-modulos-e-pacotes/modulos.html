Un modulo è semplicemente un file .py contenente codice Python — funzioni, classi, variabili — pronto per essere riutilizzato. I moduli importati nella lezione precedente fanno parte della libreria standard di Python; in questa lezione creerai il tuo.

Motivazione

Hai scritto una classe che sa leggere un file CSV ed estrarre una qualsiasi delle sue colonne. È utile e ne avrai bisogno in vari notebook diversi — non ha senso copiare e incollare lo stesso codice ogni volta.

# Lê um arquivo CSV e permite extrair colunas específicas
class ArquivoCSV:

    def __init__(self, caminho_arquivo: str):
        self.caminho_arquivo = caminho_arquivo
        self.linhas = self._ler_linhas()
        self.colunas = self._extrair_nomes_colunas()

    def _ler_linhas(self):
        with open(self.caminho_arquivo, mode='r', encoding='utf-8') as arquivo:
            return arquivo.readlines()

    def _extrair_nomes_colunas(self):
        return self.linhas[0].strip().split(',')

    def extrair_coluna(self, indice_coluna: int):
        valores = []
        for linha in self.linhas[1:]:  # [1:] pula a linha de cabeçalho
            valores.append(linha.strip().split(',')[indice_coluna])
        return valores

Definizione

Un modulo proprio viene creato esattamente come il file di dati sopra: scriviamo il codice in un file .py. Python trova questo file automaticamente quando è nella stessa cartella del notebook — basta importarlo per nome, senza l'estensione.

Attenzione: nella pratica quotidiana, scriverai arquivo_csv.py direttamente in un editor di codice, con la classe ArquivoCSV della sezione precedente al suo interno — e non lo genererai da un'altra cella, come facciamo qui solo per far sì che il notebook riesca a creare il modulo da solo.

Rivisitando la motivazione

Ora importiamo la classe dal modulo che abbiamo appena creato, invece di averla definita direttamente nel notebook:

from arquivo_csv import ArquivoCSV

arquivo_banco_modulo = ArquivoCSV(caminho_arquivo='banco.csv')

escolaridade = arquivo_banco_modulo.extrair_coluna(indice_coluna=3)
print(escolaridade)
# ['primary', 'secondary', 'tertiary', 'tertiary', 'secondary', 'tertiary', 'tertiary', 'secondary', 'tertiary', 'primary']

Il risultato è identico a quello di prima — la differenza è che questa classe ora può essere riutilizzata in qualsiasi notebook che si trovi nella stessa cartella, basta importarla.

Rimangono accessibili solo i nomi che esistono realmente dentro il modulo. Provare a usare un metodo mai definito genera un AttributeError (visto nel Modulo 03):

try:
    soma = arquivo_banco_modulo._somar_saldos(coluna='balance')
except AttributeError as exc:
    print(f'Erro: {exc}')
# Erro: 'ArquivoCSV' object has no attribute '_somar_saldos'
