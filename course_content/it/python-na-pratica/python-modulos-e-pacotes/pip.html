Oltre alla libreria standard e ai moduli che scrivi tu stesso, esiste un universo di pacchetti creati dalla comunità Python per praticamente qualsiasi compito.

PyPI

Il PyPI (Python Package Index, pypi.org) è il repository ufficiale di pacchetti Python. Al suo interno trovi librerie per analisi dati, automazione, sviluppo web, intelligenza artificiale e molto altro — ognuna con la propria pagina, le proprie versioni e la propria documentazione.

pip

Il pip è lo strumento ufficiale per installare pacchetti dal PyPI direttamente dal terminale (su Colab, in una cella con ! davanti, che esegue un comando di sistema invece di Python).

ComandoCosa fa
pip install <pacchetto>Installa la versione più recente del pacchetto
pip install <pacchetto>==<versione>Installa una versione specifica
pip freezeElenca tutti i pacchetti installati e le loro versioni
pip uninstall <pacchetto>Rimuove un pacchetto installato
 
!pip install requests==2.32.3
# Successfully installed requests-2.32.3

Suggerimento: fissare la versione (==2.32.3) evita che un futuro aggiornamento del pacchetto rompa un codice che già funzionava — una buona pratica nei progetti reali.

Il comando pip freeze elenca tutti i pacchetti installati nell'ambiente, uno per riga, insieme alla versione esatta di ciascuno — utile per documentare (o riprodurre) le dipendenze di un progetto.

requests

Il pacchetto requests facilita le richieste al protocollo web HTTP, usato praticamente da ogni servizio su internet.

Esempio: stai automatizzando la compilazione di una registrazione e, a partire dal CAP indicato dal cliente, devi scoprire la via, il quartiere e la città. Il ViaCEP è un servizio pubblico e gratuito per questo tipo di ricerca.

import requests

risposta = requests.get('https://viacep.com.br/ws/01310930/json/')
print(f'Status code: {risposta.status_code}')
# Status code: 200

Uno status_code pari a 200 indica che la richiesta è andata a buon fine. Il contenuto restituito arriva come testo, nel formato JSON — un formato molto usato per lo scambio di dati tra sistemi:

print(risposta.text)
# {
#   "cep": "01310-930",
#   "logradouro": "Avenida Paulista",
#   "complemento": "2100",
#   "unidade": "Banco Safra S.A",
#   "bairro": "Bela Vista",
#   "localidade": "São Paulo",
#   "uf": "SP",
#   "estado": "São Paulo",
#   "regiao": "Sudeste",
#   "ibge": "3550308",
#   "gia": "1004",
#   "ddd": "11",
#   "siafi": "7107"
# }

Il modulo json, anch'esso della libreria standard, converte questo testo in un dizionario Python con json.loads():

import json

indirizzo = json.loads(risposta.text)
print(indirizzo)
# {'cep': '01310-930', 'logradouro': 'Avenida Paulista', 'complemento': '2100', 'unidade': 'Banco Safra S.A', 'bairro': 'Bela Vista', 'localidade': 'São Paulo', 'uf': 'SP', 'estado': 'São Paulo', 'regiao': 'Sudeste', 'ibge': '3550308', 'gia': '1004', 'ddd': '11', 'siafi': '7107'}

Lo stesso requests offre già una scorciatoia per questo, senza dover importare manualmente json: risposta.json().

indirizzo = risposta.json()

print(f"Via: {indirizzo['logradouro']}")
print(f"Quartiere: {indirizzo['bairro']}")
print(f"Città: {indirizzo['localidade']} - {indirizzo['uf']}")
# Via: Avenida Paulista
# Quartiere: Bela Vista
# Città: São Paulo - SP

Praticamente ogni pacchetto che si connette a un'API (social network, banche, sistemi di pagamento, lo stesso ChatGPT...) segue questa stessa logica: una richiesta HTTP che restituisce dati in JSON.
