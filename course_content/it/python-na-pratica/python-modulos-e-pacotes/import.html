Python viene con una libreria standard enorme — la cosiddetta filosofia "batterie incluse" — piena di moduli pronti per compiti comuni. Per usare uno qualsiasi di essi, occorre prima importarlo.

import

Il modo più semplice è import nome_do_modulo, che porta il modulo intero. Poi, ogni funzione o variabile al suo interno si accede con nome_do_modulo.nome_do_item.

Esempio: il modulo random, per generare valori e scelte casuali.

import random

opcoes = ['pedra', 'papel', 'tesoura']

escolha_do_computador = random.choice(opcoes)
print(escolha_do_computador)
# tesoura

numero_aleatorio = random.random()  # float aleatório no intervalo [0, 1)
print(numero_aleatorio)
# 0.5191044337047542

Esempio: il modulo math, con funzioni e costanti matematiche.

import math

potencia = math.pow(10, 3)
print(potencia)
# 1000.0

# math.ceil() sempre arredonda PARA CIMA, diferente do round() visto no Módulo 01
numero_arredondado = math.ceil(10.1)
print(numero_arredondado)
# 11

print(math.pi)
# 3.141592653589793

Quando serve solo uno o alcuni elementi specifici di un modulo, importiamo esattamente questi nomi con from modulo import nome. Il vantaggio è usare il nome direttamente, senza il prefisso del modulo.

from modulo import nome

Attenzione: solo ciò che è stato esplicitamente importato diventa disponibile. Se il modulo time ha le funzioni time() e sleep(), ma importiamo solo time, provare a usare sleep() genera un NameError (visto nel Modulo 03) — semplicemente non esiste nel notebook.

from time import time

# 'time' foi importado e funciona
print(time())  # segundos desde 01/01/1970 (a "época Unix")

# sleep(1)  # NameError: name 'sleep' is not defined (sleep não foi importado)
# 1789135666.9954908

Per importare più di un nome dallo stesso modulo, li separiamo con la virgola:

from time import time, sleep

instante_inicial = time()
sleep(1)  # pausa a execução do programa por 1 segundo
instante_final = time()

print(f'Tempo decorrido: {instante_final - instante_inicial:.2f} segundos')
# Tempo decorrido: 1.00 segundos

from / import / as

Possiamo dare un alias (rinominare) a un modulo o a un elemento importato con as. È utile per accorciare nomi lunghi o evitare conflitti con altri nomi già usati nel codice.

Esempio: la classe datetime, che risiede dentro il modulo dello stesso nome, datetime — con l'alias dt per non confondere i due.

from datetime import datetime as dt

print(dt.now())
# 2026-09-11 11:07:48.102980

print(dt.now().day)
# 11

print(dt.now().year)
# 2026

Suggerimento: alias brevi e consolidati nel mercato — come import pandas as pd e import numpy as np — sono una convenzione che vedrai in praticamente ogni codice di analisi dati in Python, inclusi i prossimi moduli di questo corso.
