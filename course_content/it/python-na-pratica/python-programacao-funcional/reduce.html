map() trasforma e filter() seleziona, ma entrambi restituiscono comunque una collezione. Quando l'obiettivo è condensare tutto in un unico valore — una somma, l'elemento più grande, una concatenazione — usiamo reduce().

Definizione

La funzione reduce() applica una funzione a tutti gli elementi di una collezione, due alla volta, accumulando il risultato, finché non resta un unico valore:

variavel = reduce(funcao, colecao)

Attenzione: a differenza di map() e filter(), reduce() non è una funzione nativa di Python — da Python 3 deve essere importata dal modulo functools.

from functools import reduce

numeros = [1, 2, 3, 4]

soma = reduce(lambda acumulado, atual: acumulado + atual, numeros)
print(soma)
# 10

Funzioni di ordine superiore con reduce

Esempio: trovando il numero più grande di una lista, senza usare la funzione pronta max().

def maior_entre(primeiro: int, segundo: int) -> int:
    return primeiro if primeiro >= segundo else segundo

print(maior_entre(11, 4))
# 11

from random import random

# Lista com 100 números inteiros aleatórios entre 0 e 100
# (list comprehension: veremos essa sintaxe em detalhe em um módulo futuro)
numeros = [round(100 * random()) for _ in range(100)]
print(numeros[:10], '...')  # mostrando só os 10 primeiros
# [47, 21, 4, 15, 42, 56, 60, 35, 71, 84] ...

# reduce aplica maior_entre() aos dois primeiros números, depois ao
# resultado com o terceiro, depois ao resultado com o quarto, e assim
# por diante, até sobrar só o maior de todos
maior_numero = reduce(maior_entre, numeros)
print(maior_numero)
# 100

# A mesma lógica, com a função escrita como lambda
maior_numero = reduce(lambda primeiro, segundo: primeiro if primeiro >= segundo else segundo, numeros)
print(maior_numero)
# 100

Suggerimento: per trovare il valore più grande di una collezione, Python ha già la funzione nativa max() — molto più diretta di reduce() per questo caso specifico. L'esempio sopra ha fini didattici: reduce() si distingue davvero quando la logica di combinazione è personalizzata e non esiste una funzione pronta per essa.

Combinando map, filter e reduce

Poiché map(), filter() e reduce() seguono lo stesso schema (funzione + collezione), possono essere concatenati: l'uscita di uno diventa l'ingresso del successivo.

Esempio: sommando il quadrato solo dei numeri originariamente dispari.

from random import random

numeros = [round(100 * random()) for _ in range(100)]
print(numeros[:10], '...')
# [50, 3, 65, 46, 43, 99, 40, 69, 84, 98] ...

Passo 1: elevare al quadrato ogni numero (map).

numeros_ao_quadrado = map(lambda numero: numero ** 2, numeros)

Passo 2: mantenere solo i quadrati dei numeri dispari — il quadrato di un numero dispari è anch'esso dispari (filter).

quadrados_impares = filter(lambda numero: numero % 2 != 0, numeros_ao_quadrado)

Passo 3: sommare tutto in un unico valore (reduce).

soma_quadrados_impares = reduce(lambda acumulado, atual: acumulado + atual, quadrados_impares)
print(soma_quadrados_impares)
# 190475

Attenzione: map e filter restituiscono iteratori che possono essere percorsi solo una volta. Per questo, l'esempio sotto riparte dalla lista numeros originale — riutilizzare numeros_ao_quadrado o quadrados_impares qui non funzionerebbe, poiché entrambi sono già stati consumati nel passo 3 sopra.

soma_quadrados_impares = reduce(
    lambda acumulado, atual: acumulado + atual,
    filter(
        lambda numero: numero % 2 != 0,
        map(lambda numero: numero ** 2, numeros),
    ),
)
print(soma_quadrados_impares)
# 190475

Anche se il concatenamento sopra funziona in un'unica riga, diventa difficile da leggere. Nella pratica quotidiana, preferisci il formato passo dopo passo (come fatto prima) ogni volta che la riga diventa troppo lunga — il codice funzionale non deve essere compatto per essere buono.
