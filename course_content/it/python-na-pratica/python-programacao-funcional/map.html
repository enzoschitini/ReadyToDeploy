Con lambda già padroneggiata, possiamo combinarla con funzioni che operano su intere collezioni in una volta sola. La prima di queste è map(), che trasforma ogni elemento di una collezione.

Definizione

La funzione map() applica una funzione a tutti gli elementi di una collezione (list, dict ecc.) e restituisce tutti gli elementi già trasformati:

variabile = map(funzione, collezione)

numeri = [1, 2, 3]

numeri_al_cubo = map(lambda num: num ** 3, numeri)
print(numeri_al_cubo)
# <map object at 0x000002E53187AC50>

Attenzione: map() non restituisce una list, ma un iteratore — per questo print() mostra solo l'indirizzo dell'oggetto in memoria, e non i valori. Per vedere o usare i risultati, converti con list(). Inoltre, un iteratore può essere percorso solo una volta: dopo essere stato convertito (o usato in un ciclo), resta "vuoto".

print(list(numeri_al_cubo))
# [1, 8, 27]

Sostituendo i cicli con map

Esempio: estraendo il provider di più e-mail. Prima, la forma imperativa, con un ciclo for:

emails = ['andre.perez@gmail.com', 'andre.perez@live.com', 'andre.perez@yahoo.com']
estrai_provider_email = lambda email: email.split(sep='@')[-1]

# Forma imperativa: costruiamo la lista manualmente, elemento per elemento
provider = []
for email in emails:
    provider_email = estrai_provider_email(email)
    provider.append(provider_email)

print(provider)
# ['gmail.com', 'live.com', 'yahoo.com']

Ora, lo stesso compito in stile funzionale, con map() — senza ciclo, senza lista vuota da riempire:

provider = list(map(estrai_provider_email, emails))
print(provider)
# ['gmail.com', 'live.com', 'yahoo.com']

Suggerimento: quando la funzione è usata in un solo punto, non c'è bisogno di nominarla — possiamo passare la lambda direttamente come argomento di map().

provider = list(map(lambda email: email.split(sep='@')[-1], emails))
print(provider)
# ['gmail.com', 'live.com', 'yahoo.com']

map con più parametri

map() accetta anche più di una collezione: in questo caso, la funzione passata deve ricevere un parametro per ogni collezione, e gli elementi vengono combinati posizione per posizione (il 1° elemento di ogni lista, poi il 2°, e così via).

Esempio: calcolando il rendimento di più scenari di investimento in una sola volta.

def calcola_rendimento_investimento(valore_iniziale: float, tasso_interesse: float, anni: int) -> float:
    valore_finale = valore_iniziale
    for _ in range(anni):
        valore_finale = valore_finale * (1 + tasso_interesse)
    return round(valore_finale, 2)

valori_iniziali = [1000, 1000, 1000]
tassi_interesse = [0.05, 0.10, 0.15]
anni = [10, 10, 10]

scenari = list(map(calcola_rendimento_investimento, valori_iniziali, tassi_interesse, anni))
print(scenari)
# [1628.89, 2593.74, 4045.56]
