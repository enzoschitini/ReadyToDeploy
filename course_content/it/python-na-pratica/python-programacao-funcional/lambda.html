Il primo passo della programmazione funzionale è riuscire a creare funzioni piccole e usa e getta senza tutto il cerimoniale di un def. È per questo che esiste la funzione lambda.

Definizione

Una funzione lambda è una funzione anonima (senza nome), scritta in un'unica riga, contenente solo un'espressione — non può avere cicli, print() o istruzioni multiple. La sua sintassi è:

variabile = lambda parametri: espressione

L'espressione è automaticamente il valore di ritorno, senza bisogno della parola return.

Esempio: estraendo il provider di un'e-mail.

estrai_provider_email = lambda email: email.split(sep='@')[-1]

email = 'andre.perez@gmail.com'
print(email)

provider_email = estrai_provider_email(email)
print(provider_email)
# andre.perez@gmail.com
# gmail.com

Buone pratiche

Poiché una lambda può contenere solo un'espressione, è comune usare l'operatore ternario (valore_se_vero if condizione else valore_se_falso) per incorporare una decisione semplice.

Esempio: verificando se un numero è pari.

# Funziona, ma l'if/else è ridondante: il confronto è già un booleano
numero_e_pari_verboso = lambda numero: True if numero % 2 == 0 else False

# Forma diretta e più idiomatica: basta restituire il confronto stesso
numero_e_pari = lambda numero: numero % 2 == 0

print(numero_e_pari_verboso(4))
print(numero_e_pari(4))
# True
# True

for numero in range(10):
    if numero_e_pari(numero):
        print(f'Il numero {numero} è pari!')
# Il numero 0 è pari!
# Il numero 2 è pari!
# Il numero 4 è pari!
# Il numero 6 è pari!
# Il numero 8 è pari!

Attenzione: essendo limitata a un'espressione, lambda non sostituisce def in ogni situazione. Usa lambda per logiche brevi e, soprattutto, passate direttamente come argomento di un'altra funzione (come vedremo in map, filter e reduce). Per una logica con più righe o che necessita di un nome proprio nel codice, preferisci def — la PEP 8 raccomanda anzi di non assegnare una lambda a una variabile quando un def renderebbe il codice più chiaro.

Funzioni di ordine superiore

Una funzione di ordine superiore è una funzione che riceve un'altra funzione come parametro oppure che restituisce una funzione. Combinare questo con lambda è molto potente: una funzione può "fabbricare" altre funzioni su misura.

Esempio: una calcolatrice di rendimento d'investimento, in cui il tasso di interesse è già incorporato nella funzione generata.

def crea_calcolatrice_rendimento(tasso_interesse: float):
    # La lambda restituita "ricorda" il valore di tasso_interesse anche
    # dopo che crea_calcolatrice_rendimento() ha già terminato di
    # eseguire — questo si chiama closure.
    return lambda investimento: investimento * (1 + tasso_interesse)

rendimento_5_percento = crea_calcolatrice_rendimento(tasso_interesse=0.05)
rendimento_10_percento = crea_calcolatrice_rendimento(tasso_interesse=0.10)

# Ogni calcolatrice "conosce" già il proprio tasso di interesse
valore_finale = rendimento_5_percento(investimento=1000)
print(round(valore_finale, 2))

valore_finale = rendimento_10_percento(investimento=1000)
print(round(valore_finale, 2))
# 1050.0
# 1100.0

Poiché le calcolatrici restituiscono un valore, possiamo concatenarle in un ciclo per simulare l'interesse composto nel corso di vari anni:

anni = 10
valore_finale = 1000

for _ in range(anni):
    valore_finale = rendimento_5_percento(investimento=valore_finale)

print(round(valore_finale, 2))
# 1628.89

anni = 10
valore_finale = 1000

for _ in range(anni):
    valore_finale = rendimento_10_percento(investimento=valore_finale)

print(round(valore_finale, 2))
# 2593.74
