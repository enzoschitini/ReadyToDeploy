Anche un codice senza errori di battitura può fallire durante l'esecuzione, a causa di situazioni impreviste: una divisione per zero, un dato nel formato sbagliato, una posizione che non esiste in una lista. Questi errori di esecuzione sono chiamati eccezioni, e Python permette di gestirle affinché il programma non venga interrotto.

Motivazione

Stai calcolando quanto ogni persona deve pagare in un conto al ristorante, dividendo il valore totale per la quantità di persone. Solo che questo numero di persone arriva da un modulo compilato da un'altra persona, e a volte arriva sbagliato — incluso come zero.

Se eseguiamo la divisione direttamente, Python interrompe il programma:

preco_total_conta = 132.85
quantidade_de_pessoas = 0

valor_por_pessoa = preco_total_conta / quantidade_de_pessoas
# ZeroDivisionError: float division by zero

Come evitiamo che il programma si blocchi quando accade questo?

try / except

La struttura try / except esegue un blocco di codice e, se si verifica un'eccezione, esegue un altro blocco al suo posto — senza interrompere il programma.

try:
  # código que pode falhar
except TipoDoErro:
  # executado somente se essa exceção ocorrer

preco_total_conta = 132.85
quantidade_de_pessoas = 0

try:
  valor_por_pessoa = preco_total_conta / quantidade_de_pessoas
  print(f'Cada pessoa paga R$ {valor_por_pessoa:.2f}')
except ZeroDivisionError:
  print('Erro: a quantidade de pessoas precisa ser maior que zero.')
# Erro: a quantidade de pessoas precisa ser maior que zero.

Con una quantità di persone valida, il try viene eseguito normalmente e l'except non viene nemmeno valutato:

preco_total_conta = 132.85
quantidade_de_pessoas = 2

try:
  valor_por_pessoa = preco_total_conta / quantidade_de_pessoas
  print(f'Cada pessoa paga R$ {valor_por_pessoa:.2f}')
except ZeroDivisionError:
  print('Erro: a quantidade de pessoas precisa ser maior que zero.')
# Cada pessoa paga R$ 66.42

Catturare i dettagli dell'eccezione e gestire più tipi

Possiamo catturare l'eccezione in una variabile (convenzione: except ... as exc) per ispezionarne il messaggio, e possiamo anche gestire più tipi di eccezione diversi nello stesso try, ognuno con il proprio except.

Esempio: cercare una posizione che non esiste in una lista di anni.

anos_com_vendas = [2019, 2020, 2021]

try:
  ano_mais_recente = anos_com_vendas[5]
  print(ano_mais_recente)
except IndexError as exc:
  print(f'Erro: posição inválida. A lista tem apenas {len(anos_com_vendas)} anos.')
  print(f'Mensagem original do Python: {exc}')
# Erro: posição inválida. A lista tem apenas 3 anos.
# Mensagem original do Python: list index out of range

Esempio: convertire un testo proveniente da un modulo in numero, gestendo prima l'errore specifico e un errore generico alla fine.

Attenzione: l'ordine conta. Python testa i blocchi except nell'ordine in cui appaiono, quindi metti sempre gli errori più specifici prima e un except Exception per ultimo, come una rete di sicurezza.

dado_de_entrada = 'não é um número'

try:
  valor_convertido = int(dado_de_entrada)
  print(valor_convertido)
except ValueError:
  print('Erro: não foi possível converter o texto para número.')
except Exception as exc:
  print(f'Erro inesperado: {exc}')
# Erro: não foi possível converter o texto para número.

try / except / finally

Il blocco finally viene eseguito sempre, sia che si sia verificata un'eccezione o no. È utile per azioni che devono avvenire indipendentemente dal risultato, come confermare che un processo è terminato.

nome_cliente = 'André'
idade_cliente = 19

try:
  # idade_cliente é int; o + não junta str com int (TypeError)
  apresentacao = 'Cliente: ' + nome_cliente + ', idade: ' + idade_cliente
except TypeError:
  apresentacao = 'Cliente: ' + nome_cliente + ', idade: ' + str(idade_cliente)
finally:
  print(apresentacao)
  print('Cadastro processado.')
# Cliente: André, idade: 19
# Cadastro processado.

Rivisitando la motivazione

Rendiamo il calcolo del valore a persona più realistico: la quantità di persone arriva come testo dal modulo, quindi può fallire in due modi diversi — un testo che non è un numero (ValueError) o il numero zero (ZeroDivisionError). Gestiamo entrambi, e usiamo il finally per avvisare che il calcolo è terminato.

preco_total_conta = 132.85
quantidade_de_pessoas_texto = '0'  # veio como texto de um formulário

try:
  quantidade_de_pessoas = int(quantidade_de_pessoas_texto)
  valor_por_pessoa = preco_total_conta / quantidade_de_pessoas
  print(f'Cada pessoa paga R$ {valor_por_pessoa:.2f}')
except ValueError:
  print('Erro: a quantidade de pessoas precisa ser um número.')
except ZeroDivisionError:
  print('Erro: a quantidade de pessoas precisa ser maior que zero.')
finally:
  print('Cálculo finalizado.')
# Erro: a quantidade de pessoas precisa ser maior que zero.
# Cálculo finalizado.
