Buona parte del lavoro di un programma è ripetitivo: sommare tutti i valori di una lista, verificare ogni riga di un foglio di calcolo, elaborare ogni cliente di un registro. Invece di ripetere il codice manualmente, usiamo la struttura di ripetizione for.

Motivazione

Hai le vendite del giorno di un negozio e vuoi sapere due cose: il totale venduto e quante vendite hanno superato R$ 300,00.

vendas_do_dia = [361, 553, 194, 13, 510, 33, 135]

Come elaboriamo tutti questi valori senza scrivere una riga di codice per ciascuno?

for / range

La struttura for esegue un blocco di codice una volta per ogni elemento di una collezione. Combinata con la funzione nativa range(), ripete il blocco un numero determinato di volte:

for variavel_temporaria in range(inicio, fim, passo):
  # executado uma vez para cada valor no intervalo

for valor in range(6):
  print(valor)
# 0
# 1
# 2
# 3
# 4
# 5

range(fim) inizia da 0; range(inicio, fim) definisce l'inizio; range(inicio, fim, passo) definisce anche l'incremento. Proprio come nello slicing delle stringhe (Modulo 01), il valore fim non viene mai incluso.

# Múltiplos de 3, de 0 (incluído) até 15 (excluído)
for multiplo_de_tres in range(0, 15, 3):
  print(multiplo_de_tres)
# 0
# 3
# 6
# 9
# 12

for / liste

Il modo più comune di usare il for è per percorrere gli elementi di una lista, uno per uno:

for venda in vendas_do_dia:
  print(venda)
# 361
# 553
# 194
# 13
# 510
# 33
# 135

Uno schema molto comune è accumulare un risultato a ogni ripetizione, usando una variabile creata prima del for:

total_vendido = 0

for venda in vendas_do_dia:
  total_vendido += venda

print(f'Total vendido: R$ {total_vendido:.2f}')
# Total vendido: R$ 1799.00

E possiamo combinare il for con l'if (visto nella sezione 1) per contare solo gli elementi che soddisfano una condizione:

quantidade_vendas_acima_300 = 0

for venda in vendas_do_dia:
  if venda > 300:
    quantidade_vendas_acima_300 += 1

print(f'Vendas acima de R$ 300: {quantidade_vendas_acima_300}')
# Vendas acima de R$ 300: 3

Anche le stringhe sono sequenze e possono essere percorse carattere per carattere. L'operatore in qui verifica se un carattere appartiene a un altro testo.

frase = 'Ready To Deploy'
quantidade_vogais = 0

for caractere in frase.lower():
  if caractere in 'aeiou':
    quantidade_vogais += 1

print(f'Quantidade de vogais: {quantidade_vogais}')
# Quantidade de vogais: 5

for / dizionari

I dizionari hanno tre metodi per essere percorsi in un for: .items() (chiave e valore), .keys() (solo le chiavi) e .values() (solo i valori).

escore_de_credito = {'123.456.789-00': 750, '987.654.321-00': 812, '111.222.333-44': 980}

# .items(): retorna cada par chave-valor
for documento, escore in escore_de_credito.items():
  print(f'Documento {documento}: escore {escore}')
# Documento 123.456.789-00: escore 750
# Documento 987.654.321-00: escore 812
# Documento 111.222.333-44: escore 980

# .keys(): retorna apenas as chaves
for documento in escore_de_credito.keys():
  print(documento)
# 123.456.789-00
# 987.654.321-00
# 111.222.333-44

# .values(): retorna apenas os valores
for escore in escore_de_credito.values():
  print(escore)
# 750
# 812
# 980

for documento in escore_de_credito: (senza .keys()) ha esattamente lo stesso effetto, poiché percorrere direttamente un dizionario restituisce già le sue chiavi.

break / continue

Due parole chiave controllano l'andamento di un ciclo for:

Parola chiaveEffetto
breakinterrompe il ciclo immediatamente, senza eseguire le ripetizioni rimanenti
continuesalta direttamente alla prossima ripetizione, senza eseguire il resto del blocco attuale

Esempio: fermarsi non appena troviamo la prima vendita superiore a R$ 500,00.

for venda in vendas_do_dia:
  if venda > 500:
    print(f'Primeira venda acima de R$ 500: {venda}')
    break
# Primeira venda acima de R$ 500: 553

Esempio: mostrare solo le vendite con valore pari, saltando le dispari con continue.

for venda in vendas_do_dia:
  if venda % 2 != 0:
    continue
  print(f'Venda par: {venda}')
# Venda par: 194
# Venda par: 510

Attenzione: qualsiasi codice scritto dopo un break o continue, ancora dentro lo stesso blocco if, non viene mai eseguito — il ciclo è già stato interrotto o è già avanzato prima di arrivarci.

Rivisitando la motivazione

Con for, if e l'accumulo in variabili, risolviamo le due domande della motivazione in un unico ciclo:

vendas_do_dia = [361, 553, 194, 13, 510, 33, 135]

total_vendido = 0
quantidade_vendas_acima_300 = 0

for venda in vendas_do_dia:
  total_vendido += venda
  if venda > 300:
    quantidade_vendas_acima_300 += 1

print(f'Total vendido: R$ {total_vendido:.2f}')
print(f'Vendas acima de R$ 300: {quantidade_vendas_acima_300}')
# Total vendido: R$ 1799.00
# Vendas acima de R$ 300: 3

Riepilogo del Modulo

StrutturaA cosa serveParole chiave
CondizionaleEseguire un blocco o un altro a seconda di una condizioneif, elif, else
Gestione delle eccezioniReagire a errori di esecuzione senza bloccare il programmatry, except, finally
RipetizioneEseguire un blocco più volte, su un intervallo, lista o dizionariofor, in, range()
Controllo del cicloInterrompere o saltare ripetizioni di un forbreak, continue

Principali operatori e funzioni visti in questo modulo: and, or, range(), .items(), .keys(), .values(), oltre ai tipi di eccezione ZeroDivisionError, TypeError, ValueError, IndexError, KeyError e NameError.
