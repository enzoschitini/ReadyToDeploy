Buona parte del lavoro di un programma è ripetitivo: sommare tutti i valori di una lista, verificare ogni riga di un foglio di calcolo, elaborare ogni cliente di un registro. Invece di ripetere il codice manualmente, usiamo la struttura di ripetizione for.

Motivazione

Hai le vendite del giorno di un negozio e vuoi sapere due cose: il totale venduto e quante vendite hanno superato R$ 300,00.

vendite_del_giorno = [361, 553, 194, 13, 510, 33, 135]

Come elaboriamo tutti questi valori senza scrivere una riga di codice per ciascuno?

for / range

La struttura for esegue un blocco di codice una volta per ogni elemento di una collezione. Combinata con la funzione nativa range(), ripete il blocco un numero determinato di volte:

for variabile_temporanea in range(inizio, fine, passo):
  # eseguito una volta per ogni valore nell'intervallo

for valore in range(6):
  print(valore)
# 0
# 1
# 2
# 3
# 4
# 5

range(fine) inizia da 0; range(inizio, fine) definisce l'inizio; range(inizio, fine, passo) definisce anche l'incremento. Proprio come nello slicing delle stringhe (Modulo 01), il valore fine non viene mai incluso.

# Multipli di 3, da 0 (incluso) a 15 (escluso)
for multiplo_di_tre in range(0, 15, 3):
  print(multiplo_di_tre)
# 0
# 3
# 6
# 9
# 12

for / liste

Il modo più comune di usare il for è per percorrere gli elementi di una lista, uno per uno:

for vendita in vendite_del_giorno:
  print(vendita)
# 361
# 553
# 194
# 13
# 510
# 33
# 135

Uno schema molto comune è accumulare un risultato a ogni ripetizione, usando una variabile creata prima del for:

totale_venduto = 0

for vendita in vendite_del_giorno:
  totale_venduto += vendita

print(f'Totale venduto: R$ {totale_venduto:.2f}')
# Totale venduto: R$ 1799.00

E possiamo combinare il for con l'if (visto nella sezione 1) per contare solo gli elementi che soddisfano una condizione:

quantita_vendite_sopra_300 = 0

for vendita in vendite_del_giorno:
  if vendita > 300:
    quantita_vendite_sopra_300 += 1

print(f'Vendite sopra R$ 300: {quantita_vendite_sopra_300}')
# Vendite sopra R$ 300: 3

Anche le stringhe sono sequenze e possono essere percorse carattere per carattere. L'operatore in qui verifica se un carattere appartiene a un altro testo.

frase = 'Ready To Deploy'
quantita_vocali = 0

for carattere in frase.lower():
  if carattere in 'aeiou':
    quantita_vocali += 1

print(f'Quantità di vocali: {quantita_vocali}')
# Quantità di vocali: 5

for / dizionari

I dizionari hanno tre metodi per essere percorsi in un for: .items() (chiave e valore), .keys() (solo le chiavi) e .values() (solo i valori).

punteggio_di_credito = {'123.456.789-00': 750, '987.654.321-00': 812, '111.222.333-44': 980}

# .items(): restituisce ogni coppia chiave-valore
for documento, punteggio in punteggio_di_credito.items():
  print(f'Documento {documento}: punteggio {punteggio}')
# Documento 123.456.789-00: punteggio 750
# Documento 987.654.321-00: punteggio 812
# Documento 111.222.333-44: punteggio 980

# .keys(): restituisce solo le chiavi
for documento in punteggio_di_credito.keys():
  print(documento)
# 123.456.789-00
# 987.654.321-00
# 111.222.333-44

# .values(): restituisce solo i valori
for punteggio in punteggio_di_credito.values():
  print(punteggio)
# 750
# 812
# 980

for documento in punteggio_di_credito: (senza .keys()) ha esattamente lo stesso effetto, poiché percorrere direttamente un dizionario restituisce già le sue chiavi.

break / continue

Due parole chiave controllano l'andamento di un ciclo for:

Parola chiaveEffetto
breakinterrompe il ciclo immediatamente, senza eseguire le ripetizioni rimanenti
continuesalta direttamente alla prossima ripetizione, senza eseguire il resto del blocco attuale

Esempio: fermarsi non appena troviamo la prima vendita superiore a R$ 500,00.

for vendita in vendite_del_giorno:
  if vendita > 500:
    print(f'Prima vendita sopra R$ 500: {vendita}')
    break
# Prima vendita sopra R$ 500: 553

Esempio: mostrare solo le vendite con valore pari, saltando le dispari con continue.

for vendita in vendite_del_giorno:
  if vendita % 2 != 0:
    continue
  print(f'Vendita pari: {vendita}')
# Vendita pari: 194
# Vendita pari: 510

Attenzione: qualsiasi codice scritto dopo un break o continue, ancora dentro lo stesso blocco if, non viene mai eseguito — il ciclo è già stato interrotto o è già avanzato prima di arrivarci.

Rivisitando la motivazione

Con for, if e l'accumulo in variabili, risolviamo le due domande della motivazione in un unico ciclo:

vendite_del_giorno = [361, 553, 194, 13, 510, 33, 135]

totale_venduto = 0
quantita_vendite_sopra_300 = 0

for vendita in vendite_del_giorno:
  totale_venduto += vendita
  if vendita > 300:
    quantita_vendite_sopra_300 += 1

print(f'Totale venduto: R$ {totale_venduto:.2f}')
print(f'Vendite sopra R$ 300: {quantita_vendite_sopra_300}')
# Totale venduto: R$ 1799.00
# Vendite sopra R$ 300: 3
