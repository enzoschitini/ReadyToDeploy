La maggior parte dei programmi deve comportarsi in modo diverso a seconda della situazione: approvare o rifiutare un pagamento, concedere o bloccare un accesso, applicare uno sconto o no. Questo comportamento è controllato dal flusso condizionale, e in Python viene scritto con le parole chiave if, elif e else.

Motivazione

Stai sviluppando il sistema di pagamento con carta di credito di un e-commerce. Prima di approvare l'acquisto, il sistema deve confrontare il codice di sicurezza (CVV) fornito dal cliente con il codice registrato in banca.

# Código digitado pelo cliente e código salvo no cadastro
codigo_de_seguranca_informado = '291'
codigo_de_seguranca_cadastro = '010'

Come facciamo eseguire al programma un tratto di codice diverso a seconda che i due codici siano uguali o no?

if / else

La struttura if / else esegue un blocco di codice se una condizione è True, e un altro blocco altrimenti (quando è False):

if condicao:
  # executado quando condicao é True
else:
  # executado quando condicao é False

Attenzione: Python usa l'indentazione (il rientro all'inizio della riga) per sapere cosa appartiene a ciascun blocco. Tutte le righe di uno stesso blocco devono avere lo stesso rientro, altrimenti il codice non viene eseguito.

esta_chovendo = False

if esta_chovendo:
  print('Leve um guarda-chuva')
else:
  print('Não precisa de guarda-chuva')
# Não precisa de guarda-chuva

Applicando al nostro problema: confrontiamo i due codici con == (visto nel Modulo 01) e usiamo il risultato come condizione.

if codigo_de_seguranca_informado == codigo_de_seguranca_cadastro:
  print('Pagamento aprovado')
else:
  print('Erro: código de segurança inválido')
# Erro: código de segurança inválido

Condizioni composte con and / or

Spesso è necessario valutare più di una condizione allo stesso tempo. Per questo, combiniamo gli operatori logici and e or (visti nel Modulo 01) direttamente nella condizione dell'if.

Esempio: oltre al codice di sicurezza, il sistema richiede anche che la password fornita sia corretta. Il pagamento viene approvato solo se entrambe le condizioni sono vere.

codigo_de_seguranca_informado = '852'
codigo_de_seguranca_cadastro = '852'

senha_informada = '7783'
senha_cadastro = '7783'

# Os parênteses em cada comparação deixam a condição mais fácil de ler
if (codigo_de_seguranca_informado == codigo_de_seguranca_cadastro) and (senha_informada == senha_cadastro):
  print('Pagamento aprovado')
else:
  print('Erro: pagamento não autorizado')
# Pagamento aprovado

Puoi trovare anche gli operatori & (e) e | (o) in librerie come Pandas. Nel Python "puro", però, dentro un if, la forma raccomandata e più leggibile è usare and e or.

if / elif / else

Quando esistono più di due possibilità, usiamo elif (abbreviazione di "else if") per concatenare più condizioni. Python testa ogni condizione nell'ordine in cui appare ed esegue il blocco della prima che è vera — ignorando tutte le altre, anche se sono anch'esse vere.

if condicao_1:
  # executado se condicao_1 for True
elif condicao_2:
  # executado se condicao_1 for False e condicao_2 for True
else:
  # executado se nenhuma das anteriores for True

Rivisitando la motivazione

Ora abbiamo tutto per gestire le quattro combinazioni possibili tra codice di sicurezza e password, ognuna con un messaggio diverso:

Codice corretto?Password corretta?Risultato
SìSìPagamento approvato
NoSìErrore: codice di sicurezza non valido
SìNoErrore: password non valida
NoNoErrore: codice di sicurezza e password non validi
 
codigo_de_seguranca_informado = '802'
codigo_de_seguranca_cadastro = '852'

senha_informada = '7703'
senha_cadastro = '7783'

if (codigo_de_seguranca_informado == codigo_de_seguranca_cadastro) and (senha_informada == senha_cadastro):
  print('Pagamento aprovado')
elif (codigo_de_seguranca_informado != codigo_de_seguranca_cadastro) and (senha_informada == senha_cadastro):
  print('Erro: código de segurança inválido')
elif (codigo_de_seguranca_informado == codigo_de_seguranca_cadastro) and (senha_informada != senha_cadastro):
  print('Erro: senha inválida')
else:
  print('Erro: código de segurança e senha inválidos')
# Erro: código de segurança e senha inválidos
