Ogni studente è una persona, ma non ogni persona è uno studente. L'eredità permette alla classe Estudante di riutilizzare tutto ciò che la classe Pessoa già ha, senza copiare codice, e di aggiungere solo ciò che è specifico di uno studente.

Definizione

L'eredità crea una specializzazione di una classe. La classe originale è chiamata classe madre (o superclasse), e la nuova, classe figlia (o sottoclasse). La classe figlia eredita tutti gli attributi e i metodi della madre. La struttura generale è:

class ClasseMae:

    def __init__(self, parametros):
        ...

class ClasseFilha(ClasseMae):

    def __init__(self, parametros):
        super().__init__(parametros_da_mae)
        self.atributo_3 = ...
        self.atributo_4 = ...

    def metodo_3(self, parametros):
        ...
ElementoCosa fa
class ClasseFilha(ClasseMae):Il nome della classe madre tra parentesi indica l'eredità
super()Dà accesso ai metodi della classe madre
super().__init__(...)Esegue il costruttore della madre, che crea gli attributi ereditati

Suggerimento: un buon modo per sapere se l'eredità ha senso è la domanda "è un?": uno studente è una persona? Sì, quindi Estudante può ereditare da Pessoa.

Creando la classe Estudante

Riutilizziamo la classe Pessoa della lezione precedente. Ogni studente studia in un'università, quindi prima creiamo la classe Universidade:

class Universidade:

    def __init__(self, nome: str):
        self.nome = nome

Ora specializziamo la classe Pessoa nella classe Estudante. Il costruttore riceve i dati di una persona più l'università, passa i dati della persona al costruttore della madre con super() e crea l'unico attributo nuovo:

class Estudante(Pessoa):

    def __init__(self, nome: str, idade: int, documento: str, universidade: Universidade):
        # A classe mãe (Pessoa) cria os atributos nome, idade e documento
        super().__init__(nome=nome, idade=idade, documento=documento)
        # Atributo exclusivo de Estudante
        self.universidade = universidade

Attenzione: super().__init__() è obbligatorio quando la classe figlia ha il proprio __init__. Senza di esso, il costruttore della madre non viene eseguito, e gli attributi nome, idade e documento semplicemente non esistono nell'oggetto, generando un AttributeError la prima volta che vengono usati.

Nota un altro dettaglio: l'attributo universidade conserva un oggetto della classe Universidade. Questo è diverso dall'eredità:

Manipolazione

Creiamo gli oggetti nello stesso modo di prima. Prima l'università, poi lo studente, che riceve l'oggetto dell'università come parametro:

usp = Universidade(nome='Universidade de São Paulo')
andre_estudante = Estudante(nome='Andre Perez', idade=30, documento='123', universidade=usp)

La classe Estudante non definisce __str__, falar() né dormir(), ma l'oggetto riesce a usarli tutti, perché sono stati ereditati da Pessoa:

# __str__ herdado de Pessoa
print(andre_estudante)

# Métodos herdados de Pessoa
andre_estudante.falar(texto='Tenho prova amanhã!')
andre_estudante.dormir(horas=2)
# Andre Perez, 30 anos, documento: 123
# Andre Perez diz: Tenho prova amanhã!
# Andre Perez está dormindo... 1h de 2h
# Andre Perez está dormindo... 2h de 2h

Per accedere a un attributo di un oggetto che si trova dentro un altro, concateniamo i punti:

# andre_estudante.universidade é um objeto Universidade; .nome é o atributo dele
print(andre_estudante.universidade.nome)
# Universidade de São Paulo

Uno studente è, allo stesso tempo, un Estudante e una Pessoa. isinstance() conferma ciò, e issubclass() verifica la relazione tra le classi:

print(isinstance(andre_estudante, Estudante))
print(isinstance(andre_estudante, Pessoa))  # True: todo Estudante é uma Pessoa
print(isinstance(andre, Estudante))         # False: nem toda Pessoa é um Estudante

print(issubclass(Estudante, Pessoa))
# True
# True
# False
# True

Nuovi metodi e sovrascrittura

Oltre a ereditare, la classe figlia può:

  • Aggiungere metodi che hanno senso solo per lei (es.: estudar());
  • Sovrascrivere (override) un metodo ereditato, definendo un'altra versione con lo stesso nome. Quando il metodo viene chiamato, Python usa la versione della classe figlia.

Miglioriamo Estudante: __str__ ereditato non menziona l'università. Nella nuova versione, sfruttiamo il testo della madre con super().__str__() e aggiungiamo ciò che manca:

class Estudante(Pessoa):

    def __init__(self, nome: str, idade: int, documento: str, universidade: Universidade):
        super().__init__(nome=nome, idade=idade, documento=documento)
        self.universidade = universidade

    def estudar(self, materia: str) -> None:
        # Método novo, exclusivo de Estudante
        print(f'{self.nome} está estudando {materia} na {self.universidade.nome}')

    def __str__(self) -> str:
        # Sobrescrita: reaproveita o texto da Pessoa e acrescenta a universidade
        return f'{super().__str__()}, estudante da {self.universidade.nome}'

Poiché la classe è stata ridefinita, ricreiamo l'oggetto (ricorda l'avviso della lezione precedente):

andre_estudante = Estudante(nome='Andre Perez', idade=30, documento='123', universidade=usp)

print(andre_estudante)  # usa o __str__ de Estudante
print(andre)            # continua usando o __str__ de Pessoa

andre_estudante.estudar(materia='Programação Orientada a Objetos')
# Andre Perez, 30 anos, documento: 123, estudante da Universidade de São Paulo
# Andre Perez, 30 anos, documento: 123
# Andre Perez está estudando Programação Orientada a Objetos na Universidade de São Paulo

Suggerimento: con l'eredità, un miglioramento fatto nella classe madre arriva automaticamente a tutte le classi figlie. Se domani Pessoa guadagnasse un metodo apresentar(), ogni Estudante lo avrebbe anche lui, senza nessuna riga in più.
