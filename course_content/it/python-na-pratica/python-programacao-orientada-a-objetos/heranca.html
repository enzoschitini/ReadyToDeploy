Ogni studente è una persona, ma non ogni persona è uno studente. L'eredità permette alla classe Studente di riutilizzare tutto ciò che la classe Persona già ha, senza copiare codice, e di aggiungere solo ciò che è specifico di uno studente.

Definizione

L'eredità crea una specializzazione di una classe. La classe originale è chiamata classe madre (o superclasse), e la nuova, classe figlia (o sottoclasse). La classe figlia eredita tutti gli attributi e i metodi della madre. La struttura generale è:

class ClasseMadre:

    def __init__(self, parametri):
        ...

class ClasseFiglia(ClasseMadre):

    def __init__(self, parametri):
        super().__init__(parametri_della_madre)
        self.attributo_3 = ...
        self.attributo_4 = ...

    def metodo_3(self, parametri):
        ...

super()Dà accesso ai metodi della classe madre
super().__init__(...)Esegue il costruttore della madre, che crea gli attributi ereditati

Suggerimento: un buon modo per sapere se l'eredità ha senso è la domanda "è un?": uno studente è una persona? Sì, quindi Studente può ereditare da Persona.

Creando la classe Studente

Riutilizziamo la classe Persona della lezione precedente. Ogni studente studia in un'università, quindi prima creiamo la classe Universita:

class Universita:

    def __init__(self, nome: str):
        self.nome = nome

Ora specializziamo la classe Persona nella classe Studente. Il costruttore riceve i dati di una persona più l'università, passa i dati della persona al costruttore della madre con super() e crea l'unico attributo nuovo:

class Studente(Persona):

    def __init__(self, nome: str, eta: int, documento: str, universita: Universita):
        # La classe madre (Persona) crea gli attributi nome, eta e documento
        super().__init__(nome=nome, eta=eta, documento=documento)
        # Attributo esclusivo di Studente
        self.universita = universita

Attenzione: super().__init__() è obbligatorio quando la classe figlia ha il proprio __init__. Senza di esso, il costruttore della madre non viene eseguito, e gli attributi nome, eta e documento semplicemente non esistono nell'oggetto, generando un AttributeError la prima volta che vengono usati.

Nota un altro dettaglio: l'attributo universita conserva un oggetto della classe Universita. Questo è diverso dall'eredità:

Manipolazione

Creiamo gli oggetti nello stesso modo di prima. Prima l'università, poi lo studente, che riceve l'oggetto dell'università come parametro:

usp = Universita(nome='Universidade de São Paulo')
andre_studente = Studente(nome='Andre Perez', eta=30, documento='123', universita=usp)

La classe Studente non definisce __str__, parlare() né dormire(), ma l'oggetto riesce a usarli tutti, perché sono stati ereditati da Persona:

# __str__ ereditato da Persona
print(andre_studente)

# Metodi ereditati da Persona
andre_studente.parlare(testo='Ho un esame domani!')
andre_studente.dormire(ore=2)
# Andre Perez, 30 anni, documento: 123
# Andre Perez dice: Ho un esame domani!
# Andre Perez sta dormendo... 1h di 2h
# Andre Perez sta dormendo... 2h di 2h

Per accedere a un attributo di un oggetto che si trova dentro un altro, concateniamo i punti:

# andre_studente.universita è un oggetto Universita; .nome è il suo attributo
print(andre_studente.universita.nome)
# Universidade de São Paulo

Uno studente è, allo stesso tempo, uno Studente e una Persona. isinstance() conferma ciò, e issubclass() verifica la relazione tra le classi:

print(isinstance(andre_studente, Studente))
print(isinstance(andre_studente, Persona))  # True: ogni Studente è una Persona
print(isinstance(andre, Studente))          # False: non ogni Persona è uno Studente

print(issubclass(Studente, Persona))
# True
# True
# False
# True

Nuovi metodi e sovrascrittura

Oltre a ereditare, la classe figlia può:

  • Aggiungere metodi che hanno senso solo per lei (es.: studiare());
  • Sovrascrivere (override) un metodo ereditato, definendo un'altra versione con lo stesso nome. Quando il metodo viene chiamato, Python usa la versione della classe figlia.

Miglioriamo Studente: __str__ ereditato non menziona l'università. Nella nuova versione, sfruttiamo il testo della madre con super().__str__() e aggiungiamo ciò che manca:

class Studente(Persona):

    def __init__(self, nome: str, eta: int, documento: str, universita: Universita):
        super().__init__(nome=nome, eta=eta, documento=documento)
        self.universita = universita

    def studiare(self, materia: str) -> None:
        # Metodo nuovo, esclusivo di Studente
        print(f'{self.nome} sta studiando {materia} presso {self.universita.nome}')

    def __str__(self) -> str:
        # Sovrascrittura: riutilizza il testo di Persona e aggiunge l'università
        return f'{super().__str__()}, studente presso {self.universita.nome}'

Poiché la classe è stata ridefinita, ricreiamo l'oggetto (ricorda l'avviso della lezione precedente):

andre_studente = Studente(nome='Andre Perez', eta=30, documento='123', universita=usp)

print(andre_studente)  # usa il __str__ di Studente
print(andre)           # continua a usare il __str__ di Persona

andre_studente.studiare(materia='Programmazione Orientata agli Oggetti')
# Andre Perez, 30 anni, documento: 123, studente presso Universidade de São Paulo
# Andre Perez, 30 anni, documento: 123
# Andre Perez sta studiando Programmazione Orientata agli Oggetti presso Universidade de São Paulo

Suggerimento: con l'eredità, un miglioramento fatto nella classe madre arriva automaticamente a tutte le classi figlie. Se domani Persona guadagnasse un metodo presentare(), ogni Studente lo avrebbe anche lui, senza nessuna riga in più.
