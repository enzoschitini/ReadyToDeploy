Le classi sono il punto di partenza dell'orientamento agli oggetti: è in esse che definiamo quali dati e quali comportamenti avrà un tipo di elemento. In questa lezione costruiremo, passo dopo passo, la classe Persona.

Motivazione

Lavori nel sistema di registrazione di una banca e devi conservare i dati di vari clienti. Con quanto visto finora, un'opzione sarebbe usare variabili sciolte:

# Ogni informazione di ogni cliente in una variabile diversa
nome_cliente_1 = 'Andre Perez'
eta_cliente_1 = 30

nome_cliente_2 = 'Maria Perez'
eta_cliente_2 = 56

print(f'{nome_cliente_1}, {eta_cliente_1} anni')
print(f'{nome_cliente_2}, {eta_cliente_2} anni')
# Andre Perez, 30 anni
# Maria Perez, 56 anni

Con 2 clienti funziona. Ma con 2 mila? E quando ogni cliente avrà 15 informazioni? E se ogni regola del sistema (fare gli auguri di compleanno, validare il documento, mostrare i dati) dovesse ricevere tutte queste variabili come parametro? Il codice diventa ripetitivo e facile da rompere.

Come possiamo raggruppare i dati di un cliente e le azioni che hanno senso per lui in un'unica struttura?

Definizione

Una classe è una ricetta per la creazione di oggetti. La struttura generale è:

class NomeDellaClasse:

    def __init__(self, parametri):
        self.attributo_1 = ...
        self.attributo_2 = ...

    def metodo_1(self, parametri):
        ...

    def metodo_2(self, parametri):
        ...

Alcuni punti importanti di questa struttura:

  • La parola riservata class inizia la definizione della classe;
  • Per convenzione (PEP 8), i nomi di classe usano il PascalCase: ogni parola inizia con lettera maiuscola e non c'è _ (es.: Persona, ContoBancario, FileCSV). Variabili e funzioni restano in snake_case;
  • Tutto ciò che appartiene alla classe resta indentato al suo interno (4 spazi).

Creiamo la versione più semplice possibile della classe Persona. La parola pass indica un blocco vuoto: la classe esiste, ma non fa ancora nulla.

class Persona:
    pass


print(Persona)
# <class '__main__.Persona'>

Suggerimento: in codici più vecchi troverai class Persona(object):. In Python 3, ogni classe eredita già da object automaticamente (vedremo l'eredità nell'ultima lezione), quindi class Persona: è equivalente ed è la forma raccomandata oggi.

Attributi

Gli attributi rappresentano le caratteristiche della classe. Vengono creati dentro un metodo speciale chiamato __init__ (da initialize, "inizializzare"), che Python esegue automaticamente ogni volta che viene creato un nuovo oggetto. È conosciuto come il costruttore della classe.

Due dettagli che spesso confondono all'inizio:

ElementoCos'è
selfUn riferimento all'oggetto stesso che viene creato. Ogni metodo della classe riceve self come primo parametro
self.nome = nomeCrea l'attributo nome nell'oggetto e vi conserva il valore ricevuto nel parametro nome
 
class Persona:

    def __init__(self, nome: str, eta: int, documento: str):
        # Ogni self.attributo resta conservato dentro l'oggetto
        self.nome = nome
        self.eta = eta
        self.documento = documento

Suggerimento: le annotazioni : str e : int sono indicazioni di tipo (type hints). Documentano che tipo di valore ogni parametro si aspetta e aiutano l'editor a segnalare errori, ma Python non le impone: sono solo documentazione.

Come nelle funzioni, i parametri di __init__ possono avere valori predefiniti. Non tutte le persone forniscono il documento nella registrazione, quindi lo lasceremo opzionale, con valore None:

class Persona:

    def __init__(self, nome: str, eta: int, documento: str = None):
        self.nome = nome
        self.eta = eta
        self.documento = documento  # None quando non viene indicato

Metodi

I metodi rappresentano le azioni della classe. Sono funzioni definite dentro la classe e, per questo, ricevono sempre self come primo parametro. È tramite self che un metodo accede (e altera) gli attributi dell'oggetto stesso.

In questa versione, Persona guadagna tre azioni:

MetodoCosa fa
dormire(ore)Mostra il progresso del sonno, ora per ora
parlare(testo)Mostra una frase della persona
fare_compleanno()Altera l'attributo eta, sommando 1
 
class Persona:

    def __init__(self, nome: str, eta: int, documento: str = None):
        self.nome = nome
        self.eta = eta
        self.documento = documento

    def dormire(self, ore: int) -> None:
        # self.nome: il metodo accede a un attributo dell'oggetto stesso
        for ora in range(1, ore + 1):
            print(f'{self.nome} sta dormendo... {ora}h di {ore}h')

    def parlare(self, testo: str) -> None:
        print(f'{self.nome} dice: {testo}')

    def fare_compleanno(self) -> None:
        # Un metodo può anche ALTERARE lo stato dell'oggetto
        self.eta += 1
        print(f'Auguri, {self.nome}! Ora hai {self.eta} anni.')

Suggerimento: l'annotazione -> None indica che il metodo non restituisce alcun valore (mostra solo qualcosa o altera l'oggetto). Un metodo che restituisce un testo sarebbe annotato con -> str.

Il metodo speciale __str__

I metodi il cui nome inizia e termina con due underscore (come __init__) sono metodi speciali (chiamati anche dunder methods, da double underscore). Python li chiama automaticamente in situazioni specifiche.

Uno dei più utili è __str__, chiamato quando l'oggetto viene convertito in testo, per esempio dentro un print(). Guarda cosa succede quando stampiamo un oggetto della classe attuale, che non ha ancora __str__:

# Senza __str__, Python mostra solo la classe e l'indirizzo di memoria dell'oggetto
persona_test = Persona(nome='Andre Perez', eta=30)
print(persona_test)
# <__main__.Persona object at 0x0000028E2A2A7740>

Poco utile, vero? Aggiungiamo __str__ alla classe. Deve restituire (e non stampare) una stringa che descriva l'oggetto. Questa è la versione finale della classe Persona, che useremo nel resto del modulo:

class Persona:

    def __init__(self, nome: str, eta: int, documento: str = None):
        self.nome = nome
        self.eta = eta
        self.documento = documento

    def dormire(self, ore: int) -> None:
        for ora in range(1, ore + 1):
            print(f'{self.nome} sta dormendo... {ora}h di {ore}h')

    def parlare(self, testo: str) -> None:
        print(f'{self.nome} dice: {testo}')

    def fare_compleanno(self) -> None:
        self.eta += 1
        print(f'Auguri, {self.nome}! Ora hai {self.eta} anni.')

    def __str__(self) -> str:
        # Evita di mostrare "None" quando il documento non è stato indicato
        if self.documento is None:
            documento_mostrato = 'non indicato'
        else:
            documento_mostrato = self.documento
        return f'{self.nome}, {self.eta} anni, documento: {documento_mostrato}'

# Ora print() usa il __str__ e mostra una descrizione leggibile
persona_test = Persona(nome='Andre Perez', eta=30)
print(persona_test)
# Andre Perez, 30 anni, documento: non indicato

Attenzione: ogni volta che modifichi una classe, è necessario eseguire di nuovo la cella che la definisce e ricreare gli oggetti. Gli oggetti creati prima continuano a seguire la versione precedente della classe.
