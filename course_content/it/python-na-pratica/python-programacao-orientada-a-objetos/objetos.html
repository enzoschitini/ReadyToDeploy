Una classe da sola è solo una ricetta: chi effettivamente conserva dati ed esegue azioni sono gli oggetti. In questa lezione creeremo oggetti, accederemo e altereremo i loro attributi, chiameremo i loro metodi e applicheremo tutto questo in un esempio reale di lettura di file.

Definizione

Un oggetto è un'istanza di una classe. Per crearlo, "chiamiamo" la classe come se fosse una funzione, passando i parametri di __init__ (senza self, che Python riempie da solo). Successivamente, usiamo il punto (.) per accedere ad attributi e metodi:

objeto = NomeDaClasse(parametros)

objeto.atributo    # acessa uma característica
objeto.metodo()    # executa uma ação

# Três objetos criados a partir da mesma classe, cada um com seus próprios dados
andre = Pessoa(nome='Andre Perez', idade=30, documento='123')
maria = Pessoa(nome='Maria Perez', idade=56, documento='456')
pedro = Pessoa(nome='Pedro Perez', idade=8)  # sem documento: usa o valor padrão None

print(andre)
print(maria)
print(pedro)
# Andre Perez, 30 anos, documento: 123
# Maria Perez, 56 anos, documento: 456
# Pedro Perez, 8 anos, documento: não informado

Possiamo confermare a quale classe appartiene un oggetto con type() o, più comunemente nella pratica quotidiana, con isinstance(), che risponde con un booleano:

print(type(andre))
print(isinstance(andre, Pessoa))
print(isinstance('Andre Perez', Pessoa))  # uma string não é uma Pessoa
# <class '__main__.Pessoa'>
# True
# False

Manipolando gli attributi

Un attributo funziona come una variabile che "vive" dentro l'oggetto: possiamo leggere il valore, usarlo in calcoli e funzioni e anche alterarlo.

# Lendo atributos
print(andre.nome)
print(andre.idade)
# Andre Perez
# 30

Esempio: usando un attributo come argomento di una funzione comune.

def maior_de_idade(idade: int) -> bool:
    return idade >= 18


# Passamos apenas o atributo idade de cada objeto para a função
for pessoa in [andre, maria, pedro]:
    if maior_de_idade(idade=pessoa.idade):
        print(f'{pessoa.nome} é maior de idade')
    else:
        print(f'{pessoa.nome} é menor de idade')
# Andre Perez é maior de idade
# Maria Perez é maior de idade
# Pedro Perez é menor de idade

Esempio: consultando il punteggio di credito di un cliente a partire dal documento. Il documento dell'oggetto serve da chiave per cercare il valore in un dizionario:

# Score de crédito de cada cliente, indexado pelo número do documento
score_credito = {'123': 750, '456': 812, '789': 327}

score_andre = score_credito[andre.documento]
print(f'Score de {andre.nome}: {score_andre}')
# Score de Andre Perez: 750

Attenzione: pedro è stato creato senza documento (None), quindi score_credito[pedro.documento] genererebbe un KeyError. Con il metodo .get() del dizionario, possiamo definire un valore predefinito per quando la chiave non esiste.

# score_pedro = score_credito[pedro.documento]           # KeyError: None
score_pedro = score_credito.get(pedro.documento, 'sem score')  # valor padrão

print(f'Score de {pedro.nome}: {score_pedro}')
# Score de Pedro Perez: sem score

Possiamo anche alterare un attributo direttamente, con un'assegnazione comune. Il cambiamento vale solo per quell'oggetto:

# Pedro trouxe o documento: atualizamos só o objeto pedro
pedro.documento = '789'

print(pedro)
print(andre)  # andre não foi afetado
# Pedro Perez, 8 anos, documento: 789
# Andre Perez, 30 anos, documento: 123

Chiamando metodi

I metodi vengono chiamati con la sintassi objeto.metodo(argumentos). Nota che non passiamo self: Python capisce che self è l'oggetto che viene prima del punto.

# O self dentro de dormir() é o próprio andre
andre.dormir(horas=3)
# Andre Perez está dormindo... 1h de 3h
# Andre Perez está dormindo... 2h de 3h
# Andre Perez está dormindo... 3h de 3h

andre.falar(texto='Olá, pessoal!')
maria.falar(texto='Bom dia!')
# Andre Perez diz: Olá, pessoal!
# Maria Perez diz: Bom dia!

Il metodo fazer_aniversario() altera lo stato dell'oggetto. Osserva l'età prima e dopo:

print(maria)

maria.fazer_aniversario()

print(maria)
# Maria Perez, 56 anos, documento: 456
# Parabéns, Maria Perez! Agora você tem 57 anos.
# Maria Perez, 57 anos, documento: 456

Attenzione: per eseguire un metodo è obbligatorio usare le parentesi. Scrivere maria.fazer_aniversario (senza ()) non genera errore, ma non esegue nulla: fa solo riferimento al metodo.

Rivisitando la motivazione

Ricordi la registrazione dei clienti della lezione precedente? Con la classe Pessoa, ogni cliente diventa un unico oggetto che porta con sé i propri dati e le proprie azioni. Conservando gli oggetti in una lista, registrare 3 o 3 mila clienti richiede lo stesso codice:

clientes = [
    Pessoa(nome='Andre Perez', idade=30, documento='123'),
    Pessoa(nome='Maria Perez', idade=56, documento='456'),
    Pessoa(nome='Pedro Perez', idade=8),
]

# Uma única regra aplicada a todos os clientes
for cliente in clientes:
    print(cliente)
# Andre Perez, 30 anos, documento: 123
# Maria Perez, 56 anos, documento: 456
# Pedro Perez, 8 anos, documento: não informado

# Virada de ano: todos os clientes fazem aniversário
for cliente in clientes:
    cliente.fazer_aniversario()
# Parabéns, Andre Perez! Agora você tem 31 anos.
# Parabéns, Maria Perez! Agora você tem 57 anos.
# Parabéns, Pedro Perez! Agora você tem 9 anos.

Nessuna variabile sciolta, nessuna funzione che riceve decine di parametri: ogni oggetto sa gestire i propri dati.

Tutto in Python è un oggetto

Usi oggetti fin dal primo modulo, forse senza accorgertene. Numeri, testi, liste, dizionari e persino funzioni sono oggetti di qualche classe nativa di Python. La funzione type() mostra la classe di ciascuno:

tipos = [
    type(10),
    type(1.1),
    type('Ready To Deploy'),
    type(True),
    type(None),
    type([1, 2, 3]),
    type({1, 2, 3}),
    type({'janeiro': 1}),
    type(lambda x: x),
]

for tipo in tipos:
    print(tipo)
# <class 'int'>
# <class 'float'>
# <class 'str'>
# <class 'bool'>
# <class 'NoneType'>
# <class 'list'>
# <class 'set'>
# <class 'dict'>
# <class 'function'>

Nota il <class '...'> in ogni riga: int, str, list e gli altri sono classi. Per questo hanno metodi, che chiamiamo esattamente come abbiamo fatto con Pessoa:

# nome é um objeto da classe str, e upper() é um método dessa classe
nome = 'Andre Perez'
print(nome.upper())
# ANDRE PEREZ

# juros é um objeto da classe list, e pop() é um método dessa classe
juros = [0.02, 0.07, 0.15]

juro_removido = juros.pop(1)  # remove e retorna o item da posição 1
print(juro_removido)
print(juros)
# 0.07
# [0.02, 0.15]

Revisione: strip() e split()

Nel prossimo esempio leggeremo un file CSV riga per riga. Per questo, due metodi delle string saranno fondamentali:

MetodoCosa faEsempioRisultato
.strip()Rimuove spazi e interruzioni di riga (\n) dall'inizio e dalla fine' banana \n'.strip()'banana'
.strip(caracteres)Rimuove i caratteri indicati dall'inizio e dalla fine'..banana..'.strip('.')'banana'
.split(separador)Divide il testo in una lista a ogni separatore'a,b,c'.split(',')['a', 'b', 'c']
 
# strip() sem argumentos: remove espaços e quebras de linha das pontas
fruta = ' banana \n'
print(fruta.strip())
# banana

# strip(caracteres): remove QUALQUER um dos caracteres informados, só nas pontas
fruta = ',,,,,rrttgg.....banana....rrr'
print(fruta.strip(',.grt'))
# banana

# Combinando os dois: primeiro limpamos as pontas, depois dividimos
frase = ' O gato pulou sobre o muro '
palavras = frase.strip().split()  # sem argumento, split() divide nos espaços
print(palavras)
# ['O', 'gato', 'pulou', 'sobre', 'o', 'muro']

# Uma linha típica de arquivo CSV: valores separados por vírgula e um \n no final
linha_csv = '30,unemployed,married,primary\n'
valores = linha_csv.strip().split(',')
print(valores)
# ['30', 'unemployed', 'married', 'primary']

Esempio pratico: classe ArquivoCSV

I file CSV (Comma-Separated Values) sono tabelle in formato testo: ogni riga è un record e i valori sono separati da virgola. La prima riga di solito porta il nome delle colonne.

Creeremo una classe che legge un CSV con dati di clienti di una banca e permette di estrarre qualsiasi colonna. Prima creiamo il file banco.csv:

conteudo_csv = '''age,job,marital,education,default,balance,housing,loan
30,unemployed,married,primary,no,1787,no,no
33,services,married,secondary,no,4789,yes,yes
35,management,single,tertiary,no,1350,yes,no
30,management,married,tertiary,no,1476,yes,yes
59,blue-collar,married,secondary,no,0,yes,no
35,management,single,tertiary,no,747,no,no
36,self-employed,married,tertiary,no,307,yes,no
39,technician,married,secondary,no,147,yes,no
41,entrepreneur,married,tertiary,no,221,yes,no
43,services,married,primary,no,-88,yes,yes'''

# Gravando o texto em um arquivo no ambiente atual
with open('banco.csv', mode='w', encoding='utf8') as arquivo:
    arquivo.write(conteudo_csv)

Suggerimento: in Colab troverai anche il comando magico %%writefile banco.csv sulla prima riga di una cella, che salva il contenuto della cella in un file. Qui usiamo open() perché funziona in qualsiasi ambiente Python.

Ora, la classe. Avrà due tipi di metodo:

MetodoTipoCosa fa
_extrair_conteudo()InternoLegge il file e restituisce la lista delle righe
_extrair_nome_colunas()InternoRestituisce i nomi delle colonne (la prima riga)
extrair_coluna(indice_coluna)PubblicoRestituisce i valori di una colonna a partire dalla sua posizione
extrair_coluna_por_nome(nome_coluna)PubblicoRestituisce i valori di una colonna a partire dal suo nome

Il _ all'inizio del nome è una convenzione di Python per indicare che un metodo è a uso interno della classe: esiste per aiutare gli altri metodi, e non per essere chiamato dall'esterno.

class ArquivoCSV:

    def __init__(self, caminho_arquivo: str):
        self.caminho_arquivo = caminho_arquivo
        # O próprio construtor já lê o arquivo e descobre as colunas
        self.conteudo = self._extrair_conteudo()
        self.colunas = self._extrair_nome_colunas()

    def _extrair_conteudo(self) -> list:
        with open(self.caminho_arquivo, mode='r', encoding='utf8') as arquivo:
            return arquivo.readlines()

    def _extrair_nome_colunas(self) -> list:
        # A primeira linha do arquivo é o cabeçalho
        return self.conteudo[0].strip().split(',')

    def extrair_coluna(self, indice_coluna: int) -> list:
        coluna = []
        # [1:] pula a primeira linha, pois o cabeçalho não é um dado
        for linha in self.conteudo[1:]:
            valores_linha = linha.strip().split(',')
            coluna.append(valores_linha[indice_coluna])
        return coluna

    def extrair_coluna_por_nome(self, nome_coluna: str) -> list:
        # Um método pode chamar outro método do mesmo objeto via self
        indice_coluna = self.colunas.index(nome_coluna)
        return self.extrair_coluna(indice_coluna=indice_coluna)

Alla creazione dell'oggetto, __init__ legge già il file e popola gli attributi conteudo e colunas:

arquivo_banco = ArquivoCSV(caminho_arquivo='banco.csv')

print(arquivo_banco.colunas)
# ['age', 'job', 'marital', 'education', 'default', 'balance', 'housing', 'loan']

# Cada item do atributo conteudo é uma linha do arquivo (repare no \n no final)
print(arquivo_banco.conteudo[:3])
# ['age,job,marital,education,default,balance,housing,loan\n', '30,unemployed,married,primary,no,1787,no,no\n', '33,services,married,secondary,no,4789,yes,yes\n']

Esempio: estraendo la colonna job (professione), che è nella posizione 1.

profissoes = arquivo_banco.extrair_coluna(indice_coluna=1)
print(profissoes)
# ['unemployed', 'services', 'management', 'management', 'blue-collar', 'management', 'self-employed', 'technician', 'entrepreneur', 'services']

Esempio: estraendo la colonna education (istruzione), che è nella posizione 3.

escolaridades = arquivo_banco.extrair_coluna(indice_coluna=3)
print(escolaridades)
# ['primary', 'secondary', 'tertiary', 'tertiary', 'secondary', 'tertiary', 'tertiary', 'secondary', 'tertiary', 'primary']

Esempio: ricordare a memoria la posizione di ogni colonna è faticoso e facile da sbagliare. Con extrair_coluna_por_nome(), basta indicare il nome:

estados_civis = arquivo_banco.extrair_coluna_por_nome(nome_coluna='marital')
print(estados_civis)

# O resultado é uma lista comum, então podemos usar os métodos de lista
print(f"Clientes casados: {estados_civis.count('married')}")
# ['married', 'married', 'single', 'married', 'married', 'single', 'married', 'married', 'married', 'married']
# Clientes casados: 8

Esempio: i valori letti da un file di testo sono sempre string. Per fare calcoli, convertiamo ogni valore. Qui calcoliamo il saldo medio (balance) dei clienti:

saldos_texto = arquivo_banco.extrair_coluna_por_nome(nome_coluna='balance')

# Convertendo cada saldo de str para int
saldos = []
for saldo in saldos_texto:
    saldos.append(int(saldo))

saldo_medio = sum(saldos) / len(saldos)
print(f'Saldo médio: {saldo_medio:.2f}')
# Saldo médio: 1073.60

Attenzione: Python non impedisce di chiamare arquivo_banco._extrair_conteudo() dall'esterno della classe, ma questo va contro la convenzione del _. I metodi interni possono cambiare o smettere di esistere in versioni future della classe; usa sempre gli attributi e i metodi pubblici.
