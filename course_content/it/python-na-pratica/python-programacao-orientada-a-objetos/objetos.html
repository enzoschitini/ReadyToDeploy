Una classe da sola è solo una ricetta: chi effettivamente conserva dati ed esegue azioni sono gli oggetti. In questa lezione creeremo oggetti, accederemo e altereremo i loro attributi, chiameremo i loro metodi e applicheremo tutto questo in un esempio reale di lettura di file.

Definizione

Un oggetto è un'istanza di una classe. Per crearlo, "chiamiamo" la classe come se fosse una funzione, passando i parametri di __init__ (senza self, che Python riempie da solo). Successivamente, usiamo il punto (.) per accedere ad attributi e metodi:

oggetto = NomeDellaClasse(parametri)

oggetto.attributo    # accede a una caratteristica
oggetto.metodo()     # esegue un'azione

# Tre oggetti creati a partire dalla stessa classe, ognuno con i propri dati
andre = Persona(nome='Andre Perez', eta=30, documento='123')
maria = Persona(nome='Maria Perez', eta=56, documento='456')
pedro = Persona(nome='Pedro Perez', eta=8)  # senza documento: usa il valore predefinito None

print(andre)
print(maria)
print(pedro)
# Andre Perez, 30 anni, documento: 123
# Maria Perez, 56 anni, documento: 456
# Pedro Perez, 8 anni, documento: non indicato

Possiamo confermare a quale classe appartiene un oggetto con type() o, più comunemente nella pratica quotidiana, con isinstance(), che risponde con un booleano:

print(type(andre))
print(isinstance(andre, Persona))
print(isinstance('Andre Perez', Persona))  # una stringa non è una Persona
# <class '__main__.Persona'>
# True
# False

Manipolando gli attributi

Un attributo funziona come una variabile che "vive" dentro l'oggetto: possiamo leggere il valore, usarlo in calcoli e funzioni e anche alterarlo.

# Leggendo attributi
print(andre.nome)
print(andre.eta)
# Andre Perez
# 30

Esempio: usando un attributo come argomento di una funzione comune.

def e_maggiorenne(eta: int) -> bool:
    return eta >= 18


# Passiamo solo l'attributo eta di ogni oggetto alla funzione
for persona in [andre, maria, pedro]:
    if e_maggiorenne(eta=persona.eta):
        print(f'{persona.nome} è maggiorenne')
    else:
        print(f'{persona.nome} è minorenne')
# Andre Perez è maggiorenne
# Maria Perez è maggiorenne
# Pedro Perez è minorenne

Esempio: consultando il punteggio di credito di un cliente a partire dal documento. Il documento dell'oggetto serve da chiave per cercare il valore in un dizionario:

# Punteggio di credito di ogni cliente, indicizzato dal numero di documento
punteggio_credito = {'123': 750, '456': 812, '789': 327}

punteggio_andre = punteggio_credito[andre.documento]
print(f'Punteggio di {andre.nome}: {punteggio_andre}')
# Punteggio di Andre Perez: 750

Attenzione: pedro è stato creato senza documento (None), quindi punteggio_credito[pedro.documento] genererebbe un KeyError. Con il metodo .get() del dizionario, possiamo definire un valore predefinito per quando la chiave non esiste.

# punteggio_pedro = punteggio_credito[pedro.documento]              # KeyError: None
punteggio_pedro = punteggio_credito.get(pedro.documento, 'senza punteggio')  # valore predefinito

print(f'Punteggio di {pedro.nome}: {punteggio_pedro}')
# Punteggio di Pedro Perez: senza punteggio

Possiamo anche alterare un attributo direttamente, con un'assegnazione comune. Il cambiamento vale solo per quell'oggetto:

# Pedro ha portato il documento: aggiorniamo solo l'oggetto pedro
pedro.documento = '789'

print(pedro)
print(andre)  # andre non è stato modificato
# Pedro Perez, 8 anni, documento: 789
# Andre Perez, 30 anni, documento: 123

Chiamando metodi

I metodi vengono chiamati con la sintassi objeto.metodo(argumentos). Nota che non passiamo self: Python capisce che self è l'oggetto che viene prima del punto.

# Il self dentro dormire() è lo stesso andre
andre.dormire(ore=3)
# Andre Perez sta dormendo... 1h di 3h
# Andre Perez sta dormendo... 2h di 3h
# Andre Perez sta dormendo... 3h di 3h

andre.parlare(testo='Ciao a tutti!')
maria.parlare(testo='Buongiorno!')
# Andre Perez dice: Ciao a tutti!
# Maria Perez dice: Buongiorno!

Il metodo fare_compleanno() altera lo stato dell'oggetto. Osserva l'età prima e dopo:

print(maria)

maria.fare_compleanno()

print(maria)
# Maria Perez, 56 anni, documento: 456
# Auguri, Maria Perez! Ora hai 57 anni.
# Maria Perez, 57 anni, documento: 456

Attenzione: per eseguire un metodo è obbligatorio usare le parentesi. Scrivere maria.fare_compleanno (senza ()) non genera errore, ma non esegue nulla: fa solo riferimento al metodo.

Rivisitando la motivazione

Ricordi la registrazione dei clienti della lezione precedente? Con la classe Persona, ogni cliente diventa un unico oggetto che porta con sé i propri dati e le proprie azioni. Conservando gli oggetti in una lista, registrare 3 o 3 mila clienti richiede lo stesso codice:

clienti = [
    Persona(nome='Andre Perez', eta=30, documento='123'),
    Persona(nome='Maria Perez', eta=56, documento='456'),
    Persona(nome='Pedro Perez', eta=8),
]

# Un'unica regola applicata a tutti i clienti
for cliente in clienti:
    print(cliente)
# Andre Perez, 30 anni, documento: 123
# Maria Perez, 56 anni, documento: 456
# Pedro Perez, 8 anni, documento: non indicato

# Cambio d'anno: tutti i clienti festeggiano il compleanno
for cliente in clienti:
    cliente.fare_compleanno()
# Auguri, Andre Perez! Ora hai 31 anni.
# Auguri, Maria Perez! Ora hai 57 anni.
# Auguri, Pedro Perez! Ora hai 9 anni.

Nessuna variabile sciolta, nessuna funzione che riceve decine di parametri: ogni oggetto sa gestire i propri dati.

Tutto in Python è un oggetto

Usi oggetti fin dal primo modulo, forse senza accorgertene. Numeri, testi, liste, dizionari e persino funzioni sono oggetti di qualche classe nativa di Python. La funzione type() mostra la classe di ciascuno:

tipos = [
    type(10),
    type(1.1),
    type('Ready To Deploy'),
    type(True),
    type(None),
    type([1, 2, 3]),
    type({1, 2, 3}),
    type({'janeiro': 1}),
    type(lambda x: x),
]

for tipo in tipos:
    print(tipo)
# <class 'int'>
# <class 'float'>
# <class 'str'>
# <class 'bool'>
# <class 'NoneType'>
# <class 'list'>
# <class 'set'>
# <class 'dict'>
# <class 'function'>

Nota il <class '...'> in ogni riga: int, str, list e gli altri sono classi. Per questo hanno metodi, che chiamiamo esattamente come abbiamo fatto con Persona:

# nome è un oggetto della classe str, e upper() è un metodo di quella classe
nome = 'Andre Perez'
print(nome.upper())
# ANDRE PEREZ

# interessi è un oggetto della classe list, e pop() è un metodo di quella classe
interessi = [0.02, 0.07, 0.15]

interesse_rimosso = interessi.pop(1)  # rimuove e restituisce l'elemento in posizione 1
print(interesse_rimosso)
print(interessi)
# 0.07
# [0.02, 0.15]

Revisione: strip() e split()

Nel prossimo esempio leggeremo un file CSV riga per riga. Per questo, due metodi delle string saranno fondamentali:

MetodoCosa faEsempioRisultato
.strip()Rimuove spazi e interruzioni di riga (\n) dall'inizio e dalla fine' banana \n'.strip()'banana'
.strip(caracteres)Rimuove i caratteri indicati dall'inizio e dalla fine'..banana..'.strip('.')'banana'
.split(separador)Divide il testo in una lista a ogni separatore'a,b,c'.split(',')['a', 'b', 'c']
 
# strip() senza argomenti: rimuove spazi e interruzioni di riga dalle estremità
frutto = ' banana \n'
print(frutto.strip())
# banana

# strip(caratteri): rimuove QUALSIASI dei caratteri indicati, solo alle estremità
frutto = ',,,,,rrttgg.....banana....rrr'
print(frutto.strip(',.grt'))
# banana

# Combinando i due: prima puliamo le estremità, poi dividiamo
frase = ' Il gatto è saltato sopra il muro '
parole = frase.strip().split()  # senza argomento, split() divide sugli spazi
print(parole)
# ['Il', 'gatto', 'è', 'saltato', 'sopra', 'il', 'muro']

# Una riga tipica di un file CSV: valori separati da virgola e un \n alla fine
riga_csv = '30,unemployed,married,primary\n'
valori = riga_csv.strip().split(',')
print(valori)
# ['30', 'unemployed', 'married', 'primary']

Esempio pratico: classe FileCSV

I file CSV (Comma-Separated Values) sono tabelle in formato testo: ogni riga è un record e i valori sono separati da virgola. La prima riga di solito porta il nome delle colonne.

Creeremo una classe che legge un CSV con dati di clienti di una banca e permette di estrarre qualsiasi colonna. Prima creiamo il file banca.csv:

contenuto_csv = '''age,job,marital,education,default,balance,housing,loan
30,unemployed,married,primary,no,1787,no,no
33,services,married,secondary,no,4789,yes,yes
35,management,single,tertiary,no,1350,yes,no
30,management,married,tertiary,no,1476,yes,yes
59,blue-collar,married,secondary,no,0,yes,no
35,management,single,tertiary,no,747,no,no
36,self-employed,married,tertiary,no,307,yes,no
39,technician,married,secondary,no,147,yes,no
41,entrepreneur,married,tertiary,no,221,yes,no
43,services,married,primary,no,-88,yes,yes'''

# Salviamo il testo in un file nell'ambiente attuale
with open('banca.csv', mode='w', encoding='utf8') as file:
    file.write(contenuto_csv)

Suggerimento: in Colab troverai anche il comando magico %%writefile banca.csv sulla prima riga di una cella, che salva il contenuto della cella in un file. Qui usiamo open() perché funziona in qualsiasi ambiente Python.

Ora, la classe. Avrà due tipi di metodo:

MetodoTipoCosa fa
_estrai_contenuto()InternoLegge il file e restituisce la lista delle righe
_estrai_nome_colonne()InternoRestituisce i nomi delle colonne (la prima riga)
estrai_colonna(indice_colonna)PubblicoRestituisce i valori di una colonna a partire dalla sua posizione
estrai_colonna_per_nome(nome_colonna)PubblicoRestituisce i valori di una colonna a partire dal suo nome

Il _ all'inizio del nome è una convenzione di Python per indicare che un metodo è a uso interno della classe: esiste per aiutare gli altri metodi, e non per essere chiamato dall'esterno.

class FileCSV:

    def __init__(self, percorso_file: str):
        self.percorso_file = percorso_file
        # Il costruttore stesso legge già il file e scopre le colonne
        self.contenuto = self._estrai_contenuto()
        self.colonne = self._estrai_nome_colonne()

    def _estrai_contenuto(self) -> list:
        with open(self.percorso_file, mode='r', encoding='utf8') as file:
            return file.readlines()

    def _estrai_nome_colonne(self) -> list:
        # La prima riga del file è l'intestazione
        return self.contenuto[0].strip().split(',')

    def estrai_colonna(self, indice_colonna: int) -> list:
        colonna = []
        # [1:] salta la prima riga, perché l'intestazione non è un dato
        for riga in self.contenuto[1:]:
            valori_riga = riga.strip().split(',')
            colonna.append(valori_riga[indice_colonna])
        return colonna

    def estrai_colonna_per_nome(self, nome_colonna: str) -> list:
        # Un metodo può chiamare un altro metodo dello stesso oggetto tramite self
        indice_colonna = self.colonne.index(nome_colonna)
        return self.estrai_colonna(indice_colonna=indice_colonna)

Alla creazione dell'oggetto, __init__ legge già il file e popola gli attributi contenuto e colonne:

file_banca = FileCSV(percorso_file='banca.csv')

print(file_banca.colonne)
# ['age', 'job', 'marital', 'education', 'default', 'balance', 'housing', 'loan']

# Ogni elemento dell'attributo contenuto è una riga del file (nota il \n alla fine)
print(file_banca.contenuto[:3])
# ['age,job,marital,education,default,balance,housing,loan\n', '30,unemployed,married,primary,no,1787,no,no\n', '33,services,married,secondary,no,4789,yes,yes\n']

Esempio: estraendo la colonna job (professione), che è nella posizione 1.

professioni = file_banca.estrai_colonna(indice_colonna=1)
print(professioni)
# ['unemployed', 'services', 'management', 'management', 'blue-collar', 'management', 'self-employed', 'technician', 'entrepreneur', 'services']

Esempio: estraendo la colonna education (istruzione), che è nella posizione 3.

livelli_istruzione = file_banca.estrai_colonna(indice_colonna=3)
print(livelli_istruzione)
# ['primary', 'secondary', 'tertiary', 'tertiary', 'secondary', 'tertiary', 'tertiary', 'secondary', 'tertiary', 'primary']

Esempio: ricordare a memoria la posizione di ogni colonna è faticoso e facile da sbagliare. Con estrai_colonna_per_nome(), basta indicare il nome:

stati_civili = file_banca.estrai_colonna_per_nome(nome_colonna='marital')
print(stati_civili)

# Il risultato è una lista comune, quindi possiamo usare i metodi delle liste
print(f"Clienti sposati: {stati_civili.count('married')}")
# ['married', 'married', 'single', 'married', 'married', 'single', 'married', 'married', 'married', 'married']
# Clienti sposati: 8

Esempio: i valori letti da un file di testo sono sempre string. Per fare calcoli, convertiamo ogni valore. Qui calcoliamo il saldo medio (balance) dei clienti:

saldi_testo = file_banca.estrai_colonna_per_nome(nome_colonna='balance')

# Convertendo ogni saldo da str a int
saldi = []
for saldo in saldi_testo:
    saldi.append(int(saldo))

saldo_medio = sum(saldi) / len(saldi)
print(f'Saldo medio: {saldo_medio:.2f}')
# Saldo medio: 1073.60

Attenzione: Python non impedisce di chiamare file_banca._estrai_contenuto() dall'esterno della classe, ma questo va contro la convenzione del _. I metodi interni possono cambiare o smettere di esistere in versioni future della classe; usa sempre gli attributi e i metodi pubblici.
