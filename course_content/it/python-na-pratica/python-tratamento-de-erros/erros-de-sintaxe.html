La sintassi è l'insieme delle regole di scrittura di un linguaggio, come la grammatica di una lingua. Quando una regola viene infranta, Python non riesce nemmeno a capire cosa deve fare, e per questo non esegue nulla.

Definizione

Prima di eseguire una cella, Python legge tutto il suo codice per comprenderlo. Se trova un errore di sintassi in questa lettura, genera un SyntaxError e nessuna riga viene eseguita, nemmeno quelle che vengono prima dell'errore.

Per vedere questo accadere senza bloccare il notebook, useremo due funzioni native che ricevono un codice conservato in una string: exec(codice) esegue il codice, e compile(codice, nome, 'exec') si limita ad analizzare il codice, senza eseguirlo. Servono solo per questa dimostrazione — nel lavoro quotidiano scrivi il codice direttamente nella cella.

carrello_spesa = [
    {'id': 3184, 'preco': 37.65, 'quantidade': 10},
    {'id': 1203, 'preco': 81.20, 'quantidade': 2},
    {'id': 8921, 'preco': 15.90, 'quantidade': 2},
]

# Il print è PRIMA dell'errore di sintassi (manca ':' nel for)...
codice_con_errore = '''print('Questo messaggio arriva prima dell\\'errore')
for prodotto in carrello_spesa
    print(prodotto)
'''

try:
    exec(codice_con_errore)
except SyntaxError as errore:
    # ...e anche così non viene mostrato: nulla è stato eseguito
    print(f'{type(errore).__name__}: {errore.msg} (riga {errore.lineno})')
# SyntaxError: expected ':' (riga 2)

Nota che il messaggio 'Questo messaggio arriva prima dell\'errore' non è apparso. Tieni a mente questa differenza: vedremo nella prossima lezione che, con gli errori di esecuzione, le righe precedenti all'errore vengono eseguite normalmente.

Errori di sintassi comuni

Per testare vari esempi, creiamo una funzione che analizza un codice e mostra l'errore di sintassi, indicando la riga e la posizione con una freccia (^), come fa Python stesso:

def verifica_sintassi(codice: str) -> None:
    '''Analizza il codice (senza eseguirlo) e mostra l'errore di sintassi, se presente.'''
    codice = codice.strip('\n')  # ignora le righe vuote all'inizio e alla fine
    try:
        compile(codice, '<esempio>', 'exec')
    except SyntaxError as errore:
        riga_con_errore = codice.splitlines()[errore.lineno - 1]
        print(f'{type(errore).__name__} alla riga {errore.lineno}: {errore.msg}')
        print(f'    {riga_con_errore}')
        if errore.offset:
            print('    ' + ' ' * (errore.offset - 1) + '^')
    else:
        print('Nessun errore di sintassi trovato.')

Esempio: dimenticare i due punti (:) alla fine di un for, if, elif, else o def.

verifica_sintassi('''
for prodotto in carrello_spesa
    print(prodotto)
''')
# SyntaxError alla riga 1: expected ':'
#     for prodotto in carrello_spesa
#                                    ^

Esempio: mettere una condizione nell'else. L'else significa "in tutti gli altri casi", quindi non riceve mai una condizione. Per testare un'altra condizione, usa elif.

verifica_sintassi('''
for prodotto in carrello_spesa:
    if prodotto['id'] == 3184:
        print('Prodotto 3184')
    else prodotto['id'] == 1203:
        print('Prodotto 1203')
''')
# SyntaxError alla riga 4: expected ':'
#         else prodotto['id'] == 1203:
#              ^

# Forma corretta: elif per la seconda condizione
for prodotto in carrello_spesa:
    if prodotto['id'] == 3184:
        print('Prodotto 3184')
    elif prodotto['id'] == 1203:
        print('Prodotto 1203')
# Prodotto 3184
# Prodotto 1203

Esempio: indentazione scorretta. In Python, gli spazi all'inizio della riga definiscono quali righe appartengono a un blocco. Questo errore ha addirittura un nome proprio: IndentationError.

verifica_sintassi('''
for prodotto in carrello_spesa:
print(prodotto)
''')
# IndentationError alla riga 2: expected an indented block after 'for' statement on line 1
#     print(prodotto)
#     ^

Esempio: dimenticare di chiudere parentesi, quadre o virgolette.

verifica_sintassi('''
print('Totale prodotti:', len(carrello_spesa)
''')
# SyntaxError alla riga 1: '(' was never closed
#     print('Totale prodotti:', len(carrello_spesa)
#          ^

verifica_sintassi('''
messaggio = 'Benvenuto su Ready To Deploy
''')
# SyntaxError alla riga 1: unterminated string literal (detected at line 1)
#     messaggio = 'Benvenuto su Ready To Deploy
#                ^

Esempio: usare = (assegnazione) dove dovrebbe essere == (confronto).

verifica_sintassi('''
if len(carrello_spesa) = 3:
    print('Carrello con 3 prodotti')
''')
# SyntaxError alla riga 1: cannot assign to function call here. Maybe you meant '==' instead of '='?
#     if len(carrello_spesa) = 3:
#        ^

Esempio: usare return fuori da una funzione. Il return ha senso solo dentro un def.

verifica_sintassi('''
eta = 19
if eta > 18:
    return True
''')
# SyntaxError alla riga 3: 'return' outside function
#         return True
#         ^

Come correggere

Gli errori di sintassi non possono essere gestiti con try/except dentro la stessa cella: dato che Python non riesce nemmeno a leggere il codice, il try non arriva mai a essere eseguito. L'unica via d'uscita è correggere il codice. Per farlo, leggi con attenzione il messaggio di errore:

  1. Tipo di errore: SyntaxError o IndentationError;
  2. Riga: dove Python ha rilevato il problema;
  3. Freccia ^: la posizione approssimativa dell'errore nella riga;
  4. Descrizione: nelle versioni più recenti di Python è piuttosto specifica, come expected ':' ("attesi i due punti :").

Suggerimento: Python indica il punto in cui ha rilevato l'errore, che non sempre è dove esso si trova. Una parentesi dimenticata in una riga viene spesso segnalata solo nella riga successiva. Se la riga indicata sembra corretta, controlla anche la riga sopra.

Suggerimento: editor come Colab e VS Code sottolineano in rosso buona parte degli errori di sintassi mentre digiti. Presta attenzione a questi avvisi prima di eseguire la cella.
