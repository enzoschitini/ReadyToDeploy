Le liste conservano elementi ripetuti e nell'ordine in cui sono stati inseriti. Ma, a volte, ciò che conta non è l'ordine né la ripetizione — è solo sapere quali valori diversi esistono. Per questo usiamo gli insiemi.

Motivazione

Lavori come analista di social media e devi scoprire tutti gli hashtag diversi che sono entrati nei trending topics di un social network durante la settimana. Hai già gli hashtag di ogni giorno, in liste separate:

hashtags_lunedi = ['#tiago', '#joao', '#bbb']
hashtags_martedi = ['#sarah', '#bbb', '#fiuk']
hashtags_mercoledi = ['#gil', '#thelma', '#lourdes']
hashtags_giovedi = ['#rafa', '#fora', '#danilo']
hashtags_venerdi = ['#juliete', '#arthur', '#bbb']

Se semplicemente concateniamo le liste della settimana, l'hashtag #bbb (che è apparso in tre giorni diversi) si ripeterà nel risultato:

hashtags_settimana = hashtags_lunedi + hashtags_martedi + hashtags_mercoledi + hashtags_giovedi + hashtags_venerdi

print(hashtags_settimana)
print(f'Totale: {len(hashtags_settimana)}')
# ['#tiago', '#joao', '#bbb', '#sarah', '#bbb', '#fiuk', '#gil', '#thelma', '#lourdes', '#rafa', '#fora', '#danilo', '#juliete', '#arthur', '#bbb']
# Totale: 15

Nota che il totale (15) non rappresenta la quantità di hashtag diversi — #bbb è stato contato tre volte. Come eliminiamo le ripetizioni?

Definizione

Gli insiemi memorizzano sequenze non ordinate di valori, senza ripetizioni. Sono del tipo set e vengono creati tra parentesi graffe {}.

frutta = {'banana', 'mela', 'uva', 'uva'}

print(frutta)
print(type(frutta))
# {'uva', 'mela', 'banana'}
# <class 'set'>

Nota che 'uva' è stato scritto due volte, ma appare una sola volta nell'insieme. Poiché gli insiemi non hanno ordine, la sequenza mostrata può variare a ogni esecuzione.

Attenzione: non avendo ordine, gli insiemi non possono essere acceduti per indice (frutta[0] genera un errore TypeError).

Operazioni

Differenza (-): restituisce gli elementi che sono nel primo insieme, ma non sono nel secondo.

Esempio: paesi del nord Europa che non sono scandinavi.

nord_europa = {'regno unito', 'svezia', 'russia', 'norvegia', 'danimarca'}
scandinavia = {'norvegia', 'danimarca', 'svezia'}

nord_europa_non_scandinavo = nord_europa - scandinavia
print(nord_europa_non_scandinavo)
# {'regno unito', 'russia'}

# L'ordine degli operandi conta: qui cerchiamo l'opposto
scandinavo_non_nord_europa = scandinavia - nord_europa
print(scandinavo_non_nord_europa)  # set() vuoto: ogni paese scandinavo è nel nord Europa
# set()

Python offre anche | (unione, tutti gli elementi dei due insiemi) e & (intersezione, solo gli elementi presenti in entrambi). Qui, a differenza dei booleani, | e & sono il modo corretto di usarli con gli insiemi.

Metodi

MetodoCosa fa
.add(valor)Aggiunge un elemento all'insieme
.remove(valor)Rimuove un elemento dall'insieme
 
corsi_disponibili = {'Scienze esatte', 'Scienze umane', 'Scienze biologiche'}
print(corsi_disponibili)
# {'Scienze esatte', 'Scienze umane', 'Scienze biologiche'}

# .add(): aggiunge un elemento (se esiste già, l'insieme non cambia)
corsi_disponibili.add('Salute')
print(corsi_disponibili)
# {'Salute', 'Scienze esatte', 'Scienze umane', 'Scienze biologiche'}

# .remove(): rimuove un elemento esistente
corsi_disponibili.remove('Salute')
print(corsi_disponibili)
# {'Scienze esatte', 'Scienze umane', 'Scienze biologiche'}

Conversione

È molto comune convertire una lista in insieme (per eliminare le ripetizioni) e, poi, l'insieme di nuovo in lista (per poter usare di nuovo indici e metodi di lista).

squadre_paulistas = ['São Paulo', 'Palmeiras', 'Corinthians', 'Santos']

# list -> set: elimina eventuali ripetizioni
squadre_senza_ripetizioni = set(squadre_paulistas)
print(squadre_senza_ripetizioni)
print(type(squadre_senza_ripetizioni))
# {'Corinthians', 'Santos', 'São Paulo', 'Palmeiras'}
# <class 'set'>

# set -> list: per tornare a usare indici e metodi di lista
squadre_lista = list(squadre_senza_ripetizioni)
print(squadre_lista)
print(type(squadre_lista))
# ['Corinthians', 'Santos', 'São Paulo', 'Palmeiras']
# <class 'list'>

Rivisitando la motivazione

Combinando le due conversioni, risolviamo il problema degli hashtag in un'unica riga: uniamo le liste, convertiamo in set (rimuovendo le ripetizioni) e torniamo a list.

hashtags_settimana_uniche = list(set(hashtags_lunedi + hashtags_martedi + hashtags_mercoledi + hashtags_giovedi + hashtags_venerdi))

print(hashtags_settimana_uniche)
print(f'Totale hashtag uniche: {len(hashtags_settimana_uniche)}')
# ['#sarah', '#bbb', '#thelma', '#fora', '#danilo', '#juliete', '#arthur', '#tiago', '#gil', '#joao', '#fiuk', '#lourdes', '#rafa']
# Totale hashtag uniche: 13
