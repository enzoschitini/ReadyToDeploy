Quando dobbiamo memorizzare diverse informazioni dello stesso tipo di evento — come le transazioni di un giorno — creare una variabile per ciascuna non è scalabile. Le liste risolvono esattamente questo problema.

Motivazione

L'app della tua banca registra tutto il tuo movimento finanziario. Alla fine della giornata, l'app somma tutte le transazioni al saldo iniziale per calcolare il saldo finale. Memorizzando ogni transazione in una variabile separata, il codice diventa così:

saldo_iniziale_giorno_11 = 1000

transazione_1 = 243
transazione_2 = -798.58
transazione_3 = 427.12
transazione_4 = -10.91

saldo_finale_giorno_11 = saldo_iniziale_giorno_11 + transazione_1 + transazione_2 + transazione_3 + transazione_4
print(round(saldo_finale_giorno_11, 2))
# 860.63

Funziona, ma nota il problema: se la giornata avesse 50 transazioni, sarebbero 50 variabili diverse, e il calcolo del saldo avrebbe 50 termini scritti a mano. Esiste un modo migliore di memorizzare queste transazioni?

Definizione

Le liste memorizzano sequenze ordinate e mutabili (possono essere modificate dopo essere state create) di valori, che possono ripetersi. Sono del tipo list e vengono create tra parentesi quadre [], con gli elementi separati da virgola.

dati_utente_web = ['André Perez', 'andre.perez', 'andre123', 'andre.perez@gmail.com']

print(dati_utente_web)
print(type(dati_utente_web))
# ['André Perez', 'andre.perez', 'andre123', 'andre.perez@gmail.com']
# <class 'list'>

Una lista può mescolare valori di tipi diversi — numeri, testi, booleani e persino altre liste:

eta = 20
saldo_sul_conto = 723.15
utente_loggato = True

dati_utente_web = ['André Perez', eta, 'andre.perez', 'andre.perez@gmail.com', saldo_sul_conto, utente_loggato]

print(dati_utente_web)
print(type(dati_utente_web))
# ['André Perez', 20, 'andre.perez', 'andre.perez@gmail.com', 723.15, True]
# <class 'list'>

Operazioni

Concatenazione (+): unisce due liste in una sola, mantenendo l'ordine.

Esempio: unire produttori di hardware mobile per regione.

produttori_cina = ['xiaomi', 'huawei']
produttori_usa = ['apple', 'motorola']

produttori_mobile = produttori_cina + produttori_usa
print(produttori_mobile)
# ['xiaomi', 'huawei', 'apple', 'motorola']

**Slicing (fatiamento)**: proprio come nelle stringhe, accediamo agli elementi di una lista tramite la posizione (indice), che inizia da 0. Gli indici negativi contano a partire dalla fine.

print(f'Posizione 0:  {produttori_mobile[0]}')
print(f'Posizione -1: {produttori_mobile[-1]}')
# Posizione 0:  xiaomi
# Posizione -1: motorola

E possiamo anche estrarre un intervallo di elementi con lista[inicio:fim] — l'elemento nella posizione fim non è incluso:

produttori_cina = produttori_mobile[0:2]
produttori_usa = produttori_mobile[2:len(produttori_mobile)]

print(f'Cina: {produttori_cina}')
print(f'USA:  {produttori_usa}')
# Cina: ['xiaomi', 'huawei']
# USA:  ['apple', 'motorola']

A differenza delle stringhe, le liste sono mutabili: possiamo modificare un elemento esistente assegnando un nuovo valore alla sua posizione.

print(produttori_mobile)

produttori_mobile[2] = 'nokia'
print(produttori_mobile)
# ['xiaomi', 'huawei', 'apple', 'motorola']
# ['xiaomi', 'huawei', 'nokia', 'motorola']

Metodi

I metodi sottostanti sono i più usati nella pratica quotidiana per aggiungere e rimuovere elementi da una lista:

MetodoCosa fa
.append(valor)Aggiunge un elemento alla fine della lista
.insert(indice, valor)Inserisce un elemento in una posizione specifica
.remove(valor)Rimuove la prima occorrenza di un valore
.pop(indice)Rimuove l'elemento da una posizione e restituisce il valore rimosso
 
interessi_mensili = [0.05, 0.07, 0.02, 0.04, 0.08]
print(interessi_mensili)
# [0.05, 0.07, 0.02, 0.04, 0.08]

# .append(): aggiunge alla fine
interessi_mensili.append(0.09)
print(interessi_mensili)
# [0.05, 0.07, 0.02, 0.04, 0.08, 0.09]

# .insert(): aggiunge in una posizione specifica, spostando gli altri elementi
interessi_mensili.insert(0, 0.10)
print(interessi_mensili)
# [0.1, 0.05, 0.07, 0.02, 0.04, 0.08, 0.09]

# .remove(): rimuove per VALORE (la prima occorrenza)
interessi_mensili.remove(0.10)
print(interessi_mensili)
# [0.05, 0.07, 0.02, 0.04, 0.08, 0.09]

# .pop(): rimuove per INDICE e restituisce il valore rimosso
terzo_interesse = interessi_mensili.pop(2)
print(f'Valore rimosso: {terzo_interesse}')
print(interessi_mensili)
# Valore rimosso: 0.02
# [0.05, 0.07, 0.04, 0.08, 0.09]

Suggerimento: .pop() senza argomento rimuove e restituisce l'ultimo elemento della lista — utile per simulare una pila di elementi.

Conversione

Alcuni tipi possono essere convertiti in lista con la funzione list(). Una stringa, per esempio, diventa una lista con un elemento per ogni carattere:

email = 'andre.perez@gmail.com'
caratteri_email = list(email)

print(email)
print(caratteri_email)
# andre.perez@gmail.com
# ['a', 'n', 'd', 'r', 'e', '.', 'p', 'e', 'r', 'e', 'z', '@', 'g', 'm', 'a', 'i', 'l', '.', 'c', 'o', 'm']

Rivisitando la motivazione

Ora possiamo memorizzare le transazioni del giorno in un'unica lista, e usare .append() per aggiungere ogni nuova transazione:

transazioni_giorno_11 = []

transazioni_giorno_11.append(243)
transazioni_giorno_11.append(-798.58)
transazioni_giorno_11.append(427.12)
transazioni_giorno_11.append(-10.91)

print(transazioni_giorno_11)
# [243, -798.58, 427.12, -10.91]

E la funzione nativa sum() somma tutti gli elementi di una lista numerica in un colpo solo, senza bisogno di sommare elemento per elemento:

saldo_finale_giorno_11 = saldo_iniziale_giorno_11 + sum(transazioni_giorno_11)
print(round(saldo_finale_giorno_11, 2))
# 860.63

Non importa se il giorno ha 4 o 400 transazioni: il codice rimane esattamente lo stesso, poiché sum() somma automaticamente tutti gli elementi della lista.
