Liste e insiemi conservano valori "sciolti", identificati solo dalla posizione o dalla loro stessa esistenza. Ma molti dati del mondo reale arrivano in coppie: un nome di rete e la sua password, un codice fiscale e il nome del cliente. Per questo usiamo i dizionari.

Motivazione

Per connetterti a una rete wi-fi, hai bisogno di due informazioni: il nome della rete e la password di accesso. Cercando le reti disponibili, il tuo dispositivo trova una lista di nomi:

reti_wifi_disponibili = ['rede1', 'cnx_cnx', 'uai-fi', 'r3d3']
print(reti_wifi_disponibili)
# ['rede1', 'cnx_cnx', 'uai-fi', 'r3d3']

Il problema è che questa lista conserva solo i nomi. Non c'è modo di associare ogni rete alla sua password corrispondente. Come memorizziamo coppie di informazioni correlate, come nome e password?

Definizione

I dizionari memorizzano dati nel formato chiave-valore: ogni elemento è composto da una chiave (usata per cercare il dato) e un valore (il dato stesso). Sono del tipo dict e vengono creati tra parentesi graffe {}, nel formato {chiave: valore}.

brasile = {'capitale': 'Brasília', 'lingua': 'Portoghese', 'popolazione_milioni': 210}

print(brasile)
print(type(brasile))
# {'capitale': 'Brasília', 'lingua': 'Portoghese', 'popolazione_milioni': 210}
# <class 'dict'>

Attenzione: non è consentito avere chiavi duplicate. Se ripeti una chiave, l'ultimo valore assegnato a essa sovrascrive i precedenti, senza generare errori:

auto = {
    'marca': 'Volkswagen',
    'modello': 'Polo',
    'anno': 2021,
    'anno': 2004,  # sovrascrive il valore precedente della chiave 'anno'
}

print(auto)
# {'marca': 'Volkswagen', 'modello': 'Polo', 'anno': 2004}

Un valore di un dizionario può anche essere un altro dizionario — questo si chiama dizionario composto, molto utile per rappresentare dati con una gerarchia:

registro = {
    'andre': {
        'nome': 'André Perez',
        'anno_nascita': 1992,
        'padre': {'nome': 'Carlos Perez', 'anno_nascita': 1965},
        'madre': {'nome': 'Marta Perez', 'anno_nascita': 1968},
    }
}

print(registro)
# {'andre': {'nome': 'André Perez', 'anno_nascita': 1992, 'padre': {'nome': 'Carlos Perez', 'anno_nascita': 1965}, 'madre': {'nome': 'Marta Perez', 'anno_nascita': 1968}}}

Per accedere a un valore su più livelli, concateniamo le parentesi quadre con ogni chiave, dal livello più esterno al più interno:

anno_nascita_madre = registro['andre']['madre']['anno_nascita']
print(anno_nascita_madre)
# 1968

Operazioni

A differenza delle liste, gli elementi di un dizionario vengono acceduti e aggiornati tramite la chiave, e non la posizione.

punteggio_credito = {'123': 750, '789': 980}

# Accesso a un valore tramite la chiave
punteggio_cliente_123 = punteggio_credito['123']
punteggio_cliente_789 = punteggio_credito['789']

print(punteggio_cliente_123)
print(punteggio_cliente_789)
# 750
# 980

# Aggiornamento di un valore: assegniamo un nuovo valore a una chiave già esistente
punteggio_credito['123'] = 435
print(punteggio_credito)
# {'123': 435, '789': 980}

# Aggiunta di una nuova coppia chiave-valore: basta assegnare a una chiave nuova
punteggio_credito['456'] = 1000
print(punteggio_credito)
# {'123': 435, '789': 980, '456': 1000}

Attenzione: accedere a una chiave che non esiste con dizionario[chiave] genera un errore KeyError. Per cercare in sicurezza, usa il metodo .get(chiave), che restituisce None (invece di un errore) quando la chiave non esiste.

print(punteggio_credito.get('456'))  # esiste: restituisce il valore
print(punteggio_credito.get('999'))  # non esiste: restituisce None, senza errore
# 1000
# None

Metodi

MetodoCosa fa
.update(dict)Aggiunge o aggiorna più coppie chiave-valore in una volta
.pop(chiave)Rimuove un elemento tramite la chiave e restituisce il valore rimosso
.get(chiave)Restituisce il valore della chiave, o None se non esiste
 
articolo = dict(
    titolo='Modulo 02 - Strutture di Dati',
    corpo='Argomenti, Lezioni, Liste, Insiemi, Dizionari...',
    totale_caratteri=1530,
)
print(articolo)
# {'titolo': 'Modulo 02 - Strutture di Dati', 'corpo': 'Argomenti, Lezioni, Liste, Insiemi, Dizionari...', 'totale_caratteri': 1530}

# .update(): aggiorna una o più coppie in una sola volta
articolo.update({'totale_caratteri': 7850})
print(articolo)
# {'titolo': 'Modulo 02 - Strutture di Dati', 'corpo': 'Argomenti, Lezioni, Liste, Insiemi, Dizionari...', 'totale_caratteri': 7850}

# .pop(): rimuove tramite la CHIAVE e restituisce il valore rimosso
totale_caratteri = articolo.pop('totale_caratteri')

print(f'Valore rimosso: {totale_caratteri}')
print(articolo)
# Valore rimosso: 7850
# {'titolo': 'Modulo 02 - Strutture di Dati', 'corpo': 'Argomenti, Lezioni, Liste, Insiemi, Dizionari...'}

Conversione

Possiamo convertire le chiavi e i valori di un dizionario in liste, con i metodi .keys() e .values():

articolo = dict(
    titolo='Modulo 02 - Strutture di Dati',
    corpo='Argomenti, Lezioni, Liste, Insiemi, Dizionari...',
    totale_caratteri=1530,
)

chiavi = list(articolo.keys())

print(chiavi)
print(type(chiavi))
# ['titolo', 'corpo', 'totale_caratteri']
# <class 'list'>

valori = list(articolo.values())

print(valori)
print(type(valori))
# ['Modulo 02 - Strutture di Dati', 'Argomenti, Lezioni, Liste, Insiemi, Dizionari...', 1530]
# <class 'list'>

Rivisitando la motivazione

Ora possiamo rappresentare ogni rete wi-fi come un dizionario con le chiavi nome e password, e conservarle tutte in una lista:

reti_wifi_disponibili = []

rete = {'nome': 'rede1', 'password': 'cnx_cnx'}
reti_wifi_disponibili.append(rete)

rete = {'nome': 'uai-fi', 'password': 'r3d3'}
reti_wifi_disponibili.append(rete)

print(reti_wifi_disponibili)
# [{'nome': 'rede1', 'password': 'cnx_cnx'}, {'nome': 'uai-fi', 'password': 'r3d3'}]

Ora sì: per ogni rete della lista, sappiamo esattamente qual è il nome e qual è la password corrispondente — il problema iniziale è stato risolto combinando lista (la collezione di reti) e dizionario (i dati di ogni rete).
