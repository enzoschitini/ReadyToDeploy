Liste e insiemi conservano valori "sciolti", identificati solo dalla posizione o dalla loro stessa esistenza. Ma molti dati del mondo reale arrivano in coppie: un nome di rete e la sua password, un codice fiscale e il nome del cliente. Per questo usiamo i dizionari.

Motivazione

Per connetterti a una rete wi-fi, hai bisogno di due informazioni: il nome della rete e la password di accesso. Cercando le reti disponibili, il tuo dispositivo trova una lista di nomi:

redes_wifi_disponiveis = ['rede1', 'cnx_cnx', 'uai-fi', 'r3d3']
print(redes_wifi_disponiveis)
# ['rede1', 'cnx_cnx', 'uai-fi', 'r3d3']

Il problema è che questa lista conserva solo i nomi. Non c'è modo di associare ogni rete alla sua password corrispondente. Come memorizziamo coppie di informazioni correlate, come nome e password?

Definizione

I dizionari memorizzano dati nel formato chiave-valore: ogni elemento è composto da una chiave (usata per cercare il dato) e un valore (il dato stesso). Sono del tipo dict e vengono creati tra parentesi graffe {}, nel formato {chiave: valore}.

brasil = {'capital': 'Brasília', 'idioma': 'Português', 'populacao_milhoes': 210}

print(brasil)
print(type(brasil))
# {'capital': 'Brasília', 'idioma': 'Português', 'populacao_milhoes': 210}
# <class 'dict'>

Attenzione: non è consentito avere chiavi duplicate. Se ripeti una chiave, l'ultimo valore assegnato a essa sovrascrive i precedenti, senza generare errori:

carro = {
    'marca': 'Volkswagen',
    'modelo': 'Polo',
    'ano': 2021,
    'ano': 2004,  # sobrescreve o valor anterior da chave 'ano'
}

print(carro)
# {'marca': 'Volkswagen', 'modelo': 'Polo', 'ano': 2004}

Un valore di un dizionario può anche essere un altro dizionario — questo si chiama dizionario composto, molto utile per rappresentare dati con una gerarchia:

cadastro = {
    'andre': {
        'nome': 'André Perez',
        'ano_nascimento': 1992,
        'pai': {'nome': 'Carlos Perez', 'ano_nascimento': 1965},
        'mae': {'nome': 'Marta Perez', 'ano_nascimento': 1968},
    }
}

print(cadastro)
# {'andre': {'nome': 'André Perez', 'ano_nascimento': 1992, 'pai': {'nome': 'Carlos Perez', 'ano_nascimento': 1965}, 'mae': {'nome': 'Marta Perez', 'ano_nascimento': 1968}}}

Per accedere a un valore su più livelli, concateniamo le parentesi quadre con ogni chiave, dal livello più esterno al più interno:

ano_nascimento_mae = cadastro['andre']['mae']['ano_nascimento']
print(ano_nascimento_mae)
# 1968

Operazioni

A differenza delle liste, gli elementi di un dizionario vengono acceduti e aggiornati tramite la chiave, e non la posizione.

score_credito = {'123': 750, '789': 980}

# Acessando um valor pela chave
score_cliente_123 = score_credito['123']
score_cliente_789 = score_credito['789']

print(score_cliente_123)
print(score_cliente_789)
# 750
# 980

# Atualizando um valor: atribuímos um novo valor à chave já existente
score_credito['123'] = 435
print(score_credito)
# {'123': 435, '789': 980}

# Adicionando um novo par chave-valor: basta atribuir a uma chave nova
score_credito['456'] = 1000
print(score_credito)
# {'123': 435, '789': 980, '456': 1000}

Attenzione: accedere a una chiave che non esiste con dicionario[chave] genera un errore KeyError. Per cercare in sicurezza, usa il metodo .get(chave), che restituisce None (invece di un errore) quando la chiave non esiste.

print(score_credito.get('456'))  # existe: retorna o valor
print(score_credito.get('999'))  # não existe: retorna None, sem erro
# 1000
# None

MetodoCosa fa

artigo = dict(
    titulo='Módulo 02 - Estruturas de Dados',
    corpo='Tópicos, Aulas, Listas, Conjuntos, Dicionários...',
    total_caracteres=1530,
)
print(artigo)
# {'titulo': 'Módulo 02 - Estruturas de Dados', 'corpo': 'Tópicos, Aulas, Listas, Conjuntos, Dicionários...', 'total_caracteres': 1530}

# .update(): atualiza um ou mais pares de uma vez
artigo.update({'total_caracteres': 7850})
print(artigo)
# {'titulo': 'Módulo 02 - Estruturas de Dados', 'corpo': 'Tópicos, Aulas, Listas, Conjuntos, Dicionários...', 'total_caracteres': 7850}

# .pop(): remove pela CHAVE e devolve o valor removido
total_caracteres = artigo.pop('total_caracteres')

print(f'Valor removido: {total_caracteres}')
print(artigo)
# Valor removido: 7850
# {'titulo': 'Módulo 02 - Estruturas de Dados', 'corpo': 'Tópicos, Aulas, Listas, Conjuntos, Dicionários...'}

Conversione

Possiamo convertire le chiavi e i valori di un dizionario in liste, con i metodi .keys() e .values():

artigo = dict(
    titulo='Módulo 02 - Estruturas de Dados',
    corpo='Tópicos, Aulas, Listas, Conjuntos, Dicionários...',
    total_caracteres=1530,
)

chaves = list(artigo.keys())

print(chaves)
print(type(chaves))
# ['titulo', 'corpo', 'total_caracteres']
# <class 'list'>

valores = list(artigo.values())

print(valores)
print(type(valores))
# ['Módulo 02 - Estruturas de Dados', 'Tópicos, Aulas, Listas, Conjuntos, Dicionários...', 1530]
# <class 'list'>

Rivisitando la motivazione

Ora possiamo rappresentare ogni rete wi-fi come un dizionario con le chiavi nome e senha, e conservarle tutte in una lista:

redes_wifi_disponiveis = []

rede = {'nome': 'rede1', 'senha': 'cnx_cnx'}
redes_wifi_disponiveis.append(rede)

rede = {'nome': 'uai-fi', 'senha': 'r3d3'}
redes_wifi_disponiveis.append(rede)

print(redes_wifi_disponiveis)
# [{'nome': 'rede1', 'senha': 'cnx_cnx'}, {'nome': 'uai-fi', 'senha': 'r3d3'}]

Ora sì: per ogni rete della lista, sappiamo esattamente qual è il nome e qual è la password corrispondente — il problema iniziale è stato risolto combinando lista (la collezione di reti) e dizionario (i dati di ogni rete).
