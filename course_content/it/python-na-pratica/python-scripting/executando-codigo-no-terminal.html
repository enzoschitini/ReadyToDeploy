Oltre a eseguire un intero file di script, Python ha una modalità interattiva, chiamata REPL (Read-Eval-Print Loop): digiti una riga di codice, Python la esegue e mostra il risultato all'istante, una riga alla volta.

Su Google Colab

Ogni cella di codice di Colab funziona già come un REPL: scrivi un'istruzione, la esegui (Shift + Enter) e vedi il risultato immediatamente, senza dover eseguire un intero file .py. È per questo che Colab è così comodo per imparare e testare codice velocemente.

Sulla tua macchina locale

Per aprire il REPL di Python sul tuo computer:

  1. Crea una cartella per i file del corso (suggerimento);
  2. Apri il terminale dentro questa cartella (su Windows, Shift + tasto destro sulla cartella; su macOS/Linux, tasto destro e "Apri terminale qui");
  3. Esegui il comando python.

Il terminale passa al prompt >>>, indicando che sei dentro Python. Da qui in avanti, ogni riga digitata viene eseguita all'istante:

>>> print("Olá, mundo!")
Olá, mundo!
>>> 2 + 2
4

Per uscire dal REPL, digita quit() (o exit()) e premi Enter, oppure chiudi il terminale.
