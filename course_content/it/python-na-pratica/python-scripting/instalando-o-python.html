Per eseguire uno script fuori da Colab — sul tuo computer, o su un server — devi avere Python (e il PIP, il suo gestore di pacchetti) installati sulla macchina che eseguirà il codice.

Su Google Colab

Python e PIP sono già installati sulla macchina virtuale che Colab ti mette a disposizione — non è necessario installare nulla.

Esempio: verifica della versione di Python dallo stesso Python, con il modulo nativo platform.

import platform

print(platform.python_version())
# 3.12.6

print(platform.system())
# Linux

Suggerimento: la macchina virtuale di Colab esegue Linux, quindi il risultato del codice sopra sarà normalmente Linux — anche se il tuo computer è Windows o macOS. È un ambiente completamente separato dal tuo computer.

Oltre a eseguire codice Python in una cella, Colab permette di eseguire comandi da terminale: basta anteporre un ! al comando.

Esempio: verifica delle versioni di Python e PIP direttamente dal terminale di Colab.

!python -V
# Python 3.12.6

!pip -V
# pip 24.2 from .../site-packages/pip (python 3.12)

Il ! non è Python: dice a Colab "esegui questo come un comando da terminale (Bash)", e non come codice Python. Per questo queste ultime due celle non vengono eseguite dal verificatore automatico di questo corso — funzionano solo dentro un notebook reale, come Colab.

Sulla tua macchina locale

Prima di installare, verifica se Python non è già installato. Apri il terminale (Windows: cmd o PowerShell; macOS/Linux: terminal) ed esegui:

python -V
pip -V

Attenzione: su Windows, il comando di solito è python. Su macOS e Linux, è comune che sia python3 (il nome python da solo potrebbe non esistere, o puntare a una vecchia installazione di Python 2). Se python -V non funziona, prova python3 -V.

Se i comandi non vengono riconosciuti, Python non è installato. Vai sul sito ufficiale di Python, scarica l'installer per il tuo sistema operativo e segui le istruzioni (vedi il link delle risorse alla fine di questa lezione).

Attenzione (Windows): durante l'installazione, seleziona l'opzione "Add Python to PATH". Senza di essa, il terminale non riconoscerà il comando python, anche con Python già installato — uno degli errori di configurazione più comuni tra i principianti.

Dopo l'installazione, chiudi e riapri il terminale, ed esegui di nuovo python -V per confermare.
