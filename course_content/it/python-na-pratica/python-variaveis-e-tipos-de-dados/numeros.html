I tipi numerici sono la base di qualsiasi calcolo: prezzi, quantità, tassi, metriche di business. In questa lezione conosceremo questi tipi, le loro operazioni e come convertire l'uno nell'altro.

Motivazione

Devi calcolare lo scontrino medio giornaliero del tuo ristorante, cioè quanto, in media, ha reso ciascuna vendita in un giorno. La metrica si calcola dividendo il valore totale delle vendite del giorno per la quantità di vendite dello stesso giorno:

scontrino medio = valore totale delle vendite / quantità di vendite

Questo è il tuo foglio di calcolo:

GiornoValore totale delle vendite (R$)Quantità di venditeScontrino medio (R$)
19/01153.983?
20/01337.017?
23/01295.335?

Come possiamo fare questo calcolo usando Python?

Definizione

I tipi numerici memorizzano valori numerici:

TipoDescrizioneEsempi
intNumeri interi (positivi, negativi o zero)10, -37, 500
floatNumeri decimali (virgola mobile)0.333, 10.1, -2.5
complexNumeri complessi (parte reale + parte immaginaria j)1 + 2j
 
# Verificando il tipo di ogni numero
print(type(37))       # <class 'int'>
print(type(10.1))     # <class 'float'>
print(type(1 + 2j))   # <class 'complex'>

Suggerimento: per numeri grandi, puoi usare _ come separatore delle migliaia. Python ignora l'_, ma il codice diventa molto più leggibile.

# L'underscore serve solo a facilitare la lettura
fatturato_annuale = 1_500_000
print(fatturato_annuale)  # 1500000

# Testando tutti gli operatori aritmetici
a = 7
b = 2

print("Somma:          ", a + b)
print("Sottrazione:    ", a - b)
print("Moltiplicazione:", a * b)
print("Divisione:      ", a / b)

# Sottrazione:     5
# Moltiplicazione: 14
# Divisione:       3.5
# Divisione intera: 3
# Resto:           1

Nota la differenza tra / e //: la divisione comune restituisce sempre un float, anche quando il risultato è esatto. La divisione intera invece scarta la parte decimale e, tra due interi, restituisce un int.

dividendo = 3
divisore = 2

# Divisione comune: risultato sempre float
risultato_divisione = dividendo / divisore
print(risultato_divisione)        # 1.5
print(type(risultato_divisione))  # <class 'float'>

# Divisione intera: scarta la parte decimale
risultato_divisione_intera = dividendo // divisore
print(risultato_divisione_intera)        # 1
print(type(risultato_divisione_intera))  # <class 'int'>

L'ordine di precedenza segue la matematica: prima **, poi *, /, // e %, e infine + e -. Usa le parentesi per rendere l'ordine esplicito:

# Senza parentesi: la moltiplicazione avviene prima della somma
print(2 + 3 * 4)    # 14

# Con le parentesi: la somma avviene per prima
print((2 + 3) * 4)  # 20

Esempio: carrello della spesa di un e-commerce. Ogni volta che il cliente aggiunge un articolo, la quantità aumenta di 1.

# Il carrello inizia vuoto
quantita_articoli_carrello = 0

# Il cliente aggiunge un articolo: prendiamo il valore attuale e sommiamo 1
quantita_articoli_carrello = quantita_articoli_carrello + 1
print(quantita_articoli_carrello)  # 1

# Il cliente aggiunge un altro articolo
quantita_articoli_carrello = quantita_articoli_carrello + 1
print(quantita_articoli_carrello)  # 2

Poiché questo schema è molto comune, Python offre gli operatori di assegnazione composta, che eseguono l'operazione e l'assegnazione in un solo passo:

Forma breveEquivale a
x += 1x = x + 1
x -= 1x = x - 1
x *= 2x = x * 2
x /= 2x = x / 2
 
# Stesso esempio, ora con l'operatore +=
quantita_articoli_carrello = 0

quantita_articoli_carrello += 1
print(quantita_articoli_carrello)  # 1

quantita_articoli_carrello += 1
print(quantita_articoli_carrello)  # 2

Esempio: totale da pagare per un prodotto venduto al chilo.

# Prezzo al chilo e quantità acquistata (250 grammi = 0.250 kg)
prezzo_al_kg = 47
quantita_kg = 0.250

totale_da_pagare = prezzo_al_kg * quantita_kg
print(totale_da_pagare)  # 11.75

Esempio: l'operatore % (resto) è molto usato per verificare se un numero è pari - ogni numero pari ha resto 0 quando diviso per 2.

numero_ordine = 1024

resto_divisione = numero_ordine % 2
print(resto_divisione)  # 0 - indica che il numero è pari

Conversione

Possiamo convertire i tipi numerici tra loro con le funzioni native int(), float() e complex():

# float -> int: la parte decimale viene SCARTATA (non è un arrotondamento!)
print(int(3.9))  # 3

# int -> float
print(float(10))  # 10.0

# int -> complex
print(complex(1))  # (1+0j)

Se l'obiettivo è arrotondare, usa la funzione round(), indicando il numero e la quantità di cifre decimali desiderata. È particolarmente utile per valori monetari:

valore_lordo = 51.326666

print(round(valore_lordo))     # 51 - arrotonda all'intero più vicino
print(round(valore_lordo, 2))  # 51.33 - arrotonda a 2 cifre decimali

Rivisitando la motivazione

Ora abbiamo tutti gli strumenti per compilare il foglio di calcolo del ristorante. Scontrino medio del giorno 19/01:

valore_vendite_19 = 153.98
quantita_vendite_19 = 3

scontrino_medio_19 = valore_vendite_19 / quantita_vendite_19
print(round(scontrino_medio_19, 2))  # 51.33

Scontrino medio del giorno 20/01:

valore_vendite_20 = 337.01
quantita_vendite_20 = 7

scontrino_medio_20 = valore_vendite_20 / quantita_vendite_20
print(round(scontrino_medio_20, 2))  # 48.14

Scontrino medio del giorno 23/01:

valore_vendite_23 = 295.33
quantita_vendite_23 = 5

scontrino_medio_23 = valore_vendite_23 / quantita_vendite_23
print(round(scontrino_medio_23, 2))  # 59.07

E lo scontrino medio dell'intero periodo? Una prima idea sarebbe fare la media dei tre scontrini giornalieri:

# Media semplice degli scontrini giornalieri
media_scontrini = (scontrino_medio_19 + scontrino_medio_20 + scontrino_medio_23) / 3
print(round(media_scontrini, 2))  # 52.85

Tuttavia, questo approccio dà lo stesso peso a tutti i giorni, anche se il giorno 20/01 ha avuto più del doppio delle vendite del giorno 19/01. Il modo corretto è applicare la formula stessa dello scontrino medio all'intero periodo: sommare tutti i valori e dividere per la somma di tutte le quantità.

# Totali del periodo
valore_totale_periodo = valore_vendite_19 + valore_vendite_20 + valore_vendite_23
quantita_totale_periodo = quantita_vendite_19 + quantita_vendite_20 + quantita_vendite_23

# Scontrino medio del periodo (media ponderata per la quantità di vendite)
scontrino_medio_periodo = valore_totale_periodo / quantita_totale_periodo
print(round(scontrino_medio_periodo, 2))  # 52.42

I due risultati sono diversi! Nell'analisi dei dati, capire cosa rappresenta una metrica è tanto importante quanto saperla calcolare.
