Ogni programma deve prendere decisioni: concedere o bloccare un accesso, approvare o rifiutare un pagamento, mostrare o nascondere un messaggio. Dietro tutte queste decisioni ci sono i booleani.

Motivazione

Nei siti web (social network, e-commerce, sistemi aziendali ecc.) è comune l'uso di sistemi di controllo degli accessi, il famoso login. In generale, l'utente fornisce due dati: usuario e senha.

# Dati digitati dall'utente nella schermata di login
usuario = 'andre.perez'
senha = 'andre123'

Dal lato del server, il backend del sito ha memorizzati i dati forniti al momento della registrazione: usuario_cadastro e senha_cadastro.

# Dati salvati al momento della registrazione
usuario_cadastro = 'andre.perez'
senha_cadastro = 'andre321'

Come confrontiamo usuario con usuario_cadastro e senha con senha_cadastro per decidere se l'accesso deve essere concesso o bloccato?

Definizione

I booleani memorizzano valori logici e possono assumere solo due valori: True (vero) o False (falso). Sono del tipo bool.

verdadeiro = True
falso = False

print(verdadeiro)       # True
print(falso)            # False
print(type(verdadeiro)) # <class 'bool'>

In pratica, raramente scriviamo True o False direttamente: i booleani sono di solito il risultato di confronti. Gli operatori di confronto sono:

OperatoreSignificatoEsempioRisultato
>Maggiore di5 > 3True
<Minore di5 < 3False
==Uguale a5 == 5True
!=Diverso da5 != 5False
>=Maggiore o uguale a5 >= 5True
<=Minore o uguale a3 <= 5True

Non confondere = (assegnazione: memorizza un valore) con == (confronto: verifica se due valori sono uguali).

Esempio: bancomat. Il prelievo può essere effettuato solo se il valore è minore o uguale al saldo.

saldo_em_conta = 200
valor_do_saque = 100

pode_realizar_saque = valor_do_saque <= saldo_em_conta
print(pode_realizar_saque)  # True

Esempio: carta di credito. Il pagamento viene approvato solo se il codice di sicurezza fornito è uguale a quello registrato.

codigo_seguranca_informado = '852'
codigo_seguranca_cadastro = '010'

pode_efetuar_pagamento = codigo_seguranca_informado == codigo_seguranca_cadastro
print(pode_efetuar_pagamento)  # False

Esempio: il confronto tra stringhe è sensibile a maiuscole e minuscole. Per confrontare ignorando questa differenza, standardizza i testi prima:

email_digitado = 'Andre.Perez@Gmail.com'
email_cadastro = 'andre.perez@gmail.com'

print(email_digitado == email_cadastro)                  # False: lettere diverse
print(email_digitado.lower() == email_cadastro.lower())  # True: entrambi in minuscolo

Operatori logici

Gli operatori logici permettono di combinare valori booleani:

OperatoreSignificatoRestituisce True quando...
andEentrambi i valori sono True
orOalmeno uno dei valori è True
notNOil valore è False (inverte il risultato)

L'insieme dei risultati possibili è riassunto nella cosiddetta tabella di verità:

ABA and BA or Bnot A
TrueTrueTrueTrueFalse
TrueFalseFalseTrueFalse
FalseTrueFalseTrueTrue
FalseFalseFalseFalseTrue
 
# Tabella di verità dell'operatore and (e)
print(True and True)    # True
print(True and False)   # False
print(False and True)   # False
print(False and False)  # False

# Tabella di verità dell'operatore or (o)
print(True or True)    # True
print(True or False)   # True
print(False or True)   # True
print(False or False)  # False

# Tabella di verità dell'operatore not (no)
print(not True)   # False
print(not False)  # True

Esempio: spedizione gratuita. Un negozio offre spedizione gratuita ai clienti VIP oppure per acquisti superiori a R$ 200,00 - a patto che l'indirizzo non sia internazionale.

cliente_vip = False
valor_compra = 250.00
endereco_internacional = False

compra_acima_do_minimo = valor_compra > 200
tem_frete_gratis = (cliente_vip or compra_acima_do_minimo) and not endereco_internacional

print(tem_frete_gratis)  # True

Puoi trovare anche gli operatori & (e) e | (o) in alcuni codici - funzionano con i booleani e sono molto usati in librerie come Pandas. Nel Python "puro", però, la forma raccomandata e più leggibile è usare and, or e not.

Conversione

Possiamo convertire qualsiasi valore in booleano con la funzione nativa bool(). La regola è semplice: valori che rappresentano "vuoto" o "zero" diventano False; tutto il resto diventa True.

Valorebool(valore)
0 e 0.0False
"" (stringa vuota)False
NoneFalse
Qualsiasi altro numero (es: 19, -3.5)True
Qualsiasi stringa non vuota (es: 'O-', ' ')True
 
idade = 19
tipo_sanguineo = 'O-'
quantidade_filhos = 0
telefone_fixo = None
telefone_comercial = ''

print(bool(idade))               # True  - número diferente de zero
print(bool(tipo_sanguineo))      # True  - string com conteúdo
print(bool(quantidade_filhos))   # False - zero
print(bool(telefone_fixo))       # False - None
print(bool(telefone_comercial))  # False - string vazia

Rivisitando la motivazione

Ora possiamo risolvere il problema del login. Passo 1: confrontare i dati forniti dall'utente con i dati della registrazione:

usuario_correto = usuario == usuario_cadastro
senha_correta = senha == senha_cadastro

print(f'Usuário correto? {usuario_correto}')  # Usuário correto? True
print(f'Senha correta?   {senha_correta}')    # Senha correta?   False

Passo 2: decidere se l'accesso deve essere concesso. Per questo, entrambe le condizioni devono essere vere, quindi usiamo l'operatore and:

conceder_acesso = usuario_correto and senha_correta
print(f'Acesso concedido? {conceder_acesso}')  # Acesso concedido? False

Poiché la password digitata (andre123) è diversa da quella registrata (andre321), l'accesso è stato bloccato. Prova a modificare il valore della variabile senha all'inizio e ripetere il ragionamento!
