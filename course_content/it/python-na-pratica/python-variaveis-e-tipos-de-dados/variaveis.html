I programmi hanno bisogno di conservare informazioni per usarle in seguito: il nome di un cliente, il prezzo di un prodotto, il saldo di un conto. In Python, facciamo questo con le variabili.

Definizione

Una variabile è un nome che punta a un valore memorizzato nella memoria RAM del dispositivo in uso. Questa memorizzazione è volatile: quando il programma termina (o la sessione di Colab viene chiusa), i valori vengono cancellati.

Pensa a una variabile come a un'etichetta attaccata su una scatola: l'etichetta è il nome, e il contenuto della scatola è il valore. La sintassi per creare una variabile è:

nome_della_variabile = valore

Il segno = in Python significa assegnazione ("memorizza questo valore in questo nome"), e non uguaglianza matematica.

# Creando (assegnando) una variabile
eta = 30
print(eta)  # 30

# Riassegnando: il valore vecchio viene scartato e sostituito dal nuovo
eta = 27
print(eta)  # 27

# Le variabili possono contenere anche testi
nome = "Andrea"
print(nome)  # Andrea

Regole e buone pratiche di denominazione

I nomi delle variabili seguono alcune regole obbligatorie:

  • Devono iniziare con una lettera o underscore (_) - mai con un numero;
  • Possono contenere solo lettere, numeri e _ (senza spazi, trattini o simboli);
  • Python distingue maiuscole e minuscole: citta e Citta sono variabili diverse;
  • Non possono essere parole riservate del linguaggio, come if, for, True, class ecc.

E anche una convenzione molto importante: in Python usiamo lo standard snake_case (parole in minuscolo separate da _), secondo la guida di stile ufficiale del linguaggio, la PEP 8.

✅ Valido e consigliato❌ Non valido o sconsigliato
valore_totalevalore totale (spazio - non valido)
quantita_articoli2_quantita (inizia con un numero - non valido)
nome_clientenome-cliente (trattino - non valido)
tasso_interessex, abc, var1 (validi, ma non dicono nulla sul dato)
 
# ✅ I nomi descrittivi rendono il codice facile da capire
valore_totale_acquisto = 150.90
quantita_articoli = 3

# Python è case sensitive: queste sono DUE variabili diverse
citta = "Milano"
Citta = "Roma"

print(citta)  # Milano
print(Citta)  # Roma

Tipi nativi

Ogni valore in Python ha un tipo, che definisce cosa rappresenta e quali operazioni possiamo fare con esso. I tipi nativi più basilari sono:

CategoriaTipoEsempio
Numericoint (intero)42
Numericofloat (decimale)3.14
Numericocomplex (complesso)1 + 2j
Testostr (stringa)"Ciao"
Logicobool (booleano)True
VuotoNoneTypeNone

Per scoprire il tipo di qualsiasi valore o variabile, usiamo la funzione nativa type().

Tipi numerici: interi (int) e decimali (float).

# int: numeri interi
prezzo = 1000
print(prezzo)       # 1000
print(type(prezzo)) # <class 'int'>

# float: numeri decimali (attenzione: usa il PUNTO, non la virgola)
tasso_interesse = 0.05
print(tasso_interesse)       # 0.05
print(type(tasso_interesse)) # <class 'float'>

Tipo testo: stringhe (str), sempre tra virgolette singole o doppie.

# str: i testi possono usare le virgolette doppie...
nome_proprio = "Andrea"
print(nome_proprio)       # Andrea
print(type(nome_proprio)) # <class 'str'>

# ...oppure le virgolette singole, il risultato è lo stesso
paese = 'Italia'
print(paese)       # Italia
print(type(paese)) # <class 'str'>

Tipo logico: booleani (bool), che possono assumere solo True o False.

# bool: nota la prima lettera MAIUSCOLA in True e False
utente_maggiorenne = True
print(utente_maggiorenne)       # True
print(type(utente_maggiorenne)) # <class 'bool'>

Tipo vuoto: NoneType, il cui unico valore è None e rappresenta l' assenza di valore.

# None: utile per indicare che un dato non esiste o non è ancora stato fornito
telefono_fisso = None
print(telefono_fisso)       # None
print(type(telefono_fisso)) # <class 'NoneType'>

Python ha una tipizzazione dinamica: non serve dichiarare il tipo della variabile, perché viene scoperto automaticamente a partire dal valore. Questo significa anche che una stessa variabile può arrivare a contenere un valore di un altro tipo:

# Il tipo è definito dal valore, non dalla variabile
dato = 10
print(type(dato)) # <class 'int'>

dato = "dieci"
print(type(dato)) # <class 'str'>

Anche se possibile, cambiare il tipo di una variabile nel corso del codice tende a generare confusione. Preferisci mantenere ogni variabile con un unico tipo.
