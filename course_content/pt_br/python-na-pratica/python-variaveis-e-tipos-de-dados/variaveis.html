Programas precisam guardar informações para usá-las depois: o nome de um cliente, o preço de um produto, o saldo de uma conta. Em Python, fazemos isso com variáveis.

Definição

Uma variável é um nome que aponta para um valor armazenado na memória RAM do dispositivo em uso. Esse armazenamento é volátil: quando o programa termina (ou a sessão do Colab é encerrada), os valores são apagados.

Pense em uma variável como uma etiqueta colada em uma caixa: a etiqueta é o nome, e o conteúdo da caixa é o valor. A sintaxe para criar uma variável é:

nome_da_variavel = valor

O sinal = em Python significa atribuição ("guarde este valor neste nome"), e não igualdade matemática.

# Criando (atribuindo) uma variável
idade = 30
print(idade)  # 30

# Reatribuindo: o valor antigo é descartado e substituído pelo novo
idade = 27
print(idade)  # 27

# Variáveis também podem guardar textos
nome = "André"
print(nome)  # André

Regras e boas práticas de nomenclatura

Os nomes de variáveis seguem algumas regras obrigatórias:

  • Devem começar com uma letra ou underline (_) - nunca com número;
  • Podem conter apenas letras, números e _ (sem espaços, hífens ou símbolos);
  • O Python diferencia maiúsculas de minúsculas: cidade e Cidade são variáveis diferentes;
  • Não podem ser palavras reservadas da linguagem, como if, for, True, class etc.

E também uma convenção muito importante: em Python usamos o padrão snake_case (palavras em minúsculas separadas por _), conforme o guia de estilo oficial da linguagem, a PEP 8.

✅ Válido e recomendado❌ Inválido ou não recomendado
valor_totalvalor total (espaço - inválido)
quantidade_itens2_quantidade (começa com número - inválido)
nome_clientenome-cliente (hífen - inválido)

# ✅ Nomes descritivos deixam o código fácil de entender
valor_total_compra = 150.90
quantidade_de_itens = 3

# Python é case sensitive: estas são DUAS variáveis diferentes
cidade = "São Paulo"
Cidade = "Rio de Janeiro"

print(cidade)  # São Paulo
print(Cidade)  # Rio de Janeiro

Tipos nativos

Todo valor em Python possui um tipo, que define o que ele representa e quais operações podemos fazer com ele. Os tipos nativos mais básicos são:

CategoriaTipoExemplo
Numéricoint (inteiro)42
Numéricofloat (decimal)3.14
Numéricocomplex (complexo)1 + 2j
Textostr (string)"Olá"
Lógicobool (booleano)True
VazioNoneTypeNone

Para descobrir o tipo de qualquer valor ou variável, usamos a função nativa type().

Tipos numéricos: inteiros (int) e decimais (float).

# int: números inteiros
preco = 1000
print(preco)       # 1000
print(type(preco)) # <class 'int'>

# float: números decimais (atenção: use PONTO, e não vírgula)
taxa_de_juros = 0.05
print(taxa_de_juros)       # 0.05
print(type(taxa_de_juros)) # <class 'float'>

Tipo de texto: strings (str), sempre entre aspas simples ou duplas.

# str: textos podem usar aspas duplas...
primeiro_nome = "André"
print(primeiro_nome)       # André
print(type(primeiro_nome)) # <class 'str'>

# ...ou aspas simples, o resultado é o mesmo
pais = 'Brasil'
print(pais)       # Brasil
print(type(pais)) # <class 'str'>

Tipo lógico: booleanos (bool), que só podem assumir True ou False.

# bool: note a primeira letra MAIÚSCULA em True e False
usuario_maior_de_idade = True
print(usuario_maior_de_idade)       # True
print(type(usuario_maior_de_idade)) # <class 'bool'>

Tipo vazio: NoneType, cujo único valor é None e representa a ausência de valor.

# None: útil para indicar que um dado não existe ou ainda não foi informado
telefone_fixo = None
print(telefone_fixo)       # None
print(type(telefone_fixo)) # <class 'NoneType'>

Python possui tipagem dinâmica: você não precisa declarar o tipo da variável, pois ele é descoberto automaticamente a partir do valor. Isso também significa que uma mesma variável pode passar a guardar um valor de outro tipo:

# O tipo é definido pelo valor, não pela variável
dado = 10
print(type(dado)) # <class 'int'>

dado = "dez"
print(type(dado)) # <class 'str'>

Apesar de possível, trocar o tipo de uma variável ao longo do código costuma gerar confusão. Prefira manter cada variável com um único tipo.
