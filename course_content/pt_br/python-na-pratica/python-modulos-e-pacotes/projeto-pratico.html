Objetivo

Ao final deste projeto, você terá praticado, dentro de um único cenário conectado:

Extra 1 — Um módulo, dois apelidos

Quando você importa o mesmo módulo duas vezes, ainda que com apelidos diferentes, o Python não carrega o arquivo duas vezes — ele reaproveita o mesmo objeto já carregado na memória. Confirme isso comparando os dois apelidos abaixo com o operador is (visto no Módulo 03).
