Bootcamps

Uma sequência de trilhas e projetos numa jornada só - do zero até um resultado concreto. Feito pra quem quer um caminho, não uma lista.

Intermediário 5 meses

Desenvolvedor Backend

Da lógica ao backend de produção: a base vem do JavaScript, a forma vem do TypeScript, o dado passa por SQL e NoSQL, a API sai em Node/Express com autenticação, o ambiente sobe com Docker, e a noção de complexidade de algoritmos é o que separa código que vira produto de código que vira legenda. Cinco projetos no caminho, e o último é um encurtador de URLs — você termina com código de verdade rodando.

// você sai daqui sabendo Ao terminar, você tipa o código em TypeScript, modela dados em SQL e usa NoSQL a favor (documento e chave-valor), constrói uma API REST em Node/Express com banco, autenticação e cache, e sabe avaliar o custo dos seus algoritmos.

Iniciante 7 meses

Desenvolvedor Frontend

Do zero absoluto ao frontend de produção. Você começa sem nunca ter programado — lógica, terminal e Git — passa pela base da web (HTML, CSS, layout responsivo), aprende a construir interfaces de verdade com JavaScript e React, tipa tudo com TypeScript, e então entra no que separa um junior pronto pro mercado: formulários sérios, server state, Next.js, testes, performance, acessibilidade a fundo, segurança e deploy na edge. Sete projetos no caminho e a IA como par de programação desde cedo. Você termina com portfólio e código rodando em produção.

// você sai daqui sabendo Ao terminar, você constrói e faz deploy de aplicações web completas: interfaces acessíveis e responsivas em React + TypeScript, com formulários validados ponta a ponta, server state gerenciado, renderização no servidor com Next.js, cobertura de testes, orçamento de performance, e hardening de segurança — tudo versionado no Git e publicado na edge. Sai pronto pra uma vaga de frontend junior.
