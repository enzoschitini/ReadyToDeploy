Desenvolvedor Backend

Da lógica ao backend de produção: a base vem do JavaScript, a forma vem do TypeScript, o dado passa por SQL e NoSQL, a API sai em Node/Express com autenticação, o ambiente sobe com Docker, e a noção de complexidade de algoritmos é o que separa código que vira produto de código que vira legenda.

Cinco projetos no caminho, e o último é um encurtador de URLs — você termina com código de verdade rodando.

// você sai daqui sabendo

Ao terminar, você tipa o código em TypeScript, modela dados em SQL e usa NoSQL a favor (documento e chave-valor), constrói uma API REST em Node/Express com banco, autenticação e cache, e sabe avaliar o custo dos seus algoritmos.

// currículo

Uma jornada só, do zero até um resultado concreto: trilhas e projetos intercalados, nessa ordem, cada um construindo em cima do anterior.

  1. 01 Trilha Programação do Zero Base de lógica e JavaScript pra quem começa do zero. →
  2. 02 Projeto Primeiro projeto: coloque a lógica em prática Um build pequeno pra fixar variáveis, condicionais e funções logo depois do primeiro contato com código. →
  3. 03 Trilha Terminal para Devs O terminal é onde o backend vive: comandos essenciais em qualquer ambiente unix (local, VPS, container). →
  4. 04 Trilha Git Controle de versão do zero ao avançado — obrigatório em qualquer time e pré-requisito pra deploy e colaboração. →
  5. 05 Trilha Conventional Commits Mensagens de commit que contam uma história: o formato type(escopo): descrição, SemVer automática e changelog — o elo entre o histórico e a release. →
  6. 06 Trilha TypeScript TypeScript logo depois de JavaScript: a mente ainda está fresca sobre a linguagem, e o TS vira a forma padrão de escrever código backend no mercado. →
  7. 07 Trilha SQL e Banco de Dados Modelagem e SQL puro — a fundação de dados antes de qualquer ORM. →
  8. 08 Projeto Modelagem de um Banco de Dados Modele o banco de um mini e-commerce e escreva as consultas do negócio em SQL puro. →
  9. 09 Trilha NoSQL: Bancos Não-Relacionais Complemento ao SQL: o que é NoSQL, modelo de documento (MongoDB) e chave-valor (Redis). Como e quando combinar com SQL em sistemas reais. →
  10. 10 Trilha Backend HTTP, Node, Express, banco, ORM, autenticação, validação, testes, async profundo, error handling e debugging. →
  11. 11 Projeto API REST com Autenticação Construa a API completa: CRUD, banco, validação, login e rotas protegidas. →
  12. 12 Trilha Docker Fundamentos Empacote a API em containers: imagens, Dockerfile, volumes e rede — o jeito moderno de rodar backend. →
  13. 13 Trilha Docker Compose e Workflows Suba app + banco + cache com um comando e monte o ambiente de dev e produção da sua API. →
  14. 14 Projeto Empacote um Serviço com Docker Coloque a sua API num container e suba app + banco com um comando só. →
  15. 15 Trilha Complexidade de Algoritmos Pra escrever backend que aguenta escala. →
  16. 16 Projeto Busca com Filtros Sinta o custo das operações crescerem com os dados - a teoria de complexidade na prática. →
  17. 17 Trilha Cibersegurança para Desenvolvedores A base de segurança que todo dev backend precisa: dados, redes, autenticação, autorização, vulnerabilidades, OWASP Top 10 e segurança defensiva. →
  18. 18 Projeto Projeto final: um encurtador de URLs Um serviço estilo bit.ly: recebe uma URL longa, devolve uma curta e redireciona — do zero, pensando na arquitetura. →
